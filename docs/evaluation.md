# Phase 2: 六設定の帯域評価

共通評価器は data/bands.csv にある6設定のUL/DL/H2/H3の全区間を読み、両端を含む周波数メッシュで評価する。B13+B14は2バンドの区間を同一設定で処理する。

Python API: lpf.evaluate.evaluate_settings(make_circuit, samples_per_segment=21)。make_circuit(case)はlpf.circuit.solveのキーワード引数を返す。固定トポロジー・L・固定C・結合の設定間不変性は呼出側の責任であり、現時点では自動検査しない。

ILと高調波帯域の伝送電力減衰はともに -10log10(Pload/Pavs)。UL/DLは最大、H2/H3は最小を報告する。有限メッシュの極値は連続帯域の保証ではない。

independent.py はインダクタ枝を消去した節点アドミタンス法による照合であり、MNAとは異なる線形方程式の組立てを用いるが、同一集中定数物理モデルを共有する。EM検証や高調波生成モデルではない。

仕様適合する新しいLPF候補を発見したわけではない。Phase 3は停止中。

## 2026-10-11 追記：探索トラックの共通評価

ChatGPT主導の専用縮約ソルバも、P4-Aのグラフ探索も、最終的な比較には同じ50Ω／60−j40Ωの集中定数モデルと6設定UL/DL・UL H2/H3を使用する。`matching_only`のILは`full_lpf`の実績に合算しない。後者の必須減衰は30dB、公称目標35dB、最大ILの公称目標は0.30dB。比較基準LPF-007の有限グリッド値と昇格ゲートは[比較基準](baselines.md)を参照。

現行の`evaluate_settings`は周波数区間あたり2点以上の**有限グリッド評価**であり、全周波数区間の極大・極小を証明しない。最適化器の成功状態、物理制約適合、全グリッドの検証、独立方程式照合を別々に報告する。`validate_six_settings`の不変性検査は候補インポート時に明示的に呼び出す必要があり、自動で`evaluate_settings`から実行されるわけではない。

AI探索で発見した内部トラップ節点に可変Cを置く回路は、現在のP4-A既定アダプタのIN/OUT配置とは異なる。コード移行後に同一モデルで再計算できるまでは、表現範囲の差を成果比較に明記する。
