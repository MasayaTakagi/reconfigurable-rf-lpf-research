# EXP-007 — 0.40dB目標の継続探索：固定C接続とPCB-L補助経路

**Phase 2／2026-10-12。** 6設定UL/DL最大IL≤0.40dB、公称UL H2/H3全域最小減衰≥35dBを中間目標とする。今回の探索では**0.40dB未達**。現状のコスト7最良発見値 [A7-04](../EXP-006/A7-04.json) **最大IL 0.506950759dB、最小H2=35.001995dB、H3=35.002000dB**を維持する。A7-04は公称減衰余裕約0.002dBしかなく、実装の頑健性を示すものではない。

## 固定条件と比較基準

- 6設定 B71/B12/B28/B13+B14（1設定）/B26/B8、UL/DL最大ILおよびULのH2/H3全域で減衰を比較。50Ω入力、周波数一定の負荷60−j40Ω。
- LQP02 Q25、GJM01/対GND IC可変C Q80。固定L/C/kは6設定共通、IC可変Cは2枝のみ・各0～4pF。物理的チップコイル列はL1–L2–L3–L0、強結合は隣接のみ|k|≤0.4、非隣接公称k=0、K正定値。
- 今回のコスト7は明示された**研究用予算上限**。制約正本のhard cap6は未変更。Phase 3は停止。

## 1. 固定GJM01の枝再配置：44件

A7-04の4個のLQP02、4個の固定GJM01、2枝の対GND可変Cを出発点に、**固定GJM01のうち1枝を別の節点対へ移す44通り**を検討。2つの可変シャントLC先端間を固定Cで橋絡する案も含む。

- 宣言した配置数=44、実行済み=**44**、実行エラー=0、35dBを満たす**粗い数値成立解=19件**。
- 各配置はA7-04からの単一初期値、L-BFGS-B最大48反復。最適化4点/周波数区間、一次スクリーニング31点/区間。したがって「44通りを網羅的に大域最適化した」わけではない。
- 最良のスクリーニング結果は**IL 0.524580792dB**。新しい最良値へ昇格できなかった。固定C Cf0（内部節点1–2間、現行L3に並列）を内部節点1→GNDへ移動した構成。全パラメータと6設定の可変Cは後述の再計算データを参照。
- 一時的に**IL 0.504934dB**が出た別案はH2=33.599dB、H3=33.619dBであり**35dB条件未達**。追加精密化でも35dBを回復しておらず、成立設計として扱わない。

### 最良の新しい固定C配置案を独立検証

該当0.524581dB案についてのみ、周波数区間ごと**7,001点**の6設定UL/DL/H2/H3を再計算し、54代表周波数でコイル電流を独立未知数とする**9×9 MNA**で電力保存を照合。

| 指標 | 密グリッド／独立MNA |
|---|---:|
| 6設定最大IL | **0.524580792dB** |
| H2最小 | 35.029260dB |
| H3最小 | 35.029438dB |
| コイル結合行列の最小固有値 | 0.437412 |
| 独立MNA代表点 | 54点 |
| 最大電力保存残差 | 7.73×10⁻18W |

固定GJM01 Q80の4値[pF]は**[0.100000, 0.107352, 0.288397, 0.695643]**。LQP02 Q25の4値[nH]は**[3.305335, 7.637859, 5.888388, 7.158760]**。L1–L2、L2–L3、L3–L0の隣接kは**[−0.003029, −0.399845, +0.395758]**。詳細と6設定の可変Cの数値はこの実験の会話添付ZIPの `best_rewired_dense_validation.json` を正本とする。高密度評価は連続区間の数学的保証ではない。

## 2. PCB-L 1本の追加：15件

A7-04の固定回路に、**PCB-L 1本（Q12、0.1～3nH、チップ面積コスト0）**を5節点の15接続候補へ追加し、各1初期値で数値最適化した。chip–PCB-L相互結合k=0（|k|≤0.03を満たす）、PCB-L同士は1本のため結合なし。固定GJM01と2可変CはA7-04と共通構成。

- 実行15/15、エラー0、31点/周波数区間の35dB数値成立解5件。
- **最良粗グリッドIL 1.063643dB、H2=35.537641dB、H3=35.080043dB**。A7-04には届かない。
- 追加PCB-L枝を共振器の独立直列容量と組み合わせる構成、PCB-L×2～3（最大相互結合|k|≤0.6、SPD）、PCB-L–chip弱結合での新グラフは**この15件では未評価**。したがってPCB-Lの一般的性能限界は主張しない。最良PCB-L案は高密度独立MNA検証対象に昇格していない。

## 3. A7-04可変Cの局所感度解析

2つの対GND可変C（Cv0, Cv1）を各設定でそれぞれ**±0.005pF**摂動し、H2/H3の有限グリッド最小減衰の感度行列 `J=∂(H2min,H3min)/∂(Cv0,Cv1)` を中央差分で近似。151点／周波数区間。単位はdB/pF。

| 設定 | Jの条件数（概数） |
|---|---:|
| B71 | **9.364** |
| B12 | 1.709 |
| B28 | 2.230 |
| B13+B14 | 1.961 |
| B26 | 1.815 |
| B8 | 2.920 |

B71の `J≈[[+18.164,+3.931],[-18.423,-8.376]]`。B71では他の設定より2つの減衰指標の局所制御感度が偏り、最適化が難しい可能性がある。B71に関するJは151/601/2001点のグリッドで一致。**これは減衰最小値の局所微分であり、伝送零点の固有値感度でも、可制御性の大域証明でもない**。感度の条件数は単位スケーリングに依存するため、異なるC尺度での直接比較には注意する。

## 結論と次の探索

1. **今回は既存基準A7-04を更新できていない**。検証したのは44個の固定C再配置とPCB-L1本の15枝配置の有限局所解だけであり、性能限界・探索範囲の網羅完了は主張しない。
2. 新しいトポロジー評価では、単純なILとH2/H3に加え、**2可変C→2つの減衰帯域の局所感度行列**を一次選別に取り入れる。B71の制御感度悪化に注意する。ただし最小減衰35dBと最悪ILの定義は変えない。
3. 次に優先するのは、**可変2枝が3つ以上の共振モードへ協調作用する新しいグラフ**の列挙と、既存4L局所解からの継続初期値生成、5Lや複数PCB-Lと固定容量の組み合わせ。未収束は性能劣位と解釈しない。
4. 重い多初期値・網羅探索は既存の手動GitHub Actionsへ分割し、成功・失敗・未実行を管理。Phase 3への移行は引き続き停止。

**元コード・全44+15最適化ベクトル・A7-04感度・高密度独立MNAデータ**は、会話内配布アーカイブ `lpf_phase2_EXP007_20261012.zip` に保存した。これは GitHubへZIPを格納したとの主張ではない。
