# Phase 2 統合開発ロードマップ（現行版）

> 更新日: 2026-10-11。**本書が現行の開発ロードマップの正本**。過去の年次別／P0–P6／Phase 4以降を前提とする計画は、現在の作業指示ではない。歴史資料は削除せず保存する。Phase 3はユーザーの明示承認まで停止し、Phase 4以降の開発計画はここでは定義しない。

## 目的と当面の成功条件

複数LTEバンド対応の可変RF LPFを、性能・実装性・面積・再現性を考慮して探索する。現時点の最重要目標は、**ChatGPTが先行して発案したLPF-007より良い回路を、AI主導探索と体系的トポロジー探索の両方から発見すること**。

- 当面の比較基準：`LPF-007`、最大IL **0.513168414dB**、H2/H3最小約35.07dB、面積6、現行制約のfinite-grid計算候補。最適化未収束、実装未検証。詳細は[比較基準](baselines.md)。
- **第一の主目標**：同一RF仕様、同一評価条件でH2/H3**各35dB以上**、6設定UL/DL最大ILがLPF-007より低い`full_lpf`候補を発見し、独立解析と高密度グリッドで再確認する。
- **設計目標**：同条件で最大IL**0.30dB以下**。最小H2/H3は必須30dB、公称35dBを目指す。35dB未達の探索結果は別クラスとして明記する。
- `matching_only`の面積別最良ILは探索効率や整合機能の理解に利用するが、LPF-007のfull-LPF性能の代替評価にしない。
- いずれも有限回の探索結果を大域最適・理論限界と断言しない。

RF仕様・物理制約の正本は[設計制約](../data/design_constraints.json)と[帯域表](../data/bands.csv)。6設定B71/B12/B28/B13+B14/B26/B8のUL/DL全域最悪ILとULのH2/H3全域最小減衰、源50Ω、負荷60−j40Ω、面積≤6、PCB-L≤3、対GND可変C≤2枝・各0–4pF、チップL単列・隣接強結合、全結合行列SPDを維持する。

**新規のChatGPT探索の作業先**：[`experiments/chatgpt_topology_search/`](../experiments/chatgpt_topology_search/) → 個別実験は`runs/EXP-NNN/`。自動P4-Aの現行実装は`experiments/matching_limit/`。保存場所の原則は[フォルダ構成ガイド](repository_layout.md)に記載する。

両トラックは候補を相互供給する。Aの良好解はBの初期値／構造変異種に使い、Bで見つけた新構造はAの専用最適化に移す。専用ソルバによる「良好値」と汎用MNAによる「検証値」は別に保存する。

**最初に修正する技術的障壁**：現行Bの汎用`build_grounded_settings`は可変Cの対GND接続をIN/OUTに固定しており、AのLPF-007/008が使用する**内部トラップ節点**を直接扱えない。Bの候補数を増やす前に接続点の一般化とA/B共通モデル化を行う。[コード分担](architecture.md)。

### 重要な運用ルール

- **AとE2はR0–G2・E1の終了を待たず継続**する。有望トポロジーの考案を自動探索の実装待ちにしない。
- R0/R1を優先する理由は、**LPF-007/008を列挙探索側でも表現できること**が正当な比較の前提になるため。
- G2はprofilingを先行。最適化の`success=false`を回路性能の下限と解釈しない。多初期値・minimaxの方式を比較する。
- E1の「網羅」は定義した有限グラフクラスに限る。物理レイアウト、部品値、連続磁気結合、可変C配置の各次元を別々に記録する。予算で探索を切った場合は未実行と表示する。
- 当面のE1計算枠（内部ノード4、固定枝8）は物理仕様ではない。段階拡張は、改善余地・探索品質・計算予算を報告して判断する。勝手に面積・Q・強結合制限を緩和しない。
- 人が明示判断を要するRF仕様変更やPhase移行を除き、コード開発・テスト・小規模benchmarkを継続。大規模バッチは手動起動、無料Runner利用枠・Artifactsの保持期限に配慮する。
- 各結果はソースSHA、環境、設定ハッシュ、seed、探索構造ID、収束状態、評価回数、経過時間、周波数密度、独立検証状態を保持する。

## Phase 2完了条件

1. 探索クラスの範囲と未探索部分が記録され、AI案と自動生成案が同一の物理・評価条件で比較できる。
2. 現行仕様内のfull-LPF候補でLPF-007に対する改善結果（または限界・未達に関する実験的な証拠）が得られ、面積別の達成／未達が独立に検証される。
3. 性能・部品・結合配置の妥当性・変動感度、再現可能な計算条件と結果を報告できる。
4. ユーザーがPhase 2の評価結果を明示的にレビューし、次フェーズの判断を行う。

**Phase 3への移行は自動では行わない。** 以前のPhase 4以降の構想は現行ロードマップから除外する。必要な場合はPhase 2完了後、ユーザーの承認を受けて別に策定する。
