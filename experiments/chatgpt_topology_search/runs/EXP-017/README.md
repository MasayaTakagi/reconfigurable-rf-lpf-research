## ロバスト性・実装判断

選別した35dB・面積9⅓候補は公称減衰余裕約0.03dB。固定定数・IC Cを調整せず全固定Cを+1%変化させると最小H3は**33.889dB**、全インダクタLを+1%変化させると最小H2は**33.469dB**へ低下。結合kが同方向に一律+0.01ずれた仮想ケースでは最小H2約24.963dB。この結果は実際の製造分布や閉ループ再調整をモデル化したものではないが、物理頑健性が不十分なことを示す。

同一2-LQW04構成で、H2/H3の最小値を35.5dBに制約して全定数を再最適化すると最悪IL約**0.385952dB**、36dBなら**0.393835dB**。これも公差最悪保証ではない。

**未確認:** LQW04の品番別L値使用可能範囲・SRF・実Q(f)、異種パッケージ間の相互結合同時実現、実PCB/IC面積、EM・寄生・温度・容量実装・Phase 3寄生。旧一定Qモデルでの有限グリッドと実デバイス性能は区別する。
