# EXP-011 — Q25一定、IL最小化／トポロジー縮約（Phase 2、2026-10-12）

**結論:** EXP010-05（コスト6、最悪IL=0.299890577 dB）を起点に、固定GJMの接続変更と等Qの並列固定C・可変Cの合成、およびPCB固定Cの除去・全素子再最適化を行い、**チップコスト4⅔で最悪IL=0.293821739 dB**を得た。[EXP011-01](EXP011-01.json) は6設定のUL/DL全帯域で評価した、現時点の有限局所探索による最良記録である。数値検証は後述。**理論性能限界、大域最適、実基板性能の証明ではない。**

### 回路グラフ（ノード0=GND）

```text
  50Ω source     L0                  L3             output → (60 - j40) Ω
    node1  o-----LLLL-----o node2---LLLL----o node3
           |-----Cf3------|          |--Cv2--|  |
                            |                   L1
                            L2                  |
                            |                 node4
                          node5                 |
                            |                  Cv0
                           Cv1                  |
                            |                  GND
                           GND
```

Cf3が**L0並列**（node1–node2）、Cv2が**L3並列**（node2–node3）。Cv0はnode4–GND、Cv1はnode5–GND。固定PCBパターンCは存在しない。チップLの物理一列順は **L1–L2–L3–L0**、結合するのは隣接3ペアのみで、EXP011-01の符号付きkは **[+0.01292196, −0.37316698, +0.40000000]**、非隣接公称k=0。行列は正定値。

**EXP011-01の公称定数:** L0=3.408462 nH、L1=56.000000 nH（探索上限）、L2=8.044533 nH、L3=4.853728 nH、Cf3=0.780469 pF。3個のIC可変CはQ80、各0–4 pF（設定ごとの厳密値はJSON）。各LのQはユーザー指定どおり周波数一定の**25**。固定GJM CとIC CのQは80。チップ面積は4×1+1×(2/3)=4⅔、**PCB実面積とIC実装面積はこのコストに含めない。**

### 設計の狙いと面積削減

1. EXP010-05の主信号経路L0/L3、補助共振枝L1/L2、非GND可変Cv2の構造を残し、固定GJMの入出力ブリッジCf1を別の枝に移した。SLSQPの有限局所探索ではCf1をCv0と並列に置く案が有望だった。
2. このCf1、および従来からCv1と並列だったCf2は、**双方のQが可変CのQ80と等しい**ため、各設定の可変C容量へ固定容量を加算して厳密に同じ理想集中定数アドミタンスで置換できる。6設定とも可変容量0–4 pF内に収まる。物理固定GJM2個を除去し、GJMはL0並列Cf3のみとなる。
3. 上記縮約のあと、数値下限0.02 pFのPCBパターン固定C（L1並列）を除去して、全L/C/kおよび6設定×3個の可変Cを再最適化した。PCB-Cは最終回路**0本**。探索用の微小ダミー容量はチェックポイントの実回路に**含まれない**。
4. L0/L3の導通経路が中心のためL損失は引き続き支配的。さらに低ILの余地は一列チップ配置・共振器接続・電流バイパスの全体最適化にあるが、今回の有限探索で限界値は主張しない。

## 何を実行し、何を実行していないか

- [search_summary.json](search_summary.json) にそれぞれの有限試行数、最良201点スクリーニング解、失敗件数を記録。大規模自動探索と誤認しない。
- 旧EXP010回路起点の固定GJM単独33枝×2初期値、2個目PCB固定C14枝×2、可変C第3枝9位置×3、固定GJM2枝同時変更156組×1を一次探索。固定GJM2個を等Q可変Cへ吸収後、PCB-Cを実回路から除去して継続最適化した。
- 簡素化後の真の4L・1GJM・0PCBトポロジー専用の[解析ヤコビアン付き再最適化器](compact_search.py)で、固定GJM15位置×2、非GND可変C9位置×2、GJM追加14位置×2、PCB固定C追加15位置×2などを有限局所探索。**これらの試行内ではEXP011-01より低い成立解は確認できていない。**
- 古い多素子スクリプトのチップL接続変更試験は56候補中**17グラフ×2初期値で打ち切り**（その履歴は不完全）。これとは別に今回の縮約された**真の4L+1GJM+0PCB回路**で、4個のLの接続を1本ずつ変更する**56グラフを各1初期値**で全実行し、201点グリッドの成立解最良は**0.298567 dB**。EXP011-01の0.293822 dBを上回らなかった。各グラフ十分な多初期値最適化や数学的な限界とはみなさない。
- 高速最適化スクリプトは純粋な4L+1GJM+0PCBの回路を解析する。初期の構造縮約に用いたダミー素子は解析器には存在しない。
- 従来の短期探索の**全反復履歴をリポジトリへ完全移植したわけではない**。成功候補の厳密パラメータ、独立検証、検証器コード、探索集計、再実行可能な汎用最適化器を保存した。

## 独立数値検証と再現方法

[verify.py](verify.py) は新規に実装した独立した9×9「L電流を未知数として残したMNA」で、高密度縮約5×5解析の結果と照合する。**各個別UL/DL/H2/H3区間7,001点**と最悪点付近の有界1次元極値探索、6設定×3領域×3周波数=54点のMNA独立照合、全L・C消費電力と反射電力の和を検算。SPDを検算。最大収支残差EXP011-01が**8.67×10⁻18 W**、EXP011-02が**6.51×10⁻18 W**。なお連続周波数の厳密区間保証、周波数依存QやEM、寄生、製造ばらつきは**未検証**。

- 相互結合1ペアが|k|=0.4上限で、同時実装のEM検証はまだない。結合行列SPDは確認済み。
