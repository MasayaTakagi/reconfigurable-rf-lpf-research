**合格条件：** 旧回帰テストPASS、HV/HQ境界・内部C配置・違反構成拒否の新テストPASS、別手法MNA一致。

1. ハードコードされた面積6を正式制約ではなく`--max-search-area`等の**実験パラメータ**として分離する。実験IDとhashの更新が必要。自動探索の素子アルファベット・探索格子・未探索クラスを明示。
