# 設計仕様 / Specification

**現行の承認済み数値制約:** [RF-F001](../data/constraints/formal/RF-F001.json)（[版管理台帳](../data/constraints/registry.json)）。[`data/design_constraints.json`](../data/design_constraints.json) は現行正式版と一致する互換用コピー。この文書は説明であり、独立した数値制約の正本ではない。

6設定（B71/B12/B28/B13+B14/B26/B8）のUL・DL全域で最大挿入損失を評価し、ULのH2/H3全域の最小減衰を確認する。周波数区間は [`data/bands.csv`](../data/bands.csv)。入力50Ω、負荷60−j40Ω（周波数一定）。公称目標は最大IL 0.30dB以下、H2/H3 35dB以上、必須減衰30dB以上。

チップ面積コストはLQP02=1、LQP01=2/3、LQW04=3、GJM01=2/3で計算する。**正式条件に面積コストのハード上限は設けない。コストと6設定UL/DL最悪ILのパレートフロンティアで最終的なバランスを評価する。****PCBパターン固定C（PCB_PATTERN_C）=0**（チップ面積換算）、**1個あたり0.02～0.2pF、Q=40、最大3個**とする。PCB-Lは原則3本以下、IC可変Cは原則2枝（対GND、各0–4pF）。**LQP02は単一Qでは扱わず、LQP02HV=Q25・0.4～27nH、LQP02HQ=Q20・0.2～56nH**とする（同じ面積単位1、いずれも探索用一定Q仮定）。LQP01 Q15、PCB-L Q12、**GJM01/IC可変C Q80**は暫定一定Qモデル。LQW04 Qは未確定。

チップLは一列配置し、強結合は物理隣接のみ |k|≤0.4。非強結合は公称k=0、弱結合感度で|k|≤0.1。chip–PCB |k|≤0.03、PCB–PCB |k|≤0.6。全インダクタンス行列は正定値。固定素子（PCBパターンCを含む）・結合・トポロジーは6設定共通で、可変Cだけ設定別。PCBパターンCはシャント／直列／ブリッジに固定素子として配置できる。チップ面積0でもパターン面積、寄生容量、基板公差、導体／誘電体損失は別途検証し、0.02pFの製造可能性や高周波Q40を保証するものではない。

**面積コストの計算上限（例：旧P4-Aでの6）は実験固有の探索範囲であり正式制約ではない。** 異なる探索範囲・目的や高調波条件の数値結果を混同しない。\n\n**Phase 2継続、Phase 3は明示承認まで停止。** `matching_only` はH2/H3制約を課さないため、`full_lpf` の結果と同列比較しない。旧仕様の結果は新仕様への適合が再検証されるまで歴史的参考値。

## 2026-10-12更新：LQP02HV／LQP02HQの選択と大きいLの扱い

- **標準探索はLQP02HV（Q=25）を優先し、全Lを27nH以下に収める。** 27nH以下なら必要に応じ小さい定数を選び、Qはシリーズに従う。HQのQ20をHVのQ25へ読み替えない。
- HVのみで所定のIL、H2/H3、面積を達成できない、または探索済みの結果としてHQに有意な利点がある場合に限って、**LQP02HQ（Q=20、最大56nH）を代替案として探索可能**とする。HQ採用時は**本数、最大L値、合計L値を小さくする**比較軸を設ける。値の大きいHQを最良ILだけで無条件に推奨しない。
- **新しい候補はLごとにシリーズ（HV/HQ）とシリーズ別Qを明示する。** シリーズ未指定・Q25一律の旧候補を新規則適合済みと扱わない。新規のL>27nHはHQでQ=20を用い、L>56nHはこの2シリーズの範囲外とする。
- インダクタンスが大きいほど自己共振周波数（SRF）が利用周波数へ接近し得るため、**上側のH3帯域も含めた全RF評価周波数に対し、採用予定品番固有のSRF、寄生および周波数依存インピーダンスを別途確認**する。今回の一定Q集中定数モデルはSRFを含まず、独立MNAの一致だけでは実測との一致を保証しない。ユーザー未承認の一律SRF閾値や追加の固定面積ペナルティは設定しない。
- 従来のEXP010～014等にあるL1>27nH、Q=25の性能は**旧仮定の履歴**として保持する。新ルールによるIL、H2/H3、コスト別性能はシリーズを変更して**全L/C/k・各設定可変Cを再最適化し独立検証するまで未確定**とする。
- 条件・実装上の注意・旧候補の扱いは[インダクタシリーズ別設計方針](inductor_series_policy.md)を参照。Phase 2のまま、Phase 3停止は継続する。
