# EXP-021 — RF-T004 4L系の電気的橋絡再合成・隣接磁気結合・損失感度探索（Phase 2）

**実施：2026-10-14。実行済み有限局所探索。Phase 3は未承認・未着手。** 既存の正式RF-F002実験EXP-017および試験RF-T004アーカイブEXP-020を変更・置換しない。

## 研究目的と出所

前回の文献調査（`docs/research/rf_t004_literature_survey_2026-10-14.md`）と旧4L/3可変C・固定C橋絡型（`EXP-016/ADDENDUM_2026-10-14.md`）を起点に、「固定共振/電気橋絡と可変Cの役割分担」「低QチップLの通過帯域電流削減」「一列配置かつ隣接のみの弱い実現可能範囲の磁気結合」を具体的に探索した。

最終結果は**全プロジェクトのbest-foundではない**。mainの[EXP-020](../EXP-020/README.md)はRF-T004で**面積13⅔、IL0.297114dB、H2/H3≥35.020dB**の数値達成済み候補を保持・独立再検証しており、こちらが現時点で先行する重要な基準。EXP-021の4L結果だけから「RF-T004ではIL≤0.30未達」と記述しない。

## 制約／計算上の前提

- RF-T004（RF-F002固定ベース）、resolved fingerprint `c66302a281a1fdb88da355fc44dac1ef3b1c4e18e8ff297db9e842b219b5b0c4`、正式ベース `f20d27e93451dcec2f823e6f7c3731c06d843050c4d2ace8b0b46ded605542e2`。
- 50Ω源、60−j40Ω負荷、IL=−10log10(Pload/Pavs)。`data/bands.csv`の6設定UL/DL/H2/H3の**不連続区間を個別評価**（B13+B14も連結しない）。
- IC可変Cは最大3枝・各0〜1.5pF・Q50、固定回路と接続位置は6設定共通、設定ごとに容量値のみ変更。GJM01固定CはQ80・各100pF以下。
- チップLの公称モデル：LQP02HV Q25、許可L=0.4〜27nHを優先、または試験的LQW04 Q33。LQW04について**0.4〜27nHという今回の探索範囲を正式製品範囲と混同しない**。品番・シリーズ別実L値、Q(f)、SRFは未確認。面積1（HV）／3（LQW04）。
- 磁気結合：物理的直列配置の**L0–L1–L2–L3**で隣接3ペアのみ signed |k|≤0.15、他の磁気結合0。全Lインダクタンス行列SPD・受動性を確認。結合係数の上限が**すべて同時に実装可能かどうかは未確認**。
- 面積はハード上限なし。チップ面積コスト＝HV本数＋3×LQW04本数＋2/3×GJM個数。PCB/IC資源・EM未計上。

## 新しい4L回路グラフ

ノード0=入力、3=出力、4=内部共振ノード、−1=GND。チップL固定エッジはすべて `L0:(0,1), L1:(1,2), L2:(2,3), L3:(2,4)`。

- **30dB用：** 固定GJM01 `(1,GND),(2,GND),(4,GND),(1,3),(2,4),(0,2)`。可変C `(0,3),(4,GND),(2,4)`。固定の橋絡Cを二重に加え、主信号経路インダクタ電流を分担。
- **35dB用：** 固定GJM01 `(1,GND),(2,GND),(4,GND),(0,2),(1,2),(2,3)`。可変C `(0,1),(2,3),(1,4)`。主信号経路Lのバイパスと共振内部経路を協調制御。
- 各L値、固定C値、6設定×3可変C、signed kおよび基準数値は[保存チェックポイント](selected_checkpoints.json)参照。0pF可変Cのアドミタンスは0（開放）。

## 実行済み有限探索の内訳

前回のEXP-016（4HV・固定4GJM／3可変C／k=0）から新たに以下を探索した。探索空間は設計者が選んだ有限集合でありP4-A網羅でも連続変数の大域最適化でもない。

1. 固定C橋絡の置換／追加、4Lコアの2系列で**計42構成**、21点/帯域区間のSLSQP epigraph minimax。
2. 強結合隣接3ペアを変数化し5個の異なる初期kで4対象コアを精密化、**計20試行**。L行列SPD、解析ヤコビアンの差分チェック（とくに極端な零点では相対差を判定）。
3. LQW04 Q33に差し替えるインダクタの組合せ**28構成**（30/35dB別）、k/L/Cを同時再最適化。
4. 5個目のGJM固定Cを追加する**44構成**、6個目を追加する**40構成**。
5. 結合上限を0、0.08、0.12、0.15に変更した局所再最適化と、30dB用の複数初期値再試行（上限感度であり許可制約の変更・正式採用ではない）。
6. 精密候補を101/301/1001点/区間で評価後、**8候補を7001点／`data/bands.csv`各個別区間**で再評価。各候補84点の独立枝電流MNA、電力保存、受動性、L行列SPDを確認。

局所探索はPython 3.13 / NumPy 2.3.5 / SciPy 1.17.0、OpenBLAS単一スレッドを使用。Git管理のuv.lockによる同一環境再実行や、保存した`verify.py`のGitHub CI実行は**未実施**。

他に面積7⅓・全HVで30dB=0.399144、35dB=0.466446、面積15⅓・全Q33で30dB=0.310746、35dB=0.364543。いずれも名目局所解。上表のLQW04×4は**EXP-020の面積13⅔・IL0.297114dB/35dB候補より両指標で劣る**ため、プロジェクト全体のPareto候補として推薦しない。

全8候補の独立84点MNAで最大節点電圧誤差は約2.2×10^-14V以下、電力収支残差は約3.9×10^-17W以下。上表の保存候補で全L行列最小固有値は正（全HV30で2.28nH、全HV35で1.50nH、全Q33 30で2.13nH、全Q33 35で1.50nH）。**SPDや数値的な受動性は、現実の一列配置で磁気結合を同時達成できる証明ではない**。
