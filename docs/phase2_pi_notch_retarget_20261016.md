# Phase 2 基礎研究：π型2組結合の伝送零点再配置（2026-10-16）

## 位置づけ
RF-F003 / RF-T005 のLPF仕様とは独立した理論研究。Phase 2継続、Phase 3未開始。今回の計算は**対称π型・条件を固定した方程式解と有限周波数検査**であり、正式な新規EXP-NNN体系的最適化ではない。EM・実測・SRF・Q(f)・相互抵抗・C損失は未検証。

本追補では、前回の「1GHz IL 0.227139→0.199417dB、2GHz減衰43.087→14.644dB」の原因を調べ、結合に伴う零点移動を補正した**公平な固定零点比較**を実施した。

## 対称π型・符号定義
電気構造：入力—Ls—出力、入力/出力それぞれからGNDへ La+Ca / Lb+Cb を直列シャント。La=Lb=Lh、Ca=Cb=C、Msa=M、Msb=−M、Mab=0。Isは入力→出力、Ia/Ibは両端子→GND。M=k sqrt(Ls Lh) は**符号付き**。

枝インピーダンス行列は

Z = [[zs,m,−m],[m,zh,0],[−m,0,zh]]

zs=Rs+jωLs、zh=Rh+j(ωLh−1/ωC)、m=jωM。

奇偶モードのノードアドミタンスは

- Ye=1/zh
- Yo=1/zh+2(zh−m)^2/{zh(zs zh−2m²)}
- Y12=(Ye−Yo)/2=−(zh−m)^2/{zh(zs zh−2m²)}

したがってM≠0・無損失・非退化の場合にY12=0となる周波数は

**fz=1/[2π sqrt(C(Lh−M))]** （Lh>M）。

M=0の極限ではシャントLC自身の共振 zh=0 によって伝送零点が生じる。上記Y12式の分母と分子が同時に0になるため、**M=0でY12=0と直接代入してはいけない**。周波数式の極限は連続。

1GHzにおける無損失50Ω/50Ωの入力整合条件は **Ye Yo=1/R0²**（R0=50Ω）。fzを固定したときC=1/[(2πfz)²(Lh−M)] とし、Lsについて1次元Brent求根を行った。収束確認は独立した回路の複素反射係数で実施。Lsの探索範囲4–12nHの指定根であり、全トポロジーの大域最適ではない。

銅損@1GHzは2GHz固定・非結合0.272256mW、逆符号結合0.234707mW（約13.79%低減）。戻り損失はそれぞれ35.508dB、36.486dB（**損失あり**）。別途損失ゼロで計算した1GHz整合は数値許容差内。

## 部分帯域チェックと残課題
**2GHz固定比較**で、1GHz±0.15GHzの最大ILは非結合0.3601dB、逆符号0.3092dB（有限401点）。しかし1.9–2.1GHzの最小減衰は非結合32.02dB、逆符号30.97dBに低下し、**阻止帯域全域で優れるとは限らない**。

逆符号設計を固定しCを±1%摂動すると2GHz減衰は公称51.532dB→50.779/51.003dB、零点は2.01008/1.99007GHzへ移動。この1変数摂動は一般的な製造公差保証ではない。

現状は**単点低損失と指定ノッチの両立を示す実行済みの回路理論ベンチ**であって、RF-F003への適用、LTEバンド全域、H2/H3連続周波数、周波数依存Q・EM・実測は未実行。次段階では同一の通過帯域最悪IL・阻止帯域最悪減衰・実装資源を制約したT/π比較が必要。正式な系統的探索はmainで新規EXP番号の事前予約と照合PASS後に実施。
