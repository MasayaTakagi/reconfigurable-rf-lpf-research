# RF-T003：5L・チップ面積6⅓未満への追加探索（2026-10-13、Phase 2）

**結果：5L・GJM×1・PCB-C×3、チップコスト5⅔でUL/DL最悪IL≤0.30dBとUL H2/H3≥30dBを**同時に満たす解は、今回の有限探索では未発見**。正式RF-F001の条件変更・Phase 3開始は行わない。**

## 正本・評価条件

GitHub main `dae9377d9053b9ca0193465f7d537df6c211b004`の正式RF-F001および試験RF-T003条件を参照。RF-T003は可変IC C(Q80)2枝、1対GND(5,0)＋1非GND橋絡(2,3)、各0～4pF。橋絡は固定L3(2,3)と**並列**であり、主信号経路の直列Cではない。6設定でL/C/kは共通、可変C値のみ別設定。50Ω電源、負荷60−j40Ω固定、Q一定、UL/DL最悪IL≤0.30dBおよびUL H2/H3最小減衰≥30dB。チップ面積費はLQP02×1、LQP01×⅔、GJM×⅔の和。PCBパターンC実占有面積は別計上すべき。LQP01の使用可能L範囲は**正式台帳でも未確定**。 一方、[村田製作所の公表ラインアップ](https://www.murata.com/en-us/products/inductor/chip/overview/lineup/rf1)ではLQP01HVは**0.3～16nH**であり、今回のQ15置換試算でILが最小となった**27nH案は同系列の実製品範囲外**である。従ってコスト6の実装成立候補には数えない。

**既存達成回路を置換しない：** [5L/2GJM/3PCB・コスト6⅓・IL0.295989814dB、H2/H3最小30.01dB](rft003_5l_cost6p33_study_20261013.md)。同じ電子回路を維持した30.10dB余裕版のILは0.297214dB、30.20dB余裕版は0.298585dB、30.30dB余裕版は0.299968dB。**新たなコスト5⅔の適合解が独立検証されるまで比較基準は維持する。**

- 既存の同コスト5L/1GJM約0.308893dBから**約0.000556dB改善**。これは限界値でなく、今回探索した集合での観測最良。

**損失制約の解釈**：GJM(4,GND)固定容量を落としてPCBパターンCを(4,GND)へ振り替えると部品Qが80→40になり、許容上限も0.20pFに制約される。旧成功5Lでは(4,GND)GJM約0.284pFを用いるため、同じ共振モードを単純に等価置換できない。現ニアミスはB71・B28・B13+B14・B26・B8でほぼ同じ最悪ILを示し、単一バンドだけの整合改善は全体目標の達成に直結しない。**別の電子回路グラフ／ノード共有方式による同時再合成が次の優先探索**。
