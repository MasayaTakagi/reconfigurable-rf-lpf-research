## π型・基本電気トポロジー

```
                           Ls     (main signal series)
         node0 IN ──────────LLLL────────── node1 OUT
            |                                 |
          La (LQP02HV)                      Lb (LQP02HV)
            |                                 |
         node2 (left tip)                  node3 (right tip)
            |                                 |
         CfL fixed                          CfR fixed
           || CvL tunable                    || CvR tunable
            |                                 |
           GND                               GND

          CfB fixed + optional CvB across IN–OUT / another bridge edge
```

- **誘導性枝**：(0,1) Ls、(0,2) La、(1,3) Lb。3本ともLQP02HV Q25、範囲0.4..27 nH、面積3。
- **固定容量枝**：(2,GND) CfL、(3,GND) CfR、(0,1) CfB。CfL/CfRをGJM01 (Q80、面積2/3) またはPCBパターンC (Q40、0.02..0.2pF) から選択。CfBはPCB Q40 (0.02..0.2pF)。3PCB以下。
- **IC可変C枝**：CvL=(2,GND)、CvR=(3,GND)を2つのH2/H3共振器の独立周波数制御に使い、CvB=(0,1)または(2,3)、(0,3)などを全体整合/零点制御に使う。各0..3pF/Q35、最大3枝、設定間でC値のみ変える。
- **磁気結合符号**：電流基準はLs IN→OUT、La IN→tip、Lb OUT→tip。初期案 k(Ls,La)=−0.075、k(Ls,Lb)=+0.075。最適化は−0.1..+0.1を自由探索し、巻線ドットの実装整合・非隣接漏れの感度は後段検証。
- いずれもLPFの**外部寄生**は別の固定S2PとしてCascadingして評価する。絶対に内部50Ω終端へ置き換えない。
