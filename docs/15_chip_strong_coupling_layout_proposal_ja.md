# チップLの隣接強結合モデル：正式採用条件（2026-10-10）

> 本文は当初の検討案を、**2026-10-10 12:23 UTCのユーザー回答（Q1=Aのみ、Q2=公称A／弱結合0.1以下）を受けて正式なPhase 2ルールに更新したもの**。履歴上のファイル名にはproposalが残るが、本文は承認済み。旧検討案はGitの履歴に残す。Phase 3は停止。

## 1. 適用範囲と物理配置

- チップL（LQP01/LQP02/LQW04など）を**一列に並べる配置のみ**を認める。強結合には隣接と磁気軸・巻線極性の適切な向きを必要とする。
- **強結合を許せるのは物理的に隣接するチップLのペアのみ。** 回路図の部品番号順と物理配置順は必ずしも一致しない。配置順序を明示し、6設定で共通とする。
- 物理的に隣接しても強結合を指定しないことができる。強結合を指定した隣接ペアのみ `|k| <= 0.4` を許可する。この上限は達成保証や固定値ではない。
- 隣接強結合に該当しない**すべてのchip–chipペアは公称 `k=0`** とする。弱結合感度・ロバスト性評価時は、そのペアごとに `|k| <= 0.1` を許す。弱結合係数を全ペアで無条件に任意独立最適化した結果は、物理配置の再確認が必要。
- **2次元配置、積層による非1D強結合、物理的に非隣接の強結合は標準探索から除外する。** 変更するにはユーザーの明示的再承認が必要。
- 結合の符号は、物理的な磁気軸・ドット規約と各枝の電流の正方向によって定める。符号を全ペアで無関係に自由化せず、一貫した巻線向きに基づく。
- PCB–PCB `|k|<=0.6`、chip–PCB `|k|<=0.03`、全インダクタの結合行列の**正定値条件**は引き続き必須。

## 2. 結合グラフによる定義

物理配置を並べたリスト `placement_order = [L3,L1,L5,L2,...]` とする。強結合指定ペア集合 `E_strong` は**隣接するリスト要素間の辺**の任意の部分集合とする。強結合グラフは一列のパスグラフの部分グラフ（linear forest）であり、以下を満たす。

```text
N = physical chip-inductor count
E_allowed = {(placement_order[i], placement_order[i+1]) : 0 <= i < N-1}
E_strong is a subset of E_allowed
number_of_strong_edges <= N-1
strong_degree_per_inductor <= 2
for (i,j) in E_strong:   |k_ij| <= 0.4
for (i,j) not in E_strong:
    k_ij = 0          # nominal scenario
    |k_ij| <= 0.1    # separate weak-coupling sensitivity/robustness scenario
Full inductance matrix must be positive definite
```

「弱結合を0.1まで許す」と「公称値を0.1に固定する」は異なる。公称ベンチマークは0、別の感度計算で符号や組合せを含めて0.1まで考慮する。

## 3. 組み合わせ数

物理順序を固定し、隣接する `N−1` 個の位置で強結合する／しないを選べば、`2^(N−1)` 種類。強結合数 `m` ごとのマスク数は `C(N−1,m)`。

| チップL数N | 強結合数最大 | 固定順序での強結合マスク数 | 備考 |
|---:|---:|---:|---|
| 1 | 0 | 1 | |
| 2 | 1 | 2 | |
| 3 | 2 | 4 | L1–L2とL2–L3を同時に強結合可 |
| 4 | 3 | 8 | |
| 5 | 4 | 16 | |
| 6 | 5 | 32 | 6チップの無ラベル連結群形状は11種類 |
| 7 | 6 | 64 | LQP01混載など |
| 8 | 7 | 128 | LQP01混載など |
| 9 | 8 | 256 | **全LQP01（面積2/3×9=6）なら面積上限6に収まる**。実際のL値・SRFは未確認 |

面積6はチップLの数6を意味しない。**LQP01 9個の構成も数学的にはコスト6内**であり、組合せ列挙をチップ数6で打ち切らない。ただしGJM01固定Cを使う場合は利用可能面積が減る。

6チップで強結合マスク数は `1,5,10,10,5,1`（m=0～5）、ラベルを無視した連結群の形状数は11。回路上のインダクタL値・枝電流が異なる場合、同じグループ形状でも物理配置への素子割り当てを別に検討する。

## 4. モデル損失・先行ILの取り扱い

6個の同一LQP02を同方向に**電気的にも直列接続**し、隣接5ペアが `k=+0.4`、非強結合10ペアが `k=0` と仮定すると、独立ESRモデルで

`L_eq = 6*L + 2*(5*0.4*L) = 10L`

`R_eq = 6*omega*L/25`

`Q_eq = 25*(1 + 2*5*0.4/6) = 41.6667`

となる。以前の限定的な整合のみの数値探索では、**6チップで最大IL約0.11710dB**。これは今回の単列配置に整合する条件下での保存済み代表探索値だが、**実配置で隣接5ペアのk=0.4達成が確定したわけではない**。

6チップの全15ペアを `k=+0.4` とした `IL=0.07988dB` は、**今回の正式な単列配置モデルには不適合**なので「理論上の参考値」にのみ残す。主2ペアだけ0.4・残り13ペア0.16という旧比較も、弱結合0.1の新仕様から外れるため参考値扱いにする。

磁気結合と抵抗損失は独立巻線Qの一定値近似であり、配置による近接効果・相互抵抗・SRF・寄生C・電力／温度依存・同時実現性は未評価。インダクタに異なる電流が流れる一般LPFではこの等価Qの式を流用せず、結合MNAで評価する。

## 5. 推奨する今後の比較

1. **公称・非強結合0**：物理順序と強結合マスクを変えた最良候補を、面積0～6で比較する。強結合可能ペア数0～N−1を明記。
2. **弱結合の感度**：同じ回路値で非強結合ペアの `|k|<=0.1` を評価。さらに必要なら、同じ制約下で容量再調整時の改善幅も区別して記録する。
3. **非同一L/Qの配置最適化**：LQP01(Q15)／LQP02(Q25)／LQW04（Q未合意）の順序、部品L値、強結合グループ構成を探索する。LQW04 Qの未確定に留意。
4. **固定GJM01とPCB-Lの組み合わせ**：既存の面積・本数・結合ルールを全て守り、コスト–ILフロンティアを更新する。
5. 減衰条件を戻す場合もPhase 2内で35dB公称探索を行い、**Phase 3の離散スイッチドC設計は停止のまま**。
