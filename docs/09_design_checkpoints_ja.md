# これまでの回路構成チェックポイント（2026-10-10）

**目的:** 途中で採用・比較基準とした回路を、実装候補と理論限界探索案を混同せずに保存する。数値はすべて**公称・集中定数・有限Qモデル上の局所探索解**であり、大域最適性、実部品の実測値、EM妥当性または公差最悪値ではない。

## 比較条件と読み方

- 6設定 = B71 / B12 / B28 / B13+B14（1設定）/ B26 / B8。通過域は各ULとDL、阻止域はULの2倍と3倍の全帯域。
- 入力50Ω、負荷60−j40Ω（周波数一定）。ILは利用可能入力電力に対する負荷受電力で算出。
- **現行比較基準:** chip-L Q25、PCB-L Q12、C Q80。chip-chipは主結合2組 |k|≤0.25、副結合4組 |k|≤0.16。chip–PCBは |k|≤0.03。PCB–PCBは受動性制約下で理論探索。固定Lと全結合は6設定共通、Cは設定ごとの理想連続値。
- **必須仕様:** H2/H3 30dB以上。**当面の公称比較目標:** 35dB以上。30/33/35dBを混同しない。比較不能な古い探索は「歴史的参考」と明記する。
- **面積:** chip-LはLQP02×4単位以内（LQW04は3単位換算）。PCB-Lは部品面積に算入しないが、実配線・ビア・寄生がゼロになるわけではない。
- 表中の≈はアーカイブ・会話時点の丸め値。保存された最終解のCSV/JSONにある場合はそちらを正とする。

## 回路構造の基本形と進化

### CP07：最初に実装性を評価すべき基準構成

```text
IN──[L1∥C1]──n1──[L4∥C4]──n2──[L3∥C3]──OUT
                              |
                             L2
                              |
                             C2
                              |
                             GND
```

4個のチップLを用い、全チップL間の許容相互結合を回路方程式に含める。CP09/10はこの基本形に、Q12のPCB-LとCによる枝を追加する。

### CP09：PCB-Lを3つの役割へ分配

- PCB-L5–C5：n1からGND（シャント整合）
- PCB-L6–C6：n2からOUT（L3∥C3と並列の補助経路）
- PCB-L7–C7：INからn2（L1/L4を迂回するブリッジ）
- PCB-L同士の磁気結合=0、chip–PCBは各 |k|≤0.03。**改善主体は整合で、B8・960MHzの内部素子損失はむしろ増えた**（当該レポート参照）。

### CP10：PCB-L間結合とブリッジ位置を再設計

- PCB-L5–C5：n1からGND、L6–C6：n2からOUT、L7–C7：n1からn2。
- PCB間 k56≈+0.093、k57≈−0.20、k67≈−0.20。chip–PCBは各 |k|≤0.03。モデルではチップL損失が減少する一方、Cと相互結合の感度が大きい。

### CP11：ほぼ完全結合した3PCB-Lの同極性直列回路（実装選定外）

3本のPCBコイル（各約0.708nH、各Q12）の理想相互結合により、同じ枝を流れる電流で合成リアクタンスを増加させる。理論モデルでは `k=0.98` のとき `Qeq=12(1+2k)≈35.52`。これは**メーカーQの引用ではなく理想結合からの計算値**。渦電流・近接効果・共通損失・寄生容量が入れば成立性が変わる。**PSD成立は形状・製造可能性を証明しない**。

## 設計上の判断と残課題

1. **現行の物理モデルでの「最良計算値」と「実装候補」を分離する。** CP11は最小ILでも理論候補にとどめる。
2. 約0.005dB未満の改善は、追加枝・結合管理・EM寄生の不確実性を含めて比較する。
3. CP07/09/10いずれにも、実チップQ(f)/SRF、PCB EM、製造公差、大信号、連続周波数保証が残る。
4. 量産条件を満たすと示せるまでは「実装可能」「量産適合」を宣言しない。
5. Phase 3（スイッチドC離散化）は所有者の明示承認まで停止。
