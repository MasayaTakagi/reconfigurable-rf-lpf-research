## 1. 回路・電流の定義

```
IN ---- L1 ---- o ---- L2 ---- OUT
                 |
                 L3
                 |
                GND
```

L1の電流 I1 は左→中央、L2の I2 は中央→右、L3の I3 は中央→GND。
キルヒホッフ則: **I1 = I2 + I3**。相互インダクタンスは符号付き Mij = kij sqrt(Li Lj) と定義し、電流の参照向きとドット極性に整合すること。

各コイル群について複素実効値表示とすると、Z_L = R + jω L（R、Lは実対称行列）、Q_L,mode = Im(I† Z_L I) / Re(I† Z_L I) = ω I† L I / (I† R I)。これはコイル群全体の誘導性無効電力／散逸電力であり、各コイル単独の intrinsic Q や、コンデンサ・負荷を含めた回路の loaded Q と同一ではない。

基本近似は R = diag(ω Li/Qi)（相互抵抗0）。RF実装では相互抵抗、寄生容量、周波数分散等を追加検証する。

L行列の正定値性、および受動性 R>=0 を必須とする。正規化3×3結合行列について det K = 1 + 2 k12 k13 k23 - k12² - k13² - k23² >0（さらに主要小行列正定値）が必要。例えば k12=k13=+0.6、k23=-0.6 は不正定である。

## 2. 等L・等Qの厳密解析

L1=L2=L3=L、Q1=Q2=Q3=Q0、β=I3/I1（複素数）を置くと電流は I=I1[1,1-β,β]^T。

D = 1 + |1-β|² + |β|²

Q_mode/Q0 = 1 + {2[k12 Re(1-β) + k13 Re β + k23 Re((1-β)* β)]}/D。

- **k13だけを正に結合**: Q_mode/Q0 = 1 + 2 k13 Reβ / D。最大は β=1（I2=0）で 1+k13。これは実効Q最大のとき出力通過電流が0となることを示す。従って伝送回路の最適動作点とは限らない。
- **k13=k23=k>0、k12=0**: 実βで Q_mode/Q0 = 1 + k(2β-β²)/(1-β+β²)。最大は β=√3−1≈0.732、Q_mode/Q0=1+(2/√3)k。単一シリーズ–シャント結合より高くできるが、理想電流モードにすぎない。
- **3組とも kij=k>0**: 最大は β=1/2、Q_mode/Q0=1+(5/3)k。両シリーズLの通過電流とシャント電流が同相、かつ I2=I3=I1/2 のモードに対応。この結合行列は 0<k<1 で正定値（固有値 1−k, 1−k, 1+2k）。

Q0=25、k=0.4、β=1/2（実数）での理論比較:
| 有効な磁気結合 | Q_mode | 備考 |
|---|---:|---|
| なし | 25.000 | 基準 |
| L1–L3のみ | 31.667 | 1.2667倍 |
| L1–L3とL2–L3 | 35.000 | 1.4倍 |
| 全3組 | 41.667 | 1.6667倍、K最小固有値0.6 |

電流が直交する Re(I1* I3)=0 の場合、k13単独の寄与は0。符号が反対なら改善ではなく低下。望ましいk符号は参照電流の位相とドット極性による。

k13のみ、k=0.4の別の電流条件:
| β | Q_mode |
|---|---:|
| 0.1（同相） | 26.099 |
| 0.25（同相） | 28.077 |
| 0.5（同相） | 31.667 |
| 0.5∠−60° | 27.500 |
| 0.5∠−90° | 25.000 |
| 1（同相） | 35.000 |

## 3. 混合Qと結合損失の条件

I1=I3、I2=0、L1=L3=L、Q1=Qh、Q3=Ql では

Q_mode = 2(1+k) / (1/Qh + 1/Ql)。

高Qコイル1本のQhより高くする条件は k > (Qh/Ql−1)/2。例: Qh=25、Ql=12 なら k>0.5417 が必要。k=0.4 では Q_mode≈22.703 であり、低Qシャントを流せば常に得するわけではない。

さらに同L・同Rの2コイルで複素インピーダンス行列に相互抵抗 R13=rR が存在し、I1=I3、I2=0 の場合:
Q_mode/Q0 = (1+k)/(1+r)。
追加のAC抵抗結合が正で r>=k なら理想磁気結合で得られたQ優位は失われる（他の損失が変わらない近似）。基板渦電流・近接効果・負荷効果を無視した「kだけ」の最適化は危険。

「同一の実効インダクタンスと同じ電流」を比較するため、等L等Qの完全同相2コイルの自己Lを目標L_effに合わせて縮小でき、Q0一定という強い仮定の下では、等価抵抗が無結合時の 1/(1+k) になる。k=0.4なら約28.6%減。**自己L、面積、Q(f)、実装可能kの同時変化を考慮した実証値ではない。**

## 4. 実際のT二端子回路としての検査

端子電流を [Iin,Iout]^T（IoutはOUT端子から回路内部へ流入する向き）と定義すれば

I=[I1,I2,I3]^T = B [Iin,Iout]^T、
B = [[1,0],[0,-1],[1,1]]。

Z_port = B^T (R+jωL) B。

純3L Tの例を計算した。各単体Qi=25、50Ω源・50Ω実抵抗負荷、X1=X2=10Ω、X3を変更、k13のみ0→+0.4、他の結合なし、寄生なし。各枝抵抗は Ri=Xi/25とした。挿入損失IL = -10log10(Pload/Pavailable)。数値は周波数非依存の**正規化リアクタンス条件に対する単一点の算術例**であり、実装RF特性ではない。

| X3 | k13 | Q_mode | IL (dB) |
|---:|---:|---:|---:|
| 10Ω | 0 | 25.00 | 9.677 |
| 10Ω | 0.4 | 34.32 | 7.410 |
| 50Ω | 0 | 25.00 | 2.008 |
| 50Ω | 0.4 | 30.37 | 1.682 |
| 200Ω | 0 | 25.00 | 0.557 |
| 200Ω | 0.4 | 25.78 | 0.518 |

比較の論点: 高いQ_modeが最良ILを意味しない。X3=10Ωでは強いシャント電流でQ_modeが高いが、入力反射・バイパスによりILが非常に大きい。一方X3=200Ωではシャント電流を小さくしてILは低いが、磁気Q増加が小さい。k変更自体がリアクタンス・反射を変えるため、同じ整合制約を課した比較ではない。

このうち X3=50Ω, k13=0.4 の条件で、B^T Z Bを用いる2×2二ポート解と、3ノード＋3インダクタ電流の6×6独立MNAが同じ負荷電力(約0.00339459913W、Vs=1Vrms)を与えることを確認。電力収支残差は絶対値で約1.7e−18W。全条件・周波数への独立検証の完了を意味しない。

## 5. 今後の系統的なPhase 2研究仮説（未実行）

1. まず最大Q_mode（回路理論の上限）と、所定の伝送・インピーダンス変換を維持する最小内部抵抗・最大GT（回路の有用性）を別の目的関数として扱う。
2. 電流比β、位相、L3/L1、L2/L1、kijの符号と三体結合を掃引する。最小固有値>0、R行列の半正定値性を必須とする。
3. 同一Z_portターゲット、同一帯域/通過特性、同一素子技術・配置・コストで比較し、磁気結合がL増加のみでなく**本当に損失低減に寄与したか**を判定する。
4. 相互抵抗、Q(f)、SRF、寄生容量、EMで抽出したk(f)を使った再検証を後段に設ける。
5. 新しい体系的計算runは、main中央台帳で新規EXP番号の予約と照合PASSを済ませてから開始する。今回のこの文書は研究ノートであり、未予約のEXP番号を名乗らない。
