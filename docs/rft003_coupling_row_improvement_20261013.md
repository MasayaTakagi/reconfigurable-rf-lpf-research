# RF-T003：結合配列変更による5L損失改善（2026-10-13、Phase 2）

**研究状態：252局所最適化実行済み。5L新候補は7,001点/個別区間＋84点独立10×10 MNA検証済み。未完了項目と正式RF条件は分離。** `main`の取得基準コミット：`dae9377d9053b9ca0193465f7d537df6c211b004`。**正式条件RF-F001は変更しない。** この結果は**RF-T003試験（対GND可変C 1本＋L3並列非GNDブリッジ可変C 1本、H2/H3 ≥30dB）に限定**。Phase 3未承認。

## 実行した仮説比較と探索数

前回[損失解析](rft003_loss_analysis_20261012.md)では、4LのIL≈0.376495dBのB28/803MHzでL3損失が0.1811mW、5Lへの拡張（[既存結果](rft003_5l_low_loss_study_20261013.md)）でIL≈0.361231dB、L3損失≈0.1376mWとなった。今回は**5Lで追加インダクタL4=(1,5)を維持し、どの隣接チップL同士を磁気結合させるか**を主要設計自由度に設定。固定素子は全6設定共通、可変Cのみ各設定独立。

| 実際に実行した比較 | 構造数・計算数 | 結果 |
|---|---:|---|
| 5Lの接続変更・部分配列変更 | 21系列×2 = **42局所開始** | 有望配列L1–L4–L2–L3–L0発見 |
| 元5L配列に固定GJM/PCB-C追加 | 18系列×2 = **36開始** | 新最良を更新せず |
| 新しい配列でGJM/PCB-C追加 | 18系列×2 = **36開始** | GJMを同一端点(1,2)に重複並列した微小IL差は数値的実質同等。面積費増のため最良とみなさない |
| 新配列で既存GJM移動・非GNDブリッジ位置変更 | 11系列×2 = **22開始** | 更新せず。未収束・30dB未達試行を原始ログに保持 |
| 5Lの一列物理順 **60通り**（反転等価の120通りから半減） | **60開始** | 最良は逆順等価L0–L3–L2–L4–L1でIL≈0.348357dB、差4μdBであり有意な更新ではない |
| L5追加（計6L）で8接続×2物理順 | 16系列×2 = **32開始** | 有効解の最良IL≈0.357481dB、**面積7⅓**。今回の5L・6⅓に支配される |
| 対GND可変Cの端点を4候補へ移す | 4系列×4 = **16開始** | 全部0.348361dBに届かず |
| 減衰余裕・結合係数感度 | 4条件×2 = **8開始** | 7,001点/区間＋84点独立MNAで確認 |
| **合計** | **252局所開始** | 有限非凸探索。大域最適性や物理可否の証明ではない |

解析ヤコビアン付きSLSQP・epigraph minimax。6設定×個別28周波数区間で初期13～23点/区間を用い、選抜解を301→7,001点/区間で精査した。重要：**60行の列挙は特定電子回路グラフにおけるチップ物理一列順の有限網羅であって、回路トポロジー全体の完全探索ではない。** 原始計算スクリプト・全試行結果はユーザーへZIPで提供し、GitHubには厳密な独立再計算器を追加。実行した元最適化コードのコミットSHAはないので完全公式実験manifestとしては未登録。

| 再最適化の条件（通常のRF-T003とは別の計算設定） | 7,001点最大IL | 最小UL H2/H3 |
|---|---:|---:|
| 通常：30dB、k≤0.4 | **0.348361dB** | 30.002980dB |
| 探索目標30.103dB | **0.350122dB** | 30.102992dB |
| 探索目標30.303dB | **0.353682dB** | 30.302991dB |

これらの余裕は公差ロバスト保証ではなく、**代替名目制約の有限局所解**。特にk境界依存性が大きい。正式IL≤0.30dB目標までなお**0.048361dB**不足。RF-F001の35dB公称減衰や2対GND配置に不適合、試験RF-T003の成果のみ。
