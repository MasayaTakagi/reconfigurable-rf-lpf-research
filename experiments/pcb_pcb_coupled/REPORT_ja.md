# PCB-L間相互結合の導入結果（2026-10-10）

- 6ケース：B71、B12、B28、B13＋14、B26、B8。UL＋DL通過、ULのH2/H3全域で35dB以上を目標。
- チップLは4個/Q25、PCB-Lは3個/各≤3nH/Q12、Cは7個/Q80。チップ–PCB結合は±0.03以下。
- チップ間は主結合2組±0.25、副結合4組±0.16。PCB-L間は0～±0.30の感度試験。
- Qと負荷、最適化方式は前回と同じ。PCB-L間結合もインダクタンス行列に組み込み、その最小固有値が正であることを確認。
- 最良の確認済み候補：PCB-L5を節点1–GND、PCB-L6を節点2–出力、PCB-L7を節点1–節点2に接続。
- PCB-L間の主結合を利用してILは0.3234dB程度（結合上限0.20、35.05dB目標）。
- 結合なしの場合には、異なる枝配置の効果が出にくく、約0.3272dBだった。
- PCB-L間結合0.30を許可しても0.3233dB程度と追加効果は小さい。
- 0.30dB以下には未達であり、35dB公称減衰を緩和しない限り、既存構成へのPCB-L間結合だけでは大幅改善が見られない。
- 結果は局所的な数値最適化・0.02MHz刻みの周波数再検証であり、数学的な大域最適性証明や実装検証ではない。
- Phase 3は停止。
