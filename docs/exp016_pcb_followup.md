# EXP-016：PCB-Cの正式Q40モデルによる継続探索（2026-10-12、Phase 2）

**ステータス：探索実行済み・正式実験マニフェスト未登録・PRレビュー待ち。** `main=f08ad3f0d9ed492566f07020543fdc89efefcfe4`、正式制約ID `RF-F001`、実効制約SHA256 `df6b4cbd347aac06538527cd68963b785207582152e17117a683c10058af0c54`。

## 誤解の修正：GJM01とPCB-Cは別部品

正式`RF-F001`では、**PCBパターン固定C：0.02–0.20pF、Q40、最大3個、チップ面積コスト0**。**GJM01固定C：Q80、各100pF以下、チップ面積コスト2/3、正式下限の定義なし**。従来EXP-016初回最良の0.020pFの`Cf0`は**GJM01 Q80**として最適化されており、PCB-C Q40ではなかった。0.10pFというGJM下限は正式制約ではなく、比較用の任意計算条件にすぎない。

追加探索は素子種別とQを区別し、固定・結合・可変枝の条件を変えず、固定L/C/kと6設定の2対GND可変Cを**共同再最適化**した。GJM下限は計算探索区間として0.02pFを使ったが、これを正式仕様へ追加するものではない。

**主な発見：**
1. 初回0.020pF GJM `Cf0`をPCB-Cへ一対一置換するだけではILは改善しない。**削除＋回路全体再最適化**は改善した。
2. `Cf2`の固定GJM（5–GND）は`Cv1`のIC可変C（同じ5–GND）と**同一Q80の並列関係**。この理想一定Qモデルでは`Cf2+Cv1(setting)`へ厳密吸収でき、全6設定で0–4pF内。48組の独立MNA比較で最大IL差 **7.11×10⁻14dB**。GJM1個分の面積コスト2/3を削減する。**この等価縮約はQや端点の異なるPCB-Cには適用しない。**
3. **L0並列（1–2）のPCB-C 0.200pF/Q40**を導入して全素子を再最適化した結果、現時点の名目最良は0.507981459dB、面積4⅔。0.20pFは許容上限に接し、実際の寄生/基板面積・ばらつき評価が必要。
