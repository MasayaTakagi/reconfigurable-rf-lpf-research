# EXP-012 — EXP011のチップ面積最小化・IC可変C 3→2枝探索（Phase 2）

**2026-10-12、現在の結論：IL≤0.30 dB、UL H2/H3≥30 dBの全条件を維持できた最小の保存済み候補は引き続き[EXP011-01](../EXP-011/EXP011-01.json)、面積コスト4⅔、可変C3枝。** 本実験は減素子／可変枝削減での再最適化を行ったが、条件をすべて満たすコスト4⅓以下または可変C2枝の新候補は未発見。**これは局所探索の結果であり、これらのコスト域が不可能・理論限界とは断定しない。**

## 制約・評価方法

- 信号源50Ω、負荷60−j40Ω（周波数一定）。B71、B12、B28、B13+B14共通、B26、B8の6設定、UL/DL全周波数の最大IL≤0.30 dB。各ULの2倍波／3倍波全帯域の最小減衰≥30 dB。
- チップ面積換算はLQP02=1、LQP01=2/3、GJM01=2/3、PCB固定C=0。IC可変Cはチップ面積換算に含めない（実IC面積ゼロという意味ではない）。
- Q(LQP02)=25、Q(LQP01)=15、Q(GJM/IC)=80、Q(PCB固定C)=40。周波数一定、寄生なし、集中定数モデル。
- 物理的に一直線のチップL、強結合は隣接のみ|k|≤0.4、全K正定値。6設定のL/C固定値とkは共通、可変Cのみ設定別。0～4 pF／枝。
- 30 dB最小減衰、非GNDを含む3可変Cは承認済み**Phase 2実験緩和**。正式の2対GND可変C・公称35 dB結果LPF-007は変更しない。
- LQP01の**必要L値に対応する製品レンジは未確認**。LQP01置換は数値試験としてのみ扱い、物理適合を確認した候補とは呼ばない。

### コスト4の新しい回路：C4-PCB-01（**性能未達**）

- 4Lの枝はEXP011と同じ L0=1–2、L1=3–4、L2=2–5、L3=2–3。
- **GJM固定Cをゼロ**にし、IC可変Cの第3枝を**node1–node3（入出力ブリッジ）**へ移設。Cv0=4–GND、Cv1=5–GND、Cv2=3–1。
- PCB固定C（Q40、0.020 pF）を**node4–node3（L1並列）**に設置。チップ面積換算は4で変わらない。約0.02 pFのPCB固定C実装可能性、実際の配線／EM／基板面積は未検証。
- 3可変Cを維持したまま0.30 dBとの差を0.004820 dBまで縮小。H2/H3の最小余裕は約0.00005 dBのみ。**実装候補と誤認しないこと**。
- GJMなしでPCB-CもなしのC4-00は、同じ可変枝でIL=0.305774 dB。PCB-C追加・共同再最適化はこの局所解群で0.000954 dBだけ改善した。PCB-C自身の単独因果効果ではない。

### 2可変Cの現状：CV2-01（**性能未達**）

- 同じ4Lと1GJM（L0並列）を保持し、第3可変Cを取り除き、Cv0=4–GND、Cv1=5–GNDの2本のみとして、L/C/kと6設定×2容量値を再最適化。
- 成立した局所解の最良はIL=0.411054 dB、H2/H3≥30.002 dB、**目標の0.30 dBから0.111054 dB超過**。
- この結果は「2可変Cで0.30 dBが不可能」という意味ではない。全回路トポロジーの大域探索や多数の固定GJM配置／多初期値が未実行。
