# Phase 2 基礎理論追補：T型シャントL大電流を通過帯域で許容する整合位相設計（2026-10-16）

## 状態・出典・境界

先行追補 `docs/phase2_t_shunt_high_current_modes_20261016.md` の派生。**解析的に定数を決めた限定的な1GHz通過／2GHzノッチの決定論的ベンチは実行済み**。新規EXP番号を使用する最適化runではない。Q(f)、SRF、導体近接効果、相互抵抗、C損失、実装EM・公差、LTE/RF-F003全帯域は**未実行**。正式RF-F003に適合した成果ではない。Phase 2を維持し、Phase 3未承認のまま。

## 1. 核心：通過電流を保ったままシャント電流を大きくできる

T構造のL1,L2シリーズ、L3+C3直列シャント。結合M13=+M、M23=−M、M12=0。L3の実効値は \(L_{3,\mathrm{eq}}=L_3+2M\)。この等価値を固定し物理L3だけを減らすと、**同じ無損失インピーダンス行列**でもシャント抵抗を低減できる。

無損失の50Ω-50Ω対称Tを、左右直列インピーダンス \(jX\)、中央シャントインピーダンス \(-jY\) とする。整合条件は
\[
Y=\frac{R_0^2+X^2}{2X},\qquad R_0=50\Omega.
\]
整合時の出力電流は
\[
I_2/I_1=e^{-j\theta},\quad \theta=2\arctan(X/R_0),
\quad |I_3/I_1|=2X/\sqrt{R_0^2+X^2}.
\]
（枝電流はI1が入力→中央、I2が中央→出力、I3が中央→GNDの方向。）とくに \(X=R_0\) なら \(\theta=\pi/2\)、\(I_2=-jI_1\)、\(I_3=(1+j)I_1\)。すなわち**出力へ入力と同じ振幅の電流を通しながら、シャントLには入力の√2倍の電流を流せる**。これは抵抗へ流出する電力を失う短絡ではなく、リアクティブな電流の位相交換。通常の同相I3≈I1, I2≈0という「ノッチ電流」と区別する。

ただしXを大きくすればθと|I3/I1|を増やせる一方、L1=L2=X/ωと定Q抵抗 \(R_i=X/Q_0\) も大きくなるため、**循環電流比の最大化はIL最小化ではない**。

## 2. 1GHz通過整合と2GHzノッチを両立する回路定数

fpass=1GHz、fnotch=2GHz、R0=50Ω、X=Y=50Ωとした。直列L1=L2=R0/(2πfpass)=7.9577471546nH。シャント枝は通過時−j50Ω、2GHzで直列LC共振という2条件から
\[
L_{3,\rm eq}=\frac{Y}{\omega_p[(f_z/f_p)^2-1]}=
2.6525823849{\rm nH},\quad
C_3=1/[(2π f_z)^2 L_{3,\rm eq}]=2.3873241464{\rm pF}.
\]
各Lの単体Q0=25一定、C理想、相互R=0、50Ω信号源/負荷、Vs=1Vrms。結合kを左右それぞれ(+k,−k)とし、各ケースの物理L3を
\[
L_3=(\sqrt{L_{3,\rm eq}+k^2 L_1}-k\sqrt{L_1})^2,\quad
M=k\sqrt{L_1L_3}
\]
で再合成する。L1,L2,C3は固定。これにより**無損失2ポートのインピーダンス・整合・理想零点は全ケース一致**。磁気行列SPD、3ノード節点法と独立6×6 MNAの複素枝電流一致、利用可能電力収支を照合した。

1GHzのシャントL散逸は無結合0.124740mW、k=.1で0.089058mW、k=.4で0.034883mW。シリーズL2本の散逸は依然合計約0.38mWで支配的。合計L散逸は0.504010→0.469786→0.417804mW、伝達電力は4.495→4.530→4.582mW。2GHzではシャントI3≈8.70/8.73/8.77mA、出力電流は約0.102/0.0726/0.0282mAで、ここではノッチ電流になっている。

**結果:** 「シャント大電流なら必ず出力電流が減る」は誤り。シャント電流を出力と位相差90°の無効電流とするT型整合なら、通過を保ったまま磁気強化を利用できる。

**限界:** これは1GHzの50Ω整合と2GHz一点の減衰を合わせた、*指定定数の限定ベンチ*。周波数帯域全体の優劣、他k符号、公差、実装可能性を示していない。k=.4は現行RF-F003の結合制約を逸脱、k=.1をそのままRF-F003適合と解釈しない。L3=0.728nHでQ25を維持する仮定や、Lsとのk=.4×2を同時に実装できることも未確認。

## 3. 「強いシャントL」を有利にする観点

- 位相：シャントI3をI1とほぼ同相の短絡電流として増やすのではなく、I1/I2に約90°程度の位相差を生み、同一送信電力でI3を増やす。
- インダクタンス比：同じkでも相互インダクタンスの大きさは \(M=k\sqrt{L_\mathrm{series}L_3}\)。通過帯域でシリーズLが小さすぎるとシャントLへの強化効果が弱い。ただし大きいL1/L2は銅損を増加させる。
- ノッチ設計：C3を選んで通過帯域では容量性の整合リアクタンスを与え、阻止したい別の周波数でL3とシリーズ共振させる。
- 磁気設計：2組の符号M13=+M/M23=−M、第三組M12≈0、結合絶対値を揃える。各LのQ(f)と相互抵抗が変わると改善は保証されない。
- より高度な構成：並列LC内の大循環電流は外部正味シャント電流を小さくできるが、2組結合の相互磁気Q効果が自己共振点で相殺されることがある（前ノート）。目的が損失最小ならモードQと実際のI²Rを別々に評価する。

## 再現性

会話環境の`t_matched_large_shunt_mode.py`は3ノード縮約法と独立6×6枝電流MNAで同一点を照合。旧ノート`docs/phase2_t_two_pair_coupling_20261016.md`の理論と比較する場合、**シャント直列C有無・固定リアクタンス条件・周波数**を混同しない。
