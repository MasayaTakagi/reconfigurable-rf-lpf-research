# 設計仕様・制約（2026-10-10 時点）

## システム機能

1つの共通RFネットワークを、6つのバンド設定で動作させる。固定Lとその相互結合は全設定共通。設定ごとに可変Cの容量値を変更する。B13+B14は同一の容量設定で両バンドをカバーする。**現段階のCは連続理想値**であり、スイッチドCの離散化はPhase 3でユーザー承認を受けた後のみ着手可能。

| 設定 | UL [MHz] | DL [MHz] | H2 (UL×2) [MHz] | H3 (UL×3) [MHz] |
|---|---|---|---|---|
| B71 | 663–698 | 617–652 | 1326–1396 | 1989–2094 |
| B12 | 699–716 | 729–746 | 1398–1432 | 2097–2148 |
| B28 | 703–748 | 758–803 | 1406–1496 | 2109–2244 |
| B13+B14 | 777–787, 788–798 | 746–756, 758–768 | 1554–1574, 1576–1596 | 2331–2361, 2364–2394 |
| B26 | 814–849 | 859–894 | 1628–1698 | 2442–2547 |
| B8 | 880–915 | 925–960 | 1760–1830 | 2640–2745 |

機械可読な定義：[`../data/bands.csv`](../data/bands.csv)。B13+B14については不連続な帯域を一続きに補間してはならない。LTE帯域の参照規格は3GPP TS 36.101等。新規実装前にその最新版との照合が必要。

## 目的関数（現行Phase 2）

- 最小化するのは **6ケース、各UL/DLすべての通過帯域における最大挿入損失**。
- 必須阻止：各ケースULの2倍波と3倍波の **全域で30dB以上**。
- 探索公称阻止の目標は35dB（スクリプトによって35.05 / 35.10 / 35.15dBの丸め余裕がある。比較表には実値を示す）。
- 新しい公称最大ILの挑戦目標は0.30dB以下。未達時にも未達を報告し、不適合解を性能比較から除外する。

## 回路・部品モデル

| 項目 | 現行モデル | 未確定事項 |
|---|---|---|
| 信号源 | 抵抗50Ω | 非理想PAの出力インピーダンス |
| 負荷 | 60−j40Ω・周波数一定 | 実負荷の周波数・電力・温度依存 |
| LQP02HV相当chip-L | Q=25定数 | 実Q(f), SRF, ESR, ばらつき |
| 内層PCB-L | Q=12定数、1本あたり概ね3nH以下 | PCBスタックアップ・配線・結合・ビア |
| C | Q=80定数、最適化で主に0.1～100pF | 固定PCB容量か可変バンクか、寄生と電圧耐量 |
| chip-chip結合 | 主結合2組 |k|≤0.25、残り4組 |k|≤0.16 | どの組が実装できるか |
| chip–PCB結合 | すべて |k|≤0.03 | 実装公差 |
| PCB–PCB結合 | 理論上は物理上限を置かず、正定値条件のみ | **k≈0.98の実現可能性は不明** |
| 電力 | >23dBmを想定 | 最大値、CW/変調波、負荷VSWR、電流・ピーク電圧 |

**面積換算:** LQP02=1単位、LQW04=3単位、内層PCB-L=0単位。チップLの総面積は4単位以内。LQW04採用は単なるQ改善だけで判断せず、LQP02減数／PCB-L代替と組み合わせて考える。内層PCB-Lに面積予算を割り当てないことは、配線・ビア・寄生が存在しないという意味ではない。

## 設計上の除外事項

- Murataが公開した公称Qをそのまま回路Qの代用にしない（ユーザー決定）。
- 量産公差込み最大IL、最悪条件高調波抑圧、EM設計、部品定格、大信号非線形はPhase 2の現行結果では保証していない。
- コイル間の結合行列を正定値にすることは必要条件であり、現実の磁界配置の十分条件ではない。
- **Phase 3には進まない。**
