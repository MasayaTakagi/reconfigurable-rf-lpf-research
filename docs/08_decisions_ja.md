# 主要設計判断（2026-10-10時点）

**新仕様の正本：** [部品・コスト・トポロジー定義](11_component_cost_topology_rules_ja.md)。過去の探索結果は新仕様への適合を再検証する。

| 判断 | 現行合意 | 注意点 |
|---|---|---|
| バンド | B71, B12, B28, B13+B14, B26, B8 | B13+B14は1コード |
| 通過域 | 各設定のULとDL | 全600～960MHzを一律の通過域にはしない |
| 減衰域 | 各ULのH2/H3全域 | DLの高調波仕様ではない |
| 高調波減衰 | 最低30dB、Phase 2では公称35dBを主比較 | 公称35を最終量産保証と混同しない |
| 最大IL探索目標 | 0.30dB以下 | 公称、6設定で最大を評価 |
| 出力インピーダンス | 60−j40Ω周波数一定 | 確定した仮定 |
| 部品Q | LQP02=25、LQP01=15、PCB-L=12、固定GJM01/IC可変C=80（暫定） | LQW04のQは未合意、メーカー公称値の無断代用なし |
| チップ面積コスト | LQP02=1、LQP01=2/3、LQW04=3、GJM01=2/3、PCB-LとIC可変Cは0 | **新探索の上限6単位**。部品点数とIC/PCB資源は別記 |
| PCB-L個数 | **原則3本以下** | 各おおむね3nH以下。4本目以降は個別承認 |
| GJM01固定チップC | 個数の一律上限なし、1個100pF以下、全6設定で容量固定 | 直列・シャント許可。実装面積に加算 |
| IC可変C | **原則2枝以下、各枝の可変容量合計0～4pF** | **対GNDのみ**。直列は別途承認。固定Cとの並列は許可 |
| 整合のみの限界探索 | H2/H3減衰制約は一時的に除外 | 6設定の全UL/DLで最悪ILを評価し、従来の減衰付き探索と区別 |
| chip-chip結合 | 主結合2組≤0.25、他≤0.16 | 符号を考慮 |
| chip-PCB結合 | ≤0.03 | 強結合は使わない |
| PCB-PCB結合 | **原則|k|≤0.6、全結合行列は正定値** | 旧k≈0.98は例外的理論参考値であり新基準に不適合 |
| 大信号 | 23dBm超を想定 | 最大値・VSWR・温度は未確定 |
| Phase 3 | **停止** | 明示的な承認が必要 |
| 最良性 | 証明を目指す | まだ大域下界・網羅性なし |
