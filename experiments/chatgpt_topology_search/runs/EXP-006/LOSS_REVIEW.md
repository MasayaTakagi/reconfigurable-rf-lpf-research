# 面積予算7・35dB研究 (A7-04) — 候補別損失分解 (2026-10-12)

## 分析方法・注意事項

すべて6設定のUL/DL各周波数区間7,001点を計算し、各設定・全体の最大IL点を抽出した。最悪周波数の9×9独立枝電流MNAを解いて、50Ω源の利用可能電力5mWを入力反射・L損失・C損失・負荷伝達に分解した。
全体IL = **反射によるdB損失 + 回路内部散逸によるdB損失**。素子ごとのdBは後者を散逸電力比で割り振った**会計配分**であり、素子を削除・理想化した時の限界寄与でも微分感度でもない。
同じモデルの定Q25/80/40、50Ω源・60−j40Ω負荷を用いる。コストはIC/PCB実装面積を含まない。SLSQP未収束やEM/ばらつき未検証を解消する結果ではない。有限グリッド探索は周波数区間の厳密上界を証明しない。

## 候補別設計意図・損失内訳

### A7-04 — 面積上限7の実験
**回路設計の狙い（トポロジーからの技術的解釈）:** 2個対GND、4 L+4 GJMで面積6⅔。35dB境界に向けたA7-03同系の再最適化。 最適化結果だけから、素子別の改善因果を証明したわけではない。

- **制約:** {'LQP02': 4, 'GJM01': 4, 'PCB_PATTERN_C': 0, 'IC_VARIABLE_C': 2}, チップ面積 6.667, LQP02 Q25/GJM・可変C Q80/PCB固定C Q40（使用時）。高調波の判定閾値 35dB。
- **RF:** 6設定最悪IL **0.506950759dB**、H2最小 **35.001995dB**、H3最小 **35.002000dB**。減衰余裕 **0.001995dB**。
- **最悪IL点:** B8 DL **960.00000MHz**。電力収支残差 **-5.421e-19W**、結合係数行列の最小固有値 0.434310。
