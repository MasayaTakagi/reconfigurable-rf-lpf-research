# P4-A有限探索の対象クラス（RF-F001以降の現状）

P4-Aの**現行実装範囲**は、内部ノード最大4、固定枝最大8、チップ面積コスト最大6の**有限計算範囲**である。面積6はRF-F001の設計ハード上限ではなく、このジョブで扱うトポロジーセルの境界。コストが6を超える回路を「RF不適合」としてはならない。

- `matching_only`で6設定UL/DLの最悪ILを最小化。高調波H2/H3の減衰条件を最適化器には課していない。検証時のH2/H3報告は`full_lpf`成立を意味しない。
- 可変Cは現在IN/OUTの対GNDの2枝に限定され、内部ノードへの配置は未実装。したがってLPF-007等の内部トラップを含む全トポロジーの評価ではない。
- `LQP02`グラフ枝はHV（0.4～12 nH、Q25）だけを探索。正式仕様のHV上限27nHまでは網羅せず、HQ（Q20、0.2～56nH）は未探索。LQP01、PCB-L、GJM01の探索範囲もジョブ固有。
- PCBパターン固定Cは共通回路表現で対応するが、P4-A生成器の素子アルファベットにはまだ入っていない。
- `sample_graphs`はseed付き有限サンプリングであり、P4-Aの数学的網羅や連続素子値の大域最適性の証明ではない。
- GitHub Actionsの実行構成、チェックポイント、モデル・制約ハッシュが変わると旧Artifactは互換とみなさない。G1スモークのみが過去に完了しており、この変更後のスモークと大規模探索は別途実行・検証する。

## 今後の拡張ゲート

1. `src/lpf/`を基準に可変C配置を一般化し、LPF-007/008等のMNA回帰との一致を確かめる。
2. 正式LQP02HV/HQシリーズ別モデルをグラフ生成・目的関数・範囲定義へ導入する。
3. 面積コストの計算上限を実験マニフェストのパラメータに分離し、0～6、6～8などを同一RF条件で比較する。
4. H2/H3減衰条件を含む`full_lpf`探索と整合専用を分離し、計算の完了率・失敗・未実行数を記録してパレートを評価する。

これらは計画であり、新しい探索結果が既に出たことを示さない。Phase 2を維持し、Phase 3には進まない。
