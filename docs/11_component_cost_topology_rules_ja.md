# 部品・面積コスト・回路トポロジー制約（2026-10-10 合意）

> **適用範囲**：この文書は、2026-10-10に合意した**今後の探索に適用する新仕様**である。過去の実験結果はその時点の仮定に基づく履歴として残し、新仕様適合を未検証のまま主張しない。
>
> **開発状況**：Phase 2内のインピーダンス変換のみの損失限界・コスト–ILトレードオフ探索、および将来の減衰制約付き再評価に適用。Phase 3（離散スイッチドC実装）は明示承認まで**停止**。

## 1. 基本条件（変更なし）

- 6設定：B71 / B12 / B28 / B13+B14 / B26 / B8。各設定のULとDLを通過させ、B13+B14は**単一のC設定**を使う。帯域定義は `data/bands.csv`。
- 信号源：50 Ω（実数）。負荷：**60−j40 Ω**（周波数一定）。71 Ω∠−34°などの丸め値ではなく、この直交座標値を正本とする。
- 評価指標：50 Ω信号源の利用可能電力に対する負荷受電力 `GT = Pload / Pavs`、`IL = -10 log10(GT)`。各設定UL/DLの最大ILを最小化する。
- 将来の減衰制約付きPhase 2探索：ULのH2/H3全域に30 dB以上（必須）、公称35 dB以上（探索目標）。当面の**整合のみの限界探索ではH2/H3制約を外す**。結果を混同しない。
- 固定のL値、固定C値、インダクタの結合係数、接続トポロジーは全6設定共通。**IC可変C枝の容量設定だけ**を6設定ごとに変えられる。

## 2. 部品モデルと制限

| 要素 | 実装・型式 | モデルQ（一定） | 単体の値・数の制限 | チップ面積単位 | 扱い |
|---|---|---:|---|---:|---|
| チップL | LQP02系（LQP02HV相当） | 25 | 値の範囲は従来の候補探索条件に従う | 1 | 全設定で固定 |
| チップL | **LQP01シリーズ** | **15** | サイズはGJM01と同じ。L値の可用範囲は後日確認 | **2/3** | 全設定で固定 |
| チップL | LQW04系 | **未確定** | Qを任意に仮定しない | 3 | 全設定で固定 |
| チップ固定C | **GJM01シリーズ** | 80（当面の共通仮定） | **1個につき100 pF以下** | **2/3** | 全設定で固定 |
| IC可変C | IC内スイッチドキャパシタ | 80（Phase 2の暫定仮定） | **各独立可変枝の可変容量合計0〜4 pF**、**原則2枝まで** | チップ実装面積では0、IC資源は別途集計 | 設定ごとに可変 |
| 内層PCB-L | PCB配線で形成 | 12 | 1本おおむね3 nH以下、**原則3本まで** | チップ実装面積では0、PCB資源は別途集計 | 全設定で固定 |

Q=25/15/12/80は現段階の比較用モデルであり、製品仕様・周波数依存Q・SRF・ESR実測値を確約するものではない。GJM01およびIC可変Cは、現時点では同じQ=80を仮置きするが、将来は別モデルに分ける。LQW04のQ値は未合意なので、LQW04採用候補はQ値が確定するまで仮定を明示する。

### Cの配置規則

1. **GJM01固定C**：対GND（シャント）、直列、枝間などの受動回路内の配置を許容する。全設定で固定値。
2. **IC可変C**：**原則、片端をGNDに接続したシャント配置のみ**。信号経路に直列に置く構成は**事前の個別承認が必要**。未承認候補は通常の比較表から分離する。
3. **固定Cと可変Cの並列接続を許可**する。同一枝の総容量は固定成分と可変成分の和になってよい。固定Cの値は6設定共通、可変成分だけが設定ごとに変わる。
4. **4 pF制限は可変Cの1枝あたりの合計値**に適用する。同一枝に複数の可変素子を並列配置しても合計4 pF以下。物理的に同一の2端子間へ並列接続され、独立に使い分けられない可変要素は1枝として合算する。
5. **可変C枝は原則2枝以下**（ネットワーク全体で2つの独立したシャント位置）。各設定で部品を追加・撤去せず、2枝の容量値のみ更新可能。
6. 0 pFは探索上の理想開放状態。離散コード数、Ron、Coff、スイッチの非線形性等を実装評価するのはPhase 3であり、まだ行わない。

## 3. 面積コストと補助指標

LQP02実装面積を1単位とし、**面積に対する部品費用や実装費は現時点で同一視しない**。

```text
A_chip = N_LQP02 + (2/3)*N_LQP01 + 3*N_LQW04 + (2/3)*N_GJM01
N_chip = N_LQP02 + N_LQP01 + N_LQW04 + N_GJM01
N_PCB_L <= 3                 # 原則
N_variable_C_branches <= 2  # 原則
0 <= C_variable(branch,setting) <= 4 pF
```

- `A_chip`：チップ部品の占有面積換算値。**主要コスト軸**。
- `N_chip`：チップL・固定チップCの搭載点数（副次的なコスト指標）。
- `N_PCB_L`、`N_variable_C_branches`：面積コスト0でも必ず別軸で報告。PCB-Lの配線・ビア・専有領域、IC面積・制御線などが無料という意味ではない。
- **最新の面積上限は `A_chip <= 6` 単位（2026-10-10改定）。** 0〜6の複数の面積予算を掃引して最良ILを比較する。以前の「4単位以内」は現在の上限ではない。ただし、過去の「LQP02換算4単位以内」で得られた実験は、当時の条件として履歴に保持する。
- 例：LQP02×2 + LQP01×1 + GJM01×2 ⇒ `A_chip = 4`、`N_chip = 5`。IC可変C×2枝とPCB-L×3本は `A_chip` には加算しないが数量を必ず記録する。

## 4. インダクタの結合規則

- chip–chipの従来探索条件：指定した主結合2組は `|k|<=0.25`、その他は `|k|<=0.16`。混合したLQP01/LQP02等の**実際の物理結合可能性は未確認**。モデル上の許容範囲と実装成立性は分けて扱う。
- chip–PCBは全組 `|k|<=0.03`。
- **PCB–PCB結合は原則、各ペア `|k| <= 0.6`** とする。全インダクタンス行列の**正定値条件は別途必須**。旧研究の `k≈0.98` は歴史的な理論参考値であり、新しい標準探索の成立候補には混ぜない。0.6超を再探索する場合は例外として明示し、ユーザーの別途承認を受ける。結合の受動性は実際のPCBレイアウト・近接損失・寄生・実現可能性を保証しない。
- すべてのLを含む相互インダクタンス行列について正定値性と電力収支を検証する。

## 5. コスト–ILパレート探索の記録形式

同じ6設定の周波数集合と同じ負荷・Qを使用し、**`0 <= A_chip <= 6`** の複数の予算値ごとに最大ILを最小化して比較する。減衰制約を外した整合性能と、減衰制約ありのLPF性能を別のデータセットにする。

候補ごとに最低限、以下を保存する。

- `A_chip`、`N_chip`、LQP02/LQP01/LQW04/GJM01の各個数、PCB-L本数、IC可変C枝数。
- L/C値、結合係数、6設定のIC可変C容量、接続トポロジー、Q仮定、制約違反の有無。
- 6設定の最大IL、反射損失、チップL/PCB-L/Cの消費損失、各通過帯域の最悪周波数。
- 解の位置づけ（数値探索の成立候補／理論強結合候補／実装性確認済み）、コード版と検証グリッド。
- **旧条件（100 pFまで自由可変、C枝数無制限、全容量がスイッチドCと仮定など）の結果は、新仕様への適合を再検証するまで正式な新パレート点に混入しない。**

## 6. 例外・残課題

- PCB-Lの4本目、PCB–PCBの `|k|>0.6`、IC可変Cの3枝目、IC可変Cのシリーズ配置は**原則外**。現時点では標準設計として扱わず、ユーザーの別途承認を求める。
- LQP01/LQW04の利用可能なL値、実際のQ(f)とSRF、GJM01の実際のC値選択肢とQ(f)、IC可変CのQ・寄生・電力耐性、PCB-Lレイアウト面積は今後の検証事項。
- 現時点の部品単価・製造コスト・実装不良率・パッケージ寸法の詳細評価は未導入。面積換算はコストの代理指標である。
- **Phase 3は停止を維持**する。
