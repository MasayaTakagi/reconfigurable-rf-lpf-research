# 設計仕様 / Specification

**数値制約の唯一の機械可読な正本:** [`data/design_constraints.json`](../data/design_constraints.json)。この文書は説明であり、独立した制約値の正本ではない。

6設定（B71/B12/B28/B13+B14/B26/B8）のUL・DL全域で最大挿入損失を評価し、ULのH2/H3全域の最小減衰を確認する。周波数区間は [`data/bands.csv`](../data/bands.csv)。入力50Ω、負荷60−j40Ω（周波数一定）。公称目標は最大IL 0.30dB以下、H2/H3 35dB以上、必須減衰30dB以上。

チップ面積はLQP02=1、LQP01=2/3、LQW04=3、GJM01=2/3、合計6以下。**PCBパターン固定C（PCB_PATTERN_C）=0**（チップ面積換算）、****1個あたり0.02～0.2pF**、Q=40、最大3個**とする。PCB-Lは原則3本以下、IC可変Cは原則2枝（対GND、各0–4pF）。LQP02 Q25、LQP01 Q15、PCB-L Q12、**GJM01/IC可変C Q80**は暫定一定Qモデル。LQW04 Qは未確定。

チップLは一列配置し、強結合は物理隣接のみ |k|≤0.4。非強結合は公称k=0、弱結合感度で|k|≤0.1。chip–PCB |k|≤0.03、PCB–PCB |k|≤0.6。全インダクタンス行列は正定値。固定素子（PCBパターンCを含む）・結合・トポロジーは6設定共通で、可変Cだけ設定別。PCBパターンCはシャント／直列／ブリッジに固定素子として配置できる。チップ面積0でもパターン面積、寄生容量、基板公差、導体／誘電体損失は別途検証し、0.02pFの製造可能性や高周波Q40を保証するものではない。

**Phase 2継続、Phase 3は明示承認まで停止。** `matching_only` はH2/H3制約を課さないため、`full_lpf` の結果と同列比較しない。旧仕様の結果は新仕様への適合が再検証されるまで歴史的参考値。
