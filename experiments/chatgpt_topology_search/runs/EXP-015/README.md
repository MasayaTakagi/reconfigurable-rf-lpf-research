# EXP-015 — LQP02HV/HQのシリーズ別Q・SRFリスクを考慮した再最適化（Phase 2、2026-10-12）

**結論:** ユーザー更新に従い、LQP02HV（一定Q=25、0.4～27 nH、優先）とLQP02HQ（一定Q=20、0.2～56 nH、必要時の代替）を別シリーズとして扱った。**旧EXP011-01の「L1=56 nHかつQ25、最悪IL=0.293821739 dB」という値は新規則では不適合な旧モデルの数値記録**であり、消去せず履歴として残す。今回の有限局所探索では新規則下で**IL≤0.30 dBかつH2/H3≥30 dBの解は未発見**。新規則に適合する数値回路の保存・独立9×9 MNA確認は完了。

## 制約

- **電源50 Ω、負荷60−j40 Ω一定、6設定B71/B12/B28/B13+B14/B26/B8**。各設定のUL/DL全周波数範囲での**最大IL**、ULのH2/H3全周波数範囲の**最小減衰**を評価。
- チップ面積上限6、可変Cは各枝0～4 pF・Q80、GJM固定C Q80、PCBパターン固定C Q40（0.02～0.2 pF、最大3個）。チップL一列隣接結合のみ|k|≤0.4、他は公称0、全インダクタンス行列の正定値。
- 3可変C（2対GND+1非GND）とH2/H3≥30dBは**Phase 2限定の緩和実験**。2可変C（1対GND+1非GND）も正式の「2対GND・公称35dB」には適合しない。正式LPF-007基準は保持。
- 両シリーズとも面積コスト1。**HV優先・27 nH以下が第1選択**。HQはQ20で適用し、採用本数および大きいL値に伴う自己共振リスクを別軸で評価。LQP02の実部品SRF・Sパラメータや寄生は**未検証**。一定Qは測定データを保証しない。

## 再最適化で実行した探索と検証

- 解析ヤコビアン付きSLSQP minimax、HV/HQシリーズごとに**L上限と抵抗損失Qを再構築**、4L値・固定C・隣接k・6設定の可変Cを共同最適化。
- EXP011起点で、HV4とHQ1の2モデル、初期値ごとの多初期値（各24まで）と、一列物理配置**12通り×3初期値**を各HV/HQで探索。旧EXP014でもHV4とHQ1の各12初期値を実施。さらにHQ L上限5水準×8初期値、固定GJM接続15箇所とPCB固定C追加15箇所×2初期値を確認。**有限の局所探索であり、他の回路グラフの最適値ではない。** 一部の開始点は目的・減衰を同時に満たしておらず、成立解のみ表へ採用。
- 記録した9候補について6設定の**UL/DL/H2/H3各個別区間7,001点**で最悪IL、最小減衰を計算。別実装の**9×9枝電流MNAを72代表周波数**で解き、電力保存、5×5縮約法との差、結合K正定値、Q・シリーズ別L範囲・可変C範囲を確認。全候補は数値検証PASS。
- `summary.json` に候補と実行状況。`*_independent_MNA.json` に各候補の独立照合結果。`reopt.py`、`row_screen.py`、`hq_srf_tradeoff.py`、`rewire015.py`は実行済み探索を再現するコード。`verify015.py`は独立検証器。`*_rows.json` と `rewire015_results.json` は全局所終了時の記録であり、各反復の履歴ではない。
- **GitHub Actions大規模探索は未実行**。この研究は連続帯域の数学的保証、大域最適値、実部品のSRF/ESR/f依存性やEM実装の証明ではない。Phase 3は停止したまま。
