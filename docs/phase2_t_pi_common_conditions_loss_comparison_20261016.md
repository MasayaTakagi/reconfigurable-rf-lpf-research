## 1. モデル・公平性

**共通:** Vs=1Vrms、Rsrc=Rload=50Ω、fpass=1GHz、**理想時**の伝送零点2GHz（損失を含む実伝送零点ではない）、1GHz理想整合、各コイルの定Q=25、結合2組の|k|=0.1、非指定第3結合公称ゼロ、全Cに同じ定Q_C（各CのESR=1/(ω C Q_C)）、相互抵抗と寄生Cなし。

- T型：左右シリーズL1=L2=7.957747nH、中央L3+C3シャント。M13=+M, M23=−M、L3物理1.87917nH、C3=2.387324pF。左右のシリーズリアクタンスX=+50Ω、シャントX3=−50Ω（1GHz）。
- π型：中央シリーズLs=5.675550nH、左右シャントLa=Lb=5nH、それぞれ直列C=1.144570pF。Msa=−M、Msb=+M、Mab=0。1GHz無損失整合と2GHz理想ノッチが一致するようLs/Cを再設計。
- Q_C=35を主評価、Q_C=∞、80を参考比較。
- **制限:** 同じ終端・同じ単体Q・同じ指定周波数で比較したが、**同一連続帯域の減衰条件・同一部品数・同一実装コストではない**。TがC1個、πがC2個であり、これらは一般の最小損失を探索した結果ではない。

## 2. 実行済み単点・有限局所帯域比較（Q_C=35）

| 指標 | T（X=50Ω,k=0.1） | π（k_sa=−0.1,k_sb=+0.1） |
|---|---:|---:|
| 物理コイル自己L合計 | 17.795 nH | 15.676 nH |
| C個数・合計公称容量 | 1 / 2.387 pF | 2 / 2.289 pF |
| IL@1GHz | 0.748909 dB | **0.3694 dB** |
| L損失@1GHz | 0.449507 mW | **0.231544 mW** |
| C損失@1GHz | 0.332940 mW | **0.176063 mW** |
| 1GHzで内部に散逸する合計 | 0.782447 mW | **0.407607 mW** |
| 1GHzで負荷に伝わる電力 | 4.208033 mW | **4.592255 mW** |
| 局所0.85–1.15GHz・301点最大IL | 1.606 dB | **0.544 dB** |
| 2GHz減衰 | 36.802 dB | **42.079 dB** |
| 局所1.9–2.1GHz・301点最小減衰 | 29.36 dB | 29.82 dB |
| 3GHz減衰 | **21.81 dB** | 9.32 dB |

損失差の構造：Tは1GHzで各シリーズLに約9.97/9.17mA、中央シャントL+Cに約13.22mAが流れる。πは中央シリーズ約11.10mA、左右シャントL+Cに約4.81/4.60mA。πは**2個のCがあっても各シャントC電流が小さい**ため、総容量ESR損失が低い。TのシリーズL2本分の銅損もπの中央Ls1本分より大きい。

πの1GHz総損失はTより約48%低いが、前記**2つの特定設計の比較**であって「π一般がT一般より48%低損失」の証明ではない。信号源利用可能電力5mW。反射差と負荷電力差も含めた解析。

## 3. CのQ変化での感度（同じ設計素子固定）

| Q_C | T（X50,k.1）1GHz IL [dB] | π（k−.1）1GHz IL [dB] |
|---:|---:|---:|
| 理想∞ | 0.428907 | **0.209827** |
| 80 | 0.570710 | **0.2799** |
| 35 | 0.748909 | **0.3694** |

コンデンサの有限Qが下がるほど、通過周波数におけるπの優位が大きくなる。C1個対2個のコスト・面積・制御・SRF等の比較は別問題。

## 4. Tのシリーズリアクタンスを再選択した限定的な感度

同じTの \(X_1=X_2=X\) を解析的な50Ω整合条件 \(Y=(R_0^2+X^2)/(2X)\) で調整し、シャント直列LCが2GHzで共振するよう定数再合成。いずれも**結合2組k=0.1,Q_L=25,Q_C=35**。

| TのX@1GHz | IL@1GHz | 減衰@2GHz | 減衰@3GHz | 0.85–1.15GHzのmax IL |
|---:|---:|---:|---:|---:|
| 25Ω | **0.3843dB** | 26.70dB | 12.28dB | 0.609dB |
| 50Ω | 0.7489dB | 36.80dB | 21.81dB | 1.606dB |
| 100Ω | 1.4228dB | 45.68dB | **30.38dB** | 4.302dB |

従って**TでもILをπの0.3694dB近くまで減らせる（X=25Ω: 0.3843dB）**が、その固定設計点では2GHz減衰がπの42.08dBより浅い。Tを3GHz減衰30dB近傍へ寄せると、この固定解析構成では通過ILが大きくなる。

πは2GHzで42.08dBと深いが、3GHzでは9.32dB。**3GHzの減衰を重視する仕様ではこのπ設計は採用できない**。左右シャントLCを非対称化して2つの零点を狙う案は未実行の将来研究であり、達成実績ではない。

## 5. 研究上の判定

- **1GHz付近のILと2GHz単独ノッチを優先するなら、評価した設計点ではπ型を優先。** 理由は全体のコイル損失とC損失の小ささ。Qの一数値では判断しない。
- **3GHzを含む高域の減衰優先ならT型の利点を保持。** 同じkでもTのロールオフがこのモデルでは強い。コイル/C実装特性を入れてから再判定する必要がある。
- **決着には両方式を同じ全帯域仕様・H2/H3・実装コストで再最適化**すべき。今回はそのための初期ベンチと理論的な損失源の分解。
- RF-F003の正式帯域の再現・外部固定S2P・部品と結合の実装上限・パラメータばらつき等を適用していない。特に評価例のコイルQ25は現行RF-F003に含まれる実部品Qの評価ではない。
