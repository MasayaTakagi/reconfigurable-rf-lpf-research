### LQP02の数値上限27→56nHについて

従来の27nHは**EXP-009局所探索器の上限値**であって、LQP02HQのサイズ共通パッケージの製品レンジ上限ではない。村田製作所の[LQP02シリーズ選択ガイド](https://www.murata.com/products/inductor/chip/overview/lineup/rf1)では、同じ0402（01005）のLQP02HQ_02に**0.2–56nH**が存在する。実験ではパッケージ面積とQ25一定仮定を維持し、**数値探索器のL範囲だけ**を0.4–56nHに変更した。**約50nH品の実周波数依存Q/SRFが要求帯域で成立することは確認していない。** Q25一定仮定を使うというユーザー判断に従い、今段階ではQ(f)を勝手に変更しない。
