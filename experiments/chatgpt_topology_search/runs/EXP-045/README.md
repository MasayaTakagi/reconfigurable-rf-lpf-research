## 解釈・継続課題

* 既存T型の可変C調整だけでは最悪B28/B8の制約がほとんど動かず、IL改善は微小。固定L/C/kの有限摂動では、他設定の高調波制約再成立が難しく、改善は見つからなかった。ただしこれは**大域的な性能限界の証明ではない**。
* π型の公平条件下保存ベクトルもT型ベンチマークよりILが約0.108dB大きい。ただし本実験は保存点の再評価であり、π型の新たな系統最適化の完了ではない。
* RF-F003/RF-T005の固定S2Pだけからの理想受動整合MAG参考下限はB8 DL 960MHzでIL約0.385849dB（出典：EXP-042の`external_s2p_MAG_bound.md`）。これは現行外部モデル特有の理論参考結果であり実機測定ではない。現行の0.30dB公称目標を変更しない。
* 追加固定PCBパターンC（3個目）やトラップ帰還配置のトポロジー探索、二重BSF、損失分配最適化、H2/H3の頑健余裕を増やす継続法には未着手。
* 図面から生成したS2Pの基準面、実部品のSRF/Q(f)、チップ列配置での2結合同時実現性、ICスイッチ寄生・面積、温度、公差、EMおよび実測は未検証。Phase 3未承認・停止。
