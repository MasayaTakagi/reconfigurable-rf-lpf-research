# EXP-044 π型3L（RF-T005）— 実行済みローカル一次探索と非採用判定（2026-10-16）

## 状態と判定

**Phase 2の正式な実験番号 EXP-044 を main で事前予約済み。** 探索対象はRF-T005（正式RF-F003と混同しない）。GitHub PR #63の6 variant Actions `38908768631` および regression `38908768691` は、どちらもステップ記録のない状態でFAILED。**GitHub Actionsで成功した計算値はゼロ**であり、下記は会話ローカル環境で実際に行った別の決定論的計算である。

**結論**：全LQP02HV(Q25)のπ型は、EXP-043現行3Lに勝てない。Q33のLQW04への部分置換で数値ILだけ0.00325dB改善する候補は現れたが、チップ面積は3⅔→8⅓に増え、H3余裕は0.002dB未満、異種パッケージの実装結合も未確認。これは**正式に採用できる低ロスπ型を確立した結果ではない**。

## 正本条件

- RF-T005 = RF-F003の3可変C試験拡張。6設定、別々の28 bands.csv区間、通過帯域ILの最大値、UL H2/H3の最小減衰を評価。

## 今回実際に行った解析の独立性と限界

GitHub mainの両固定S2P（0–6GHz/1MHz・SHA検証済み）から、**600–2800MHzのChebyshev近似を作成**（実部虚部を別処理、各S11/S21/S22）。1MHz正本格子をサンプリングした近似誤差の最大成分値は7.70e−9程度（厳密な連続周波数上限ではない）。**ローカルの数万回の最適化ではこの近似を使用し、元S2Pを毎回直接読んでいない。** したがって**正式な正本S2P full-band数値検証ではなく一次スクリーニング**。

- 一次探索：π型GJM1/GJM2/PBC-only初期候補、6設定×3可変Cと固定L/C/2組kの26実数同時変数。多初期値L-BFGS-B/SLSQP/epigraph、28区間×5点の制約付き最適化、候補28×301/1001再チェック。
- 配置変種：第三Cvと固定PCB Cのポート接続を30通り×2開始点で比較。厳密な完全なトポロジー網羅ではない。
- 各Q入替え感度：LQW04 Q33を中央Ls、左La、右Lbの全部または一部に使用し、同一RF条件・部品コスト区分で再合成。LQW04 9nH等のSRF・部品型番は未検証。
- **独立な実際の数値点検**：GitHub mainの元S2Pから617/803/960/1406/2148/2745MHzの行を**直接取得**、縮約4ノードアドミタンス法とは別の**明示7×7枝電流MNA**で IL と電力収支を計算。Q25候補のB28 803MHzではIL1.18083664dBと近似1.18083671dBの差7.3e−8dB、受動電力保存残差1.7e−18W。Q33候補でも元S2P原値で803/960MHzのILを照合済み。**全格子の独立MNA未実施**。

- 同一3L・高Qコイルはサイズと隣接結合実現性を楽観視した理論上の部品Q固定ベンチ。
- Ls,La Q33の0.892741dBはEXP-043の0.895993dBに対し**0.003252dB**差。Q33×3では0.006372dB差。これらは小さく、追加面積・SRF・製造公差を見れば現段階では設計採用根拠にならない。
- 従って**チップ面積とILのトレードオフではEXP-043 3Lを研究ベースラインとして継続**し、π型は「非常に高いQを要求する」ことが明確になった対抗案として保存する。

## 主要損失要因の解析

GJM2・Q25の初期ローカル勝者（IL1.1808367dB）でB28 803MHzにおいて、独立元S2P MNA：チップL散逸0.525680mW、C散逸0.213336mW、入寄生0.286941mW、出寄生0.156542mW、反射0.007840mW、Pload3.809661mW。これに対しEXP-043 area3⅔基準の同803MHzはL損失0.370445mW、C損失約0.09961mW、Pload4.06780mW。**π型は2シャント共振器+中央シリーズLに電流が集中し、磁気Q数値を上げるだけではL/Cの実際の損失が小さくならない。**

高Q版は同803MHzのチップL損失を、Ls/LaQ33・LbQ25で約0.3255mW、3L全Q33で約0.32365mWへ減らしたが、代償となるパッケージ面積が大きい。また最良サロゲートの結合係数は（Ls–La, Ls–Lb）で約(-0.064,-0.018)、当初の基礎研究で想定した(−,+)強結合の対称状態ではない。**本用途におけるIL最小が磁気Q最大化と別の最適化問題**であることを改めて確認。
