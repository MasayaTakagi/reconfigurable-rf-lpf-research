# EXP-011 発見経緯と探索知見（Phase 2、2026-10-12）

> **要点:** EXP011-01 は「部品を減らせば必ず低損失になる」という単純則の成果ではない。部品が多いEXP010で有効な接続関係を発見 → 固定GJMの接続位置を変更 → **等Q・同一枝の固定Cと可変Cを厳密に等価縮約** → PCB固定Cを除去（この操作自体は等価ではない） → **全固定素子・結合・6設定の可変Cを再最適化**、という一連の局所探索の成果である。

## 適用範囲・証拠の区別

- 50 Ω源、60−j40 Ω負荷、B71/B12/B28/B13+B14共通/B26/B8の6設定。全UL/DL帯域最悪IL、全UL H2/H3帯域最小減衰。
- LQP02 Q=25、GJM01およびIC可変C Q=80、PCB固定C Q=40、いずれも周波数一定の仮定。
- チップLは物理一列、強結合は隣接のみ |k|≤0.4、結合行列正定値、チップ面積上限6。
- **3可変C（うち非GND1本）とH2/H3≥30 dBはPhase 2実験限定の承認緩和条件**。正式な2対GND可変C・公称35 dBの[LPF-007](../../../../candidates/LPF-007.json)を置換しない。
- 記号: **[V]** 保存した候補の7,001点／各区間＋独立9×9 MNA代表点による検証、**[S]** 201点など粗グリッドの有限局所探索、**[E]** 同一Q・同一端子の固定C＋可変Cの集中定数モデル上の厳密等価、**[H]** 今後の実証が必要な設計仮説。

## EXP010-05からEXP011-01への主要な操作

### 操作A：固定GJM接続先の単独変更 [S]

[EXP010-05](../EXP-010/EXP010-05.json) の固定C配置は次の通り。

| 素子 | EXP010-05の接続 | EXP011-01への変換 |
|---|---|---|
| Cf1 (GJM Q80) | node1–node3（ブリッジ） | **node4–GND（Cv0と並列）に一旦再配置**し、等価縮約 |
| Cf2 (GJM Q80) | node5–GND | **同枝のCv1と等価縮約** |
| Cf3 (GJM Q80) | node1–node2（L0並列） | **この固定Cだけ残す** |
| Cpcb0 (PCB-C Q40) | node3–node4（L1並列） | 縮約後に**除去＋全素子再最適化** |
| Cv0 (IC Q80) | node4–GND | 合計容量として保持 |
| Cv1 (IC Q80) | node5–GND | 合計容量として保持 |
| Cv2 (IC Q80) | node2–node3（L3並列） | 保持 |

3-GJMの固定C接続変更を**33グラフ×2初期値**で粗スクリーニングし、Cf1をCv0と同じ枝に移す有望局所解（201点評価の最大IL ≈ **0.294326 dB**）が見つかった。この値は粗スクリーニング値であり、最終EXP011-01の精密検証値と同等の証拠レベルではない。

GJMの2枝同時変更も**156組×1初期値**で試したが、粗い成立解の最良は約0.294326 dBで、この時点では単独変更の発見を上回らなかった。多初期値数が少ないことを記録する。

### 操作B：同じ端子間・同じQのCを統合 [E]

採用した一定Qモデルでは、容量Cのアドミタンスは

    Y_C(ω; C,Q) = ω C / (1/Q − j)

であり、**同じ端子に並列**で、かつ**Qが等しければ**

    Y_C(ω; Cf,Q) + Y_C(ω; Cv,Q) = Y_C(ω; Cf+Cv,Q)

が厳密に成立する。したがって、各バンド設定sの可変Cを

    Cv_new(s) = Cv_old(s) + Cf

と置くことで、**モデル内で同じ周波数応答のまま**固定Cを取り除ける。

ただし全6設定について、Cv_new(s)が **0～4 pF** の範囲に入ることが必要。Cf1/Cf2の統合はこれを満たした。削減後も可変枝数は3本のまま。4L＋3GJMから4L＋1GJMへ変わり、チップコストは 6−2×(2/3)=**4⅔**。

**正確な解釈:** 同Q統合自体は「ILをさらに改善する変換」ではなく**等価性を保った面積削減**。ILの改善は、その前の固定C再配置と、その後の独立した全ネットワーク再最適化が関与する。等価縮約だけの効果と混同しない。

**一般化の条件:** 同じ枝（ノード順逆も可）、同じ周波数依存Qモデル・損失、合算後の容量範囲、可変C設定資源と物理制約が成立すること。Q40のPCB-CとQ80の可変C、異なる枝のC、あるいは可変上限4 pFを超える和は安易に統合できない。Phase3のICスイッチ寄生や物理IC面積に関する等価性は未保証。

### 操作C：PCB-C削除後の全回路再最適化 [V、非等価]

統合後もL1並列（node3–node4）にはQ40、約0.02 pFのPCB固定Cが残っていた。これを削除して再最適化した。**この操作自体は等価変換ではない。** すべてのL値、残存固定Cf3、チップ隣接k、そして全6設定の3本の可変Cを同時に変更する必要があった。

結果: **EXP011-01** はIL=**0.2938217385 dB**、最小H2/H3=約**30.00010 dB**、コスト**4⅔**。比較対象EXP010-05はIL=0.2998905774 dB、コスト6。観測差は **0.006068839 dB**、チップコストは**22.2%減**。これは複数の連続した設計操作を含む差である。

最終接続:
- L0=1–2、L1=3–4、L2=2–5、L3=2–3。
- 固定Cf3=1–2（L0並列）、Cv0=4–0、Cv1=5–0、Cv2=2–3（L3並列）。
- チップ物理順 L1–L2–L3–L0。隣接k=[+0.012922, −0.373167, +0.400000]、その他公称0。
- L0=3.408462 nH、**L1=56.0 nH（探索上限）**、L2=8.044533 nH、L3=4.853728 nH、Cf3=0.780469 pF。全設定の可変C値は候補JSONが正本。

### 操作D：厳密な候補検証 [V]

- 6設定すべての各UL/DL/H2/H3区間に**7,001サンプル**を使用。極値付近の周波数方向の有界探索も実施。
- **9×9 MNA**（4本のインダクタ電流が独立未知数）を各候補54代表点で照合。電力収支・結合行列SPDをチェック。
- [EXP011-01-loss.json](EXP011-01-loss.json) の最悪点は**B8・960 MHz**。全IL約0.293822 dB中、L0≈0.09016、L3≈0.08951、L2≈0.04313、L1≈0.00529、固定C≈0.00511、IC可変C≈0.05059、反射≈0.01003 dB。
- **30 dB減衰に対する余裕は約0.0001 dB**のみ。比較用のEXP011-02は約0.01 dBの余裕でIL≈0.293975 dB。
- 連続周波数区間の数学的証明、大域最適性、Q(f)/SRF、EM、製造公差・実装特性は未検証。非凸局所最適化の未収束も維持記録。

## 失敗した探索から得られた情報

1. EXP010ベースの**第2PCB-C追加14位置×2初期値**では、成立局所解の最良が約0.300103 dBで、既存最良未更新。[search_summary.json](search_summary.json)
2. EXP010の第3可変Cの枝変更**9位置×3初期値**でも、成立粗解の最良は約0.309571 dB。既存L3並列は探索済み初期値の範囲で有利。
3. 真の4L＋1GJM＋0PCBに縮約した後、GJM固定位置15、Cv2変更9、GJM追加14、PCB-C追加15位置を有限試行したが、最良EXP011-01を更新しなかった。
4. 最終コンパクト回路の**1インダクタ枝変更56案×1初期値**を全実行し、201点評価の成立最良は0.298567 dB。各構造の多初期値最適化が不足するため**上限・限界とは言えない**。
5. 途中の古い構造に対する別のL接続56案は17案のみ実行した。これと最終コンパクト回路の56案完了を混同しない。

## 次回探索へのアルゴリズム上の教訓 [H]

1. **まず有望な複雑トポロジーを探索し、その後に回路グラフを正規化・縮約する。** 最初から必要部品数を最小に限定すると、EXP010のような「探索用の冗長な枝」を通じて見つかる解を見逃す可能性がある。
2. **同一枝・同Qの固定C＋可変Cが見つかったら自動統合候補として検査する。** 設定別容量の上下限を確認してから、同一周波数応答を独立MNAでチェックする。
3. **部品の追加と削除の双方を探索演算子に含める。** PCB-Cのようにチップ面積コスト0の素子でも、損失および結合した電流分布を変え得るため、削除試験の価値がある。ただし単体の消費電力が小さいことだけでは不要とは判定できない。
4. **縮約／接続変更後に、固定L/C/kと全バンド可変Cを共同で再最適化する。** 可変Cだけの局所調整で改善しなくても、ネットワーク全体の再最適化で成立する場合がある。
5. **固定部品再配置と変数変換は別ステップとして記録する。** 「固定Cを削ったから0.006dB改善」という単純な因果解釈は誤り。各中間候補のIL、部品数、等価性の有無を別々に残す。
6. **面積–最悪IL–高調波余裕のPareto候補を保持する。** 30 dB境界ぎりぎりのEXP011-01と0.01 dB余裕のEXP011-02を共存させ、数値最小と比較的余裕のある候補を混ぜない。
7. **局所スクリーニング→多初期値再最適化→高密度・独立MNA検証を分離する。** 不成立解でも有望な構造・初期値になり得るが、成立扱いしない。探索ジョブの未実行・失敗・反復上限・乱数シード・コミットSHAを記録する。
8. **次のボトルネックはL0/L3損失。** 主信号経路の電流分配、磁気結合順、Lの2枝以上の同時変更、固定／可変Cの共同再配置を優先。ただし損失会計は反事実的な素子除去効果ではなく、別途感度／再最適化が必要。
9. **探索上限へ張り付いたL1=56nH、k=0.4を記録して別途感度探索する。** Q=25はユーザー指定どおり維持しつつ、最適化境界依存性と実装可能性は別の評価軸とする。

## 次の自動探索に組み込む手順

1. 既存の良好解の素子接続・数値ベクトルを新グラフの初期値に移植する。
2. 固定C1/2枝の再配置、可変C枝の再配置、PCB-Cの追加／削除、L複数枝の変更、一列隣接結合順を生成する。
3. 各グラフで同枝・同Qの固定C＋可変Cを検出。範囲成立時に等価縮約して重複除去し、**縮約前後の完全な設定別容量ベクトル**を保存。
4. 縮約後・非等価変換後は、L/C/k＋全可変Cを再最適化。初期値を複数使い、最悪周波数を適応的に追加する。
5. 候補を **(面積コスト、最大IL、最小H2/H3余裕)** で比較し、成立した非劣解と不成立だが興味深い解を別管理する。
6. 上位候補のみ7,001点／区間と独立MNA、電力収支、SPDで再検証。未実施を完了扱いしない。Phase 2を維持する。
