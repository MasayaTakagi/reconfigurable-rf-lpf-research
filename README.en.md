# Reconfigurable RF LPF Research

Phase 2 topology and performance exploration. Phase 3 switched-capacitor implementation remains paused pending explicit approval.

Six configurations: B71, B12, B28, B13+B14, B26, B8. Evaluate worst-case insertion loss over UL/DL and minimum H2/H3 rejection over all UL harmonics. Nominal IL target <=0.30 dB, rejection >=35 dB (mandatory >=30 dB).
