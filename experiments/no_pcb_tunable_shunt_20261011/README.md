# 2026-10-11 PCB-Lなし・新制約適合 LPF 再探索（Phase 2）

## 結論（新規実験、旧解は保存）

旧CP07の0.328924dB案はバンドごとに4容量を自由に変化させるため、2026-10-10版の**対GND可変IC-C 2枝 / 固定GJM01**の制約を満たさない。前段の再最適化済み候補LPF-005（IL=1.251127dB）/ LPF-006（IL=1.163823dB）は旧解として保存し、この実験では**可変LCシャントトラップ**の新トポロジーを検討した。

| 新候補 | 6設定最大IL | H2/H3最小減衰 | chip配列/結合 | 状態 |
|---|---:|---:|---|---|
| [LPF-007](../../candidates/LPF-007.json) | **0.513168dB** | 35.069970/35.069996dB | (L1,L2,L3,L0); 隣接k=(-0.006,-0.4,+0.4) | 低IL数値候補 |
| [LPF-008](../../candidates/LPF-008.json) | **0.518587dB** | 35.099999/35.099995dB | 同配列; 隣接k=(0,-0.4,+0.4) | 2主結合・簡素化候補 |

両者とも**IL≤0.30dBには未達**。SLSQP最適化器の収束成功フラグはfalseで、性能限界や大域最適性は主張しない。両候補の具体的素子値と6設定のIC値はJSONが正本。

## 電気的な構造（2変調シャントLC、PCB-Lなし）

全電気節点を 0=GND, 1=IN, 2=中間, 3=OUT, 4=トラップA先端, 5=トラップB先端 とする。

```text
(IN=1)──L0──(2)──L3──(3=OUT)
                 |      |
                 L2     L1
                 |      |
                (5)    (4)
                 |      |
          [Cf2 || Cv1]  Cv0
                 |      |
                GND    GND

Cf0: (2)-(3)  [L3と並列]
Cf1: (1)-(3)  [IN-OUTの容量ブリッジ]
```

- LQP02×4（L0…L3、各Q=25）、固定GJM01×3（Cf0…Cf2、各Q=80）、IC可変C×2（Cv0/Cv1、対GND、0～4pF、Q=80）。PCB-L=0。面積=4+3×2/3=**6.000**。
- シャントLに直列に置かれたIC-Cを変更することで、バンドごとのシャントLC共振周波数を制御する。**同じトポロジー・固定素子・結合を全6設定で共通使用**。
- chip L物理列は L1–L2–L3–L0。強結合は物理隣接に限り |k|≤0.4。非隣接ペアk=0。LPF-008では L1–L2もk=0なので**2組だけ強結合**。
- 全インダクタンス行列の正定値を確認済み（Kの最小固有値 ≈0.4343>0）。
- 個々の固定Cは0.100～0.23pF程度。最小値0.1pFは探索下限であり、GJM01実部品の存在を証明したものではない。基板寄生とキャパシタ実現方法は別途検証。

## 検証方法と限界

1. 6設定UL+DLの最大IL、ULのH2/H3各区間の最小減衰を**0.02MHz以下のメッシュ**で評価（端点を含む）。B13+B14は1つの容量設定で評価。
2. 5節点+4インダクタ枝電流の**9×9独立MNA**で代表周波数を再計算。最大IL誤差は約1.3e-12dB、電力収支残差は1e-17W未満。
3. 可変C×2はGNDへ接続、0–4pF、固定L/C/結合は6設定共通。Q・コスト・コイル物理列の形式的条件も確認。
4. 実測Q(f)/SRF、LCの公差、磁気結合の符号と強度の同時実現性、GJM01の0.1pF近傍容量、配線寄生、負荷実態、大信号は未検証。有限メッシュは連続帯域の確証付き証明ではない。
5. 追加のLQP01 Q15×2＋LQP02 Q25×2＋GJM01×4（コスト6）の初期試験では、得られた精密化候補は最大IL約0.594dB、H2/H3約35.05dB。優位でなく、こちらも**収束・大域最適性未確認**。

## 再評価コマンド

GitHubの共通解析器を使用し、候補JSONの回路枝から直接MNAを構成できる。次のコードは外部レビュー向けの再現入口：

```bash
python scripts/verify_no_pcb_tunable_candidates.py
```

このスクリプトの結果は独立した有限グリッド再計算であり、連続周波数の数学的保証やEM検証を代替しない。
