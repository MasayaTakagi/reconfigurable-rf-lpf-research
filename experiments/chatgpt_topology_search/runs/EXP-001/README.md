# EXP-001 — PCBパターン固定容量の0.2pF上限適用と LPF-008 比較（2026-10-11）

**Status:** Phase 2、有限数値探索と検証、理論最適性／EM実装性は未証明。候補 [LPF-009](../../../../candidates/LPF-009.json) を保存した。旧LPF-007/008は変更しない。

## 追加制約

基準は [data/design_constraints.json](../../../../data/design_constraints.json) の2026-10-11 owner-approved revision。固定PCBパターン容量 `PCB_PATTERN_C` は **各0.02～0.2pF、Q=40、チップ面積コスト0、3個以下**。全バンド共通の固定Cであり、IC可変Cと異なる。実基板の配線面積・寄生・製造公差は未検証。今回の探索はPCB-Lなし。従来の固定GJM01 Q80・コスト2/3、LQP02 Q25、IC可変C Q80・2枝各0～4pF・対GND制約は維持する。LQP02×4 + GJM01×3のコストは6。チップ強結合は単列の隣接コイルのみ |k|≤0.4、非隣接k=0。

## 探索範囲

旧LPF-007/008の2つの接地可変LCトラップ型を初期値とする。PCBパターンCを1個、既存の5電気節点の接地/節点間ブリッジに追加する案を中心に、最大3個の配置とGJM01を一部置換する構成も一次スクリーニングした。有限個の配置と初期値のみであり、全トポロジーの網羅列挙ではない。

旧スクリーン探索の80候補のうち、PCBパターンCの新しい各0.02～0.2pF上限を満たす解だけを成立候補として再評価し、それ以外の旧結果は除外。既存のコードで数値最適化範囲を0.02～0.2pFに修正。採用チェックポイントは追加PCB C 1個（0.020000pF）を中間節点 n1 からGNDに接続した構成。

## 固定素子／容量

詳細は LPF-009.json。LQP02 (nH) = [3.52595847,8.47617761,5.73355221,6.52650989]、GJM01 (pF) = [0.10016296,0.21699337,0.22511569]、PCB-C (pF) = [0.02000000001]。IC可変Cのバンド別値は候補JSONと [6設定CSV](per_band_dense.csv) を参照。

物理的なチップ列はL1–L2–L3–L0。隣接kは[−0.00610594,−0.39929701,+0.39988226]で非隣接はすべて0。K最小固有値≈0.434878>0。小さい第1結合も、隣接結合許容枠として記録している。EM実現性は未検証。

## 数値検証

- 6設定UL/DLと2×/3×ULの周波数区間を全走査。各帯域区間で最大5251点を使用して0.02MHz以下の周波数刻みを確保（範囲端を含む）。結果は [per_band_dense.csv](per_band_dense.csv)。
- 縮約節点アドミタンスによる評価に対し、インダクタ枝電流を独立未知数として含む **9×9 MNA** で各バンドの代表周波数を照合。最大差≈1.85×10^−13dB、電力保存残差≤5.67×10^−18W。
- PCB固定容量のQ40、3個以下、0.02～0.2pF、6ケース固定容量、面積≤6を形式的に確認。最適化はL-BFGS-Bで収束フラグがTrueの局所解。ただしペナルティ目的の収束であり、制約付きminimaxの大域最適性の証拠ではない。
- 連続周波数の区間解析による厳密保証、実測Q(f)、パッド／配線寄生、強結合のEM物理配置、大信号・公差は未実施。

## 次の方針

PCB-C 0.02～0.2pFを厳守して固定Cの再配置と部品コスト割当てを見直し、LPF-007を上回る可能性を探索する。**現在の成果はLPF-008からの小幅改善だけであり、0.30dB目標には未達**。Phase 3には移行しない。
