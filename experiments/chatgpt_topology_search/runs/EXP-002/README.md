# EXP-002 — 面積コスト7までのfull_lpf探索基準（2026-10-11）

## 研究上の位置付け

2026-10-11のユーザー指示により、**比較用面積予算を7に拡張して探索した**。既存の承認済みチップ面積 **hard cap=6** は [data/design_constraints.json](../../../../data/design_constraints.json) で変更しない。したがって本成果の A7-01 と A7-02 は**探索予算7の検証用参照候補**であり、現行hard cap6で実装承認された候補ではない。コスト7「以下」のbest-foundと、コスト7「ちょうど」のbest-foundは分ける。

**結論:** この有限探索での最良数値は、6設定最大IL **0.508388959dB**、H2最小 **35.069978dB**、H3最小 **35.070000dB**。使用面積は **20/3=6.666667**。コスト6のLPF-007（0.513168414dB）より **0.004779455dB** 改善。**コスト7の数学的性能限界を示したものではない。**

## 設計条件

- ソース50Ω、負荷60−j40Ω一定、全6設定のUL/DL最大IL、各設定のUL 2倍/3倍波全帯域の最小減衰。最低30dB、当面の公称目標35dB、最終IL目標0.30dB。
- LQP02：Q25／面積1。GJM01固定C：Q80／面積2/3。IC可変C：Q80、対GNDに2枝、それぞれ0～4pF、6設定でのみ値変更。PCB-LとPCBパターンCも許容されるが、**今回保存する2つの最良候補には使っていない**。
- chip L物理列 L1–L2–L3–L0、**隣接ペアのみ**|k|≤0.4、非選択／非隣接ペアの公称k=0、L行列正定値。
- 全固定素子・配置・結合は6設定で共通。B13+B14は1設定。Phase 3には進まない。

両新案ともLQP02×4、GJM01×4、IC可変C×2、PCB-Lなし。回路接続は両案共通。

```text
IN ─── L0 ─── n1 ─── L3 ─── OUT
 |       |      |       |      |
 └─Cf3───┘      |       |      L1 ── n3 ── Cv0 ── GND
                |       |
                |       └── Cf0 ───(n1とOUTの間)
                L2 ── n4 ── [Cf2∥Cv1] ── GND

Cf1 は IN と OUT を接続するブリッジC
Cf3 は L0 と並列に接続する固定C
```

機械可読の節点番号は 0=GND、1=IN、2=n1、3=OUT、4=n3、5=n4。詳細な netlist、固定L/C、相互結合、全6設定の可変C値は [A7-01.json](A7-01.json) / [A7-02.json](A7-02.json) の `topology` を唯一の正本とする（ASCII図は概念図）。

### 最良A7-01の固定値

- L0 3.176326503nH、L1 7.721074665nH、L2 5.747162981nH、L3 6.849749113nH。全Q25。
- Cf0 0.100000000pF、Cf1 0.100000000pF、Cf2 0.285779712pF、Cf3 0.656792462pF。全GJM01 Q80。
- 物理隣接k（L1–L2、L2–L3、L3–L0）= (−0.003060028、−0.400000000、+0.400000000)。非隣接はゼロ。
- [各設定の最大IL、最小H2/H3、Cv0/Cv1](A7-01_six_band.csv)。2強結合専用案は [A7-02_six_band.csv](A7-02_six_band.csv)。

**第三隣接kの重要性:** A7-01の素子定数を固定しk(L1,L2)だけゼロにすると、H2≈34.14dB、H3≈33.67dBまで悪化する。したがってA7-01の優位性は微小な結合係数の制御に依存し、PCB実装上の不確実性がある。A7-02はk(L1,L2)=0のもとで**改めて全固定値・6設定の可変Cを再最適化**した独立候補。

## 計算した探索範囲と未完了領域

| 一次スクリーニングした回路族 | 配置／組合せ数 | 例 | 結果 |
|---|---:|---|---|
| LQP02×4+GJM01×4 | 12 | 3固定Cから4固定Cへ、追加枝位置を12通り | A7-01を発見する起点 |
| LQP02×4+GJM01×4+PCBパターンC×1 | 10 | PCB-C 0.02～0.2pF、Q40 | 今回の粗い探索ではA7-01を更新できず |
| LQP02×5+GJM01×3（実使用コスト7ちょうど） | 44 | 第5チップLの枝位置・行配置 | 粗い初期値では良好解を発見できず。**未収束による見逃しの可能性が高く、性能劣位は未確定** |
| LQP02×5+GJM01×2+PCBパターンC×1 | 7 | 第5チップLと固定PCB-C | 今回の粗い探索では良好解なし |
| **合計** | **73** | L/C値＋結合＋可変Cを部分最適化 | **網羅探索ではない** |

粗い段階は各配置1初期値、最大65～120反復のペナルティ形式。GJM01×4構成に対して追加でSLSQP等の局所精密化を実施。**SLSQPのsuccessはFalse**。そのため一次探索の失敗は回路の下限とは解釈できない。なお、第5チップLを導入する構成は初期値設計や結合配置の多様性が不十分であり、次回の探索優先対象。

**未探索:** PCB-L×1～3、PCBパターンC×2～3、新しいグラフ構造、別の可変C節点、LQP01混用とLQW04、さらに広いチップL物理列。コスト7の最良値が確定したとは言えない。

## 独立検証

- 6設定UL/DL/UL×2/×3を**各周波数セグメント7,001点**（最大間隔0.02MHz未満）で再評価。区間端を含む有限メッシュであって、連続区間の厳密保証ではない。
- 高速節点縮約解析とは別に、各コイルの電流も未知数とする独立MNAで各ケース・各帯域の代表点を計算。電力収支残差：A7-01最大6.1×10⁻18W、A7-02最大6.9×10⁻18W。
- K正定値、固定部品の6設定同一性、全IC-Cの0～4pF、面積上限7を確認。Q25/Q80は仮定で、実部品Q(f)ではない。
- [共有MNAによる再計算スクリプト](verify_area7.py)：`python experiments/chatgpt_topology_search/runs/EXP-002/verify_area7.py --reference A7-01 --points 61`。最大周波数分解能検証は `--points 7001`。通常の CI 回帰は粗い11点でソフトウェア互換性のみをチェックする。
- EM/配置・2組k≈0.4の同時実現性、容量の製品ラインアップ、寄生、製造公差、温度、大信号、全周波数連続保証、大域最適性は**未検証**。

## 大規模探索への移行条件

1. コスト7は**面積予算上限**として評価し、同じ候補集合で実使用コスト>6の最良値も別集計。コスト4/5/6も同一条件で探索し、失敗・未実行を数える。
2. まずA7-01とA7-02を固定回帰させ、追加の5Lトポロジーの初期値を既存4L解から安全に移植する。コスト7ちょうどの5L+3GJM案について独立した探索予算を割り当てる。
3. 固定枝種別をPCB-L（Q12）、PCB-C（Q40、0.02～0.2pF）へ拡張。Cは最大3、PCB-Lは最大3、チップL–PCB-L |k|≤0.03、PCB-L同士 |k|≤0.6+SPD。
4. P4-Aは任意の内部ノードへ対GND可変Cを接続できるよう一般化し、`matching_only`と`full_lpf`を別管理。
5. GitHub Actionsでは手動起動・分割・checkpoint・失敗結果保存・SHA/シード/評価回数/実行時間記録。完全な指定クラスを消化したときのみ、その有限範囲での最良発見値と報告する。
6. **Phase 3は引き続き停止**。
