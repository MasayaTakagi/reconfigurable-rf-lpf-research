# PCB-Lなし設計の新制約への更新（Phase 2、2026-10-11）

このフォルダは **新しい物理/可変容量制約を満たす回路に移行するための局所探索結果** を記録する。**IL 0.30dB達成候補・実装承認候補ではない。** 以前の CP07 (=IL 0.328924dB、4個のバンド別Cを独立変更) は新制約不適合であり、削除せず歴史的基準として保持する。

## 使用したGitHub仕様

- 正本: `data/design_constraints.json`（policy_version 2026-10-10、2026-10-10T12:23Zの結合ルール改訂を含む）。
- 6ケースのUL/DL、ULの2倍/3倍は `data/bands.csv`。B13+B14は1設定であり同じ2可変C値を共用。
- チップ面積 = LQP02×1 + LQP01×2/3 + GJM01×2/3 ≤6。PCB-Lなし。LQW04はQ未確定のため使わない。
- LQP02: Q25、LQP01: Q15、GJM01およびIC可変C: Q80。全て一定Qモデル。
- IC可変Cは2枝だけ、各0～4pF、各枝グランド接続。固定C/Lおよび回路結合は6設定共通。GJM01は各0.1～100pFの探索範囲（仕様上確定しているのは最大100pF、0.1pF下限は本実験の数値範囲）。
- チップLは一列物理配置。隣接するペアだけ磁気結合を許容（|k|≤0.4）、非隣接ペアの公称k=0。全行列正定値。
- Source=50Ω、load=60−j40Ω (周波数一定)。UL/DL全域の最大ILを小さくし、H2/H3の公称減衰35dB以上を要求。必須30dB。

## 回路トポロジーの説明

**A（PCB0-Q25-L4-C3-IC2）** 4個のLQP02と3個の固定GJM01（面積4+2=6）。**B（PCB0-MIX-L4-C4-IC2）** LQP02×2、LQP01×2、固定GJM01×4（面積2+4/3+8/3=6）。

両者とも物理回路は次の接続を基本とする（Lの番号は0始まり）。

```
IN (node0)──[L0 || Cf0]──(node1)──[L3 || Cf3]──(node2)──[L2 || Cf2*]──OUT (node3)
                                             │
                                             L1
                                             │
                                          Cf1 (直列)
                                             │
                                            GND
IC可変C A/B : ノード → GND、各0～4pF
```

A案のみL2への固定並列Cを**配置しない**（*印）。よってL2は単独直列Lである。B案では3段すべてに固定並列Cを使用する。L1–Cf1はシャント直列LC。キャパシタは固定成分にバンド別チューニングを加算したものではない。**追加のIC Cは明示された2ノードの対GND枝**である。

## 解の数値検証

- 2026-10-11実験。初期値・固定Cの割当・物理チップ順序・シャント位置を変えた**有限回数の局所探索**。
- 0.02MHz以下の間隔で通過域・H2/H3の全区間を走査（0.02MHz周波数グリッド、端点含む）。これを「連続周波数の数学的保証」とはみなさない。
- 別MNA方程式（各Lの枝電流を未知数とする8x8行列）と、高速縮約モデルを代表周波数で比較。IL差は最大約2.3e-13dB、電力収支残差は約1e-12W未満。
- 4x4インダクタンス行列の正定値、チップ単列配置・隣接結合係数上限、全6設定共通のL/C固定値、IC可変C対GND・0～4pF、面積コスト≤6を確認。
- LQP01の実品番の選定可能L範囲は仕様ファイルで`inductance_range_confirmed=false`、**B案は実部品適合が未確定**。コイルの正負の結合配置もEM未検証。公差・実部品Q(f)・自己共振・大信号は未確認。

## 現時点での結論・次の作業

今回の探索で確認した2案は**新しい構成制約には適合するが目標IL≤0.30dBには到達せず、旧0.328924dB候補の置き換えはしない**。全PCB-Lなしトポロジーの網羅も大域最適性の証明もない。候補索引では`structurally_valid_il_target_fail`とする。

次段階では、面積6以内の別トポロジー（3チップL＋4固定C＋2可変C、LQP01による5～9コイル構成、独立並列経路、結合利用Q改善）をP4-A等の自動探索と多初期値最適化で評価し、最大ILとH2/H3の同時性能を改善する。Phase 3は停止のまま。

最適化コード（`reopt.py`、`reopt_mixed.py` など）は今回の付属アーカイブに保存されているが、GitHub上への探索器移植は**未完了**。GitHub内で再現できるのは**保存済み候補の回路応答の独立再計算**である。
