## 1. RF-F003の必須評価モデル（不変更）

外部源50Ω → 入力固定S2P Port1→Port2 → LPF（6設定で固定構造、最大2可変C枝だけ設定ごとに変更） → 出力固定S2P Port1→Port2 → 外部負荷60−j40Ω。

- 各S2Pは50Ω正規化、DC〜6GHz、1MHz刻み、6001点、`# Hz S RI R 50`。ワーカー内で1回検証・キャッシュ。複素S実部・虚部の線形補間。ハッシュ不一致・欠損・不正形式・周波数範囲外はfail-closed。目的関数呼出しごとの元RLC再合成は禁止。
- S2P参照インピーダンス50ΩをLPFとの接続境界の**内部50Ω終端**として追加しない。
- 6設定のUL/DL全区間の最大 `IL=-10log10(Pload/Pavs)`、UL由来H2/H3各区間の最小減衰（同じtransducer gain定義）。30dB必須／35dB公称、IL≤0.30dB。有限点と連続区間の評価を混同しない。
- チップLの物理一列・強隣接 `|k|≤0.10`、PCB-L同士 `|k|≤0.10`、非強結合公称0・感度 `|k|≤0.03`、chip–PCB k=0、全インダクタンス行列SPD。
- IC可変Cは正式最大**2独立枝**、各0〜3pF、Q35。固定L/C、全結合、トポロジーは6設定共通。パッケージL・固定C・PCB部品の残る正式RF-F003規則を遵守。チップ面積はPareto評価軸でありhard capなし。
- 入出力の固定寄生部品はLPF設計変数とLPF面積コストに含めず、基準面・物理面積は別記録。
- 旧RF-F002/Q50/1.5pF/k0.15を新結果へ自動適用しない。

**仕様監査注意:** 現行RF-F003 JSONの数値フィールドは`|k|≤0.10`だが、`overrides_require_owner_approval`内の歴史的文字列には`above_0_15`が残っている。数値判定には明示上限0.10を適用し、矛盾は監査で報告する。承認済みimmutable正式スナップショットを無断編集しない。
