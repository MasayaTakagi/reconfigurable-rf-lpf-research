### 検証

- **6設定・UL/DL・H2/H3の全セグメントを各7,001点で再計算**（最大ステップ約0.02MHz未満）。これは連続周波数保証ではない。
- インダクタ枝電流4本を追加未知数とする独立の**9×9 MNA解析**を54代表周波数点で実行。電力収支残差最大 **6.07×10⁻18W**（source電圧1Vrms正規化）。
- 全4コイル結合Kの最小固有値は**0.4343101**。数値的受動性は満たす。2つの隣接結合が|k|≈0.4、第3隣接はk≈−0.003179（実配置での同時実現性未確認）。
- 6設定で共通L・GJM01・k、IC可変C値0～4pFを確認。GJM01 0.1pF下限が2個あり、製品選定・基板寄生・Q(f)・公差は未検証。
- 共通回路解析器での再計算: `python experiments/chatgpt_topology_search/runs/EXP-002/verify_area7.py --reference A7-04 --points 7001 --check-saved`。CIは少点数回帰、独立54点MNA確認と7,001点の高密度走査は本実験で実施。
