# RF-T003 Phase 2 継続：6L・面積6⅔のL値上限縮小と更なる縮約探索（2026-10-13）

## 正本と試験条件

main基準コミット `dae9377d9053b9ca0193465f7d537df6c211b004`、承認済み試験`RF-T003`（可変C：対GND(5,0)×1＋非GNDブリッジ(2,3)×1、各0–4pF/Q80）。RF-T003公称試験のUL H2/H3下限**30dB**・最悪IL目標**0.30dB**。正式RF-F001の対GND可変C2個＋H2/H3公称35dBへは読み替えない。6設定の各UL/DL/H2/H3**28個別不連続区間**に対応。1Vrms Thevenin source 50Ω、固定負荷60−j40Ω、シリーズ別定数Qモデル。

既存ベースは`RFT003-6L-1GJM-3PCB-LOWIL-01`：HV Q25×6、固定GJM Q80×1、PCB-C Q40×3、チップコスト**6⅔**、IL0.297613445dB、最小H2/H3 30.003dB。もう一つのベースは最小H2/H3 30.100dB、IL0.299150613dB。L1/L4が27nH上限であるため、**6L全素子のインダクタンス上限を新しい仮の数値制約として厳しくする**。RF正式制約上限27nHを変更したわけではない。

## 更なる縮約：RF-T003成立未発見

- **Q15 1個置換、チップコスト6⅓を想定**：6素子に1つずつ仮想低Qを割り当て36局所試行。最良IL**0.300344532dB**はL1をQ15/約27nHとしたモデル値である。ただし村田製作所の公表LQP01HVの範囲は**0.3～16nH**であり、この値域外のモデルは**実製品に適合しない**。16nH以内の試行も目標ILに不適合。チップ面積費を実現したという主張はしない。外部確認先：村田製作所の[RF inductor selection guide](https://www.murata.com/en-eu/products/inductor/chip/overview/lineup/rf1)。
