# Chip–chip結合上限0.4への変更と整合専用IL感度（2026-10-10）

**フェーズ**：Phase 2内の整合専用低ロス限界探索。Phase 3はユーザー承認まで停止。
**正本**：[最新部品・コスト仕様](11_component_cost_topology_rules_ja.md) ／ [機械可読制約](../data/design_constraints_20261010.json)。

## 今回の変更

- チップL同士は、**各ペアの結合係数の絶対値 |k| ≤ 0.4** を新しい原則上限とする。旧規則の「主2組0.25／副結合0.16」は以前の探索条件として保存する。
- **新上限は全ペアを同時に0.4にする義務でも、同時実装可能性の保証でもない**。そこで全ペア同値結合と、少数ペアのみ結合する構成の両方を評価する。
- PCB-L間|k|≤0.6、chip–PCB|k|≤0.03、チップ面積上限6、PCB-L原則3本、IC可変C対GND原則2枝・各0〜4pFを維持する。今回の具体例はPCB-Lなし、GJM01なし、LQP02のみ。
- 比較条件：50Ωソース、周波数一定の60−j40Ω負荷、6設定のUL/DL全域で最大ILを最小化。**H2/H3減衰は課さない**。
- 各設定で独立に変更するのは、入力側・出力側の2つのICシャント可変Cのみ。固定Lと相互結合は6設定共通。Q_LQP02=25、Q_C=80。

## 理論直列等価回路とモデルの注意

等しいn個のLQP02を同極性・直列接続し、全チップ対の結合係数を一律kとすると、素子ごとの独立直列ESRを用いるこの集中定数モデルでは

```text
L_eff = n L_one [1 + (n-1)k]
R_eff = n omega L_one / 25
Q_eff = 25 [1 + (n-1)k]
```

となる。全結合行列の固有値はk≠0で最小1−k (k=0.4なら0.6) で、受動性が成立する。**この式では相互抵抗、近接効果、自己共振や寄生Cを考慮していない**ため、Q_eff=75を実物LQP02の物理Qとして解釈してはならない。

## 結合するペア数を限定した感度

| 結合モデル | LQP02×4：最大IL | LQP02×6：最大IL |
|---|---:|---:|
| 主2ペアのみk=0.4／その他0 | 0.13199dB | 0.14148dB |
| 隣接ペアのみk=0.4／その他0 | 0.12041dB | 0.11710dB |
| 主2ペアk=0.4／その他k=0.16 | **0.11462dB** | **0.10498dB** |
| 全ペアk=0.4 | **0.09726dB** | **0.07988dB** |

いずれも全結合行列の正定値性を確認。少数ペアしか結合できないときは、チップ数を増やすことでILがかえって悪化する場合がある（6チップ・主2ペアのみの行）。増やしたチップの物理ESRを、その磁気結合による実効Q上昇で相殺できないためである。

**実装検討上は「主2ペア0.4＋その他0.16」程度の結合パターンを比較基準として残す。** 全ペア0.4はベンチマーク上の上限を使い切った*楽観シナリオ*に分類する。これも現実の結合配置や部品間隔を検証したわけではない。

## 設計判断

- コスト–ILを実装制約へ近づけるには、|k|の上限だけでなく**結合許容ペア集合**を明記すべき。
- 次のフェーズ内探索では、面積1〜6のチップ数ごとに「結合主2ペアのみ」「隣接結合」「副結合も許可」「全ペア理論上限」の4クラスを分離する。
- H2/H3公称35dB減衰を復帰させる際も、新しい|k_chip|≤0.4、|k_PCB|≤0.6、固定GJM01＋対GND可変C≤4pF×2枝、面積≤6の**全条件を同時に遵守**する。Phase 3は停止する。
