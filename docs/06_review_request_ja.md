# 外部レビュワー向け重点依頼事項

**本リポジトリは「最良設計の公開」ではなく、低損失LPFの研究結果に対する独立した反証・改善提案を求めるための資料集です。**

## 高優先度（数値モデル）

1. **7巻線相互結合解析の符号とエネルギー収支:** `experiments/strong_pcb_coupling_theory/independent_verify.py`、`stack_refine.py`を読み、全巻線のインピーダンス行列、負荷電力、反射電力、キャパシタESRを独立に再計算してほしい。
2. **k≈0.98のモデルと損失:** 3PCB-Lの同極性直列接続による\(Q_{eq}=12(1+2k)\)が、部品Q=12と矛盾せず、どこまでの物理条件で妥当か。近接導体の相互抵抗・周波数依存Qを含めるとどう変わるか。
3. **結合行列のPSDだけで十分か:** 7巻線の全体PSD、2主結合／4副結合条件、chip–PCB≤0.03、電気的枝のループにおける符号規約が整合しているか。
4. **連続周波数保証:** 探索メッシュの間に減衰違反がないか、極値検出／区間演算／有理関数の数値安定な解析を提案してほしい。
5. **大域最適性:** 4チップL・任意個内層PCB-L・追加Cを無制限に許すと網羅はできない。物理的に意味のある有界な設計空間と、確証付き下界計算法を提案してほしい。

## 高優先度（物理実装）

6. **PCB3巻線で同時k≈0.98は成立するか:** 多層配置、共通磁束、近接効果、浮遊容量、SRF、製造ばらつきを考慮し、成立しない場合は上限を定量化してほしい。
7. **LQP02HVの特性:** 公称メーカーQを引用してQ=25を置換しない。実測Sパラメータまたは実装モデルに基づき、Q=25仮定の誤差を評価してほしい。
8. **>23dBmの非線形／ストレス:** 高調波除去のネットワークS21と、高出力時にフィルタ内部で生成されるH2/H3は別。送信電力・VSWR・温度で部品ストレスとdBcを検証してほしい。
9. **内層PCB-L面積ゼロという会計上の仮定:** チップ部品数を減らさずに基板内層を使った時の配線可能領域、ビア、損失、実装歩留まりを定量化してほしい。

## 任意の改善課題

- L3/L4を流れる通過電流を減らす、結合トランス型/ブリッジ型/シャント整合型の新構成の提案。
- IL–H2/H3のPareto境界と、バンド間トレードオフの評価。
- 50Ωと60−j40Ωへの非等抵抗終端が伝達効率に与える影響の独立照合。
- 最も少ない強結合ペア数でIL<0.30dBを維持する探索。
