# EXP-047 — RF-F003 4L・最大2可変CのFull-LPF局所最適化（2026-10-17）

**Phase 2。正式 RF-F003**（最大2独立可変C枝、各0–3pF/Q35、隣接chip-L |k|≤0.10、一列物理配置、入力・出力固定S2P必須）。RF-T005（3可変C）は初期ベクトルの参照元のみであり、今回の達成値と混用しない。EXP-047は着手前に `data/experiment_number_registry.csv` のmainへ予約済み。

## 評価モデル

- 6設定・28不連続周波数区間（`data/bands.csv`）、50Ω源、60−j40Ω負荷、外部入力S2P→LPF→外部出力S2P。LPF内部に仮想50Ω終端なし。
- LQP02HV Q25×4、配置 L0–L1–L3–L2、非隣接磁気結合公称0、強結合のsigned kは隣接3組のみ。GJM01 Q80、PCB-C Q40、IC可変C Q35（Cv0とCv2のみ）。固定L/C/kは6設定で共通。
- L枝は L0(0,1), L1(1,3), L2(1,4), L3(1,2)。固定Cは Cf0(0,1), Cf1(4,GND), Cf2(1,2), Cp(0,3)。可変は Cv0(3,GND), Cv2(1,2) の2枝。元T005のCv1(4,GND)は**存在しない**。保存29要素ベクトルの各Cv1=0は旧添字との互換プレースホルダで、第三可変枝ではない。
- S2Pのmain Git blob: input `1d46ad6f2e144ff90e6789869c8b08203dd3c41e`, output `d8f45955ce05978bd1e25c89a3578a2710735e30`。いずれも手書き回路由来の**モデルS2Pであり測定データではない**。
- 評価はin-chat実行の保存済みJavaScript（元S2Pを参照）。GitHub ActionsでEXP-047の最適化・独立MNA再実行を完了したという主張ではない。

## 必須：部品Q割り当ての訂正

初回～第2ラウンドの保存コードには **`Q[5]=80` のバグ**がある。`Q`配列における第5添字は削除済みのCv1であり、正しくは固定GJM-Cf1（index 1）をQ80にする **`Q[1]=80`** である。当初のCf1約0.48pFはPCB固定Cの承認上限0.2pFを超えるので、古いコードによる`0.982543`・`0.887183`・`0.870962dB`等を**正しいRF-F003部品モデルでの性能値として採用しない**。旧ファイルは履歴として残す。修正版の初期同一ベクトル評価は `round2_corrected_cf1_Q80_28x1001_20261017.json` で worst IL **0.859650909dB**、H2 **30.146369910dB**、H3 **30.260680292dB**、独立84点MNA PASS。

## 公差の初期感度（実行済み・限定的）

`q80_sensitivity_101grid_20261017.json` に、面積6および面積6⅔の両低IL候補について、各固定L/C±1%・k両端0.005摂動・全Cv±1%の計20単独変動/候補を保存。**いずれの単独変動でも**固定した6設定Cvのままでは28×101点の最低H2/H3=30dBを割った。これは実装公差の上限や歩留まり試験ではなく、独立単一パラメータ診断である。感度によって一時的に名目部品値制約を超える評価も、設計条件の緩和承認を意味しない。

## 判定・未解決

- **実行済み：** Q誤割当監査と訂正、RF-F003・2可変Cによる4L数値候補探索、28×1001密格子、84点別式MNA、受動電力収支、初期1%感度。
- **未達：** IL≤0.30dB、H2/H3公称35dB、旧試験の暫定IL≤0.8dB（今回の正式RF-F003目標ではない）。
- **未実施／未証明：** 連続区間の厳密極値、大域的トポロジー最適性、部品別Q(f)・SRF、実配置での同時結合と符号、PCB/IC寄生とEM、PCBパターン実面積、温度・製造公差・歩留まり、実測およびGH Actions独立再計算。
- **Phase 2継続。Phase 3は所有者承認待ち。正式RF-F003の制約は不変更。**

結論：現時点の非支配候補は面積6の0.836868dBと面積6⅔の0.833867dB。後者は面積+⅔に対しIL改善0.003001dBのみである。両者の小さい30dB余裕と顕著な公差脆弱性を踏まえ、次の最適化では**減衰余裕・感度も目的に組み込んだ新トポロジー/伝送零点再合成**が必要。
