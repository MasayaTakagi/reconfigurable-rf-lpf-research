# EXP-005：0.40dB目標・コスト7の継続探索（2026-10-12）

## 結果と位置付け

**今回の最良発見値は最大IL 0.5073307597dB、UL H2最小35.0199905dB、UL H3最小35.01999999dB。** [A7-03](A7-03.json) は、旧A7-01の**同一トポロジー**を制約付きminimax（SLSQP・補助上限変数）で再最適化した解。使用チップ面積コストは20/3=6.6667（予算7以内）、LQP02×4、固定GJM01×4、対GND IC可変C×2。PCB-LとPCBパターンCは不使用。

公称35dB以上を維持し、既存A7-01の0.5083889589dBから **0.0010581992dB** 改善した。ただし**目標0.40dBには未達**。実際に得られた数値成立解であって、「コスト7の理論限界」ではない。**SLSQPは収束成功していない**。

今回も現行仕様 [data/design_constraints.json](../../../../data/design_constraints.json) のhard cap6は変更せず、**比較用の面積予算7という明示された実験条件**である。6設定・固定Q25（チップL）/Q80（GJM/IC可変C）・入力50Ω・負荷60−j40Ω・H2/H3公称35dBを固定する。

## 技術的な知見

1. 現行2可変対GND C制約では、旧CP07の4自由度（3直列可変C＋1可変シャントC）に相当する独立伝送零点の協調移動が未解決。0.32dB案は現行ポリシーに適合せず、現行ベースラインとしない。
2. A7-01の局所解の未収束を解消すると、構造を維持しても**約0.001dB**程度改善できた。単なる部品数増加は今回の優先試験では十分な改善を示さなかった。
3. 目標0.40dBとの差は現最良で**0.107331dB**。可変Cの作用先を変える新たなグラフ群の追加と、効率化した多初期値最適化が必要。
4. PCBパターンCは**0.02～0.2pF、Q40、最大3、コスト0**を守る。今回の24＋36件の試験は1個のみであり、2・3個を用いる網羅探索ではない。
