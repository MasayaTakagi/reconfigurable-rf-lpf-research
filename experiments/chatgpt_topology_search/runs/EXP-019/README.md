## 制約と目的

試験ID **RF-T004**（正式RF-F002を基準、実効SHA256 `c66302a281a1fdb88da355fc44dac1ef3b1c4e18e8ff297db9e842b219b5b0c4`）を明示適用。LQP02HV Q25（0.4–27nH）・LQW04 **仮定Q33**・GJM01 Q80・PCB固定C Q40（各0.02–0.2pF、最大3）・可変C Q50（各0–1.5pF、最大3）・チップ物理一列隣接|k|≤0.15と非隣接公称0。50Ω源、60−j40Ω一定負荷、6設定のUL/DL/H2/H3全連続区間を個別評価。面積6は実用目安であり形式的ハード上限ではない。

## 再検証（このレビューで再実行済み）

- 独立実装の集中定数回路解析により、**28連続周波数区間×14,001点**の全バンド最大IL・最小減衰を再計算。
- インダクタ枝電流を未知数に取る**12×12 MNAを84周波数点**で解き、節点5×5縮約法との最大電圧差 **5.48e−15V**、最大電力収支残差 **2.37e−17W**を確認。正規化インダクタンス結合行列の最小固有値 **0.773126**（SPD）。
- LQP02HV値0.4～27nH、3可変C0～1.5pF、PCB-C3個各0.02～0.2pF、隣接6結合のみ|k|≤0.15、部品面積計算を再照合。
- 結果：IL **0.3148244235dB**、H2 **35.0099999984dB**、H3 **35.0099999982dB**。**35dBは成立、0.30dBは未達**。2つの異なるMNA形式で代表周波数の整合と電力収支を確認しただけで、全連続周波数の数学的証明ではない。

## 未検証と解釈

- LQP02HVが**27nHに2本**張り付き、SRF・Q(f)を含む実メーカー素子モデルなし。LQW04 Q33もモデル仮定であり、特定品番・SRFや実Qは未検証。
- 物理的に隣接するkが**+0.15に複数箇所**張り付き、符号や同時実現のレイアウト根拠なし。
- PCB-C 0.02pFに2枝張り付き、実PCB占有・寄生・公差・EM未評価。
- H2/H3余裕約0.01dB、ILは0.30dBより0.014824dB大きい。量産対応可・仕様達成の主張はしない。
- 5L/6L/7L/8Lの比較は異なる部品数・限定したトポロジー群の**best-found**であり、低面積の理論限界ではない。

**次ゲート**：LQW04×1のままIL≤0.30を目指すなら、単純な並列L追加より、共振器機能と損失電流の再分配を伴う新しい構成が必要。RF-T004は試験研究のみ。**Phase 2継続、Phase 3停止。**
