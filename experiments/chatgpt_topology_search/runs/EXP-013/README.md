## 実際に完了した一次探索

詳細は [screening_summary.json](screening_summary.json)。最適化の局所有限開始点ごとに成功フラグ・粗201点評価・エラーを記録。**347試行**の一次探索と**9試行**の物理順序精密化を実行した。ランダム初期値や繰り返し計算が含まれ、347種類の固有グラフを網羅した意味ではない。

- PCB固定C 1枝：45試行（15配置、最大3開始点）。
- PCB固定C 2枝：28試行（基準Cpcbに14枝追加、各2開始点）。
- PCB固定C 3枝：91試行（基準Cpcbのほか2枝追加、各1開始点）。全91候補を完走。
- 物理L一列配置：24試行（向きの重複相当を含む12順序×2開始点）。高密度の候補を9追加試行で精密化。
- 第3可変C枝：18試行。残る第1可変C枝変更17試行、第2可変C枝変更14試行。いずれも一部未収束・非成立。
- チップL単独枝接続変更：60試行（枝方向が逆で等価なケースも含む）、チップL0/L3を2本同時に移動：48試行。多くが減衰不成立／SLSQP未収束。固定主経路から良好な成立解を見つけられていない。
- 基準回路の局所再最適化：2試行。

**探索範囲の限界:** この探索は非凸局所最適化であり、L枝多初期値・L複数枝の広範囲組み合わせ・PCB-Cと可変Cの同時移動を網羅していない。単に未収束の候補や一つの初期値を計算しただけで、その回路の性能限界と断定しない。0.3 dB達成不可能という証明ではない。
