# Phase 2 基礎研究追補：π型の中央シリーズLと左右シャントLの2組結合

- 日付：2026-10-16
- 状態：**理論導出 + 限定した1GHz/2GHz数値ベンチ実行済み**。50Ωの単点のみで、正式EXP-NNNの体系的探索ではない。
- 研究スコープ：LPF・LTE帯域・面積制限とは独立。現行RF-F003の変更もPhase 3移行も行わない。EM・実測・Q(f)/SRF・相互抵抗は未実行。

## 1. 対象回路

```
                 Is ->
 IN ---o----------Ls----------o--- OUT
       |                      |
       La (Ia downward)       Lb (Ib downward)
       |                      |
       Ca                     Cb
       |                      |
      GND                    GND
```

Ca,CbはシャントLに直列の**理想C**。純シャントLは低周波を短絡するため、LPFでの採用を仮定しない。枝インダクタンス行列は枝順(s,a,b)で

\[
L=\begin{bmatrix}
L_s & k_{sa}\sqrt{L_sL_a} & k_{sb}\sqrt{L_sL_b}\\
k_{sa}\sqrt{L_sL_a}&L_a&0\\
k_{sb}\sqrt{L_sL_b}&0&L_b
\end{bmatrix},
\quad R=\omega\operatorname{diag}(L_s,L_a,L_b)/Q_0.
\]

参照電流はIsを入力→出力、Ia/Ibを各入力/出力ノード→GNDの向きにとる。左右シャントL間の直接結合k_ab=0を公称とし、\(\lambda_{\min}(K)>0\) を検査。|ksa|=|ksb|=kならSPD条件は \(k<1/\sqrt2\)。

**T型との差異：** T回路では3枝に周波数非依存の電流KCL \(I_1=I_2+I_3\) を適用できるが、このπ型3枝にはその同一の拘束を適用できない。π型には代わりにノード電圧/枝電圧のKVL関係がある。Tに固有の「2組結合で全モードQ≥Q0」の数学的証明をπ型へ流用しない。

\[
Q_\mathrm{mag}
=\frac{\omega I^\dagger L I}{I^\dagger RI}.
\]
特に等自己L・等Qで符号 \(k_{sa}=+k,k_{sb}=-k\) とすると
\[
Q_\mathrm{mag}/Q_0 =
1 + \frac{2k\,\mathrm{Re}\{I_s^*(I_a-I_b)\}}
{|I_s|^2+|I_a|^2+|I_b|^2}.
\]
Q改善にはシャント**差動電流**とシリーズ電流の相関が正であることが必要。符号の逆転はQ改善条件も反転する。ただし現実のシャント電流は相互結合によって変化するため、電力伝送は回路全体で解く。

## 2. 決定論的πベンチ（算術実行済み）

条件：f=1GHz、Rsrc=Rload=50Ω、Vs=1Vrms、Ls=6.36619772nH（1GHzでX=+40Ω）、La=Lb=5nH、全コイル単体Q=25一定、Cと結合は理想、Mab=0。各シナリオの**無損失**回路について、左右のシャントCを個別に解いて1GHzで理想整合(\(\Gamma=0\))に合わせ、その**同じC値**のままQ=25の損失回路を評価する。基準C=1.211078pFはシャント枝リアクタンス−100Ωを与える。測定由来のモデルではない。

| ksa / ksb | Ca=Cb (pF) | 1GHz IL (dB) | Qmag | コイル損失 (mW) | 2GHz減衰 (dB) |
|---|---:|---:|---:|---:|---:|
| 0 / 0 | 1.211078 | 0.227139 | 25.000 | 0.253532 | 43.087 |
| +0.1 / −0.1 | 1.128192 | **0.199417** | **23.993** | **0.223405** | **14.644** |
| −0.1 / +0.1 | 1.377606 | 0.287683 | 26.818 | 0.318566 | 26.457 |

k=+0.1/−0.1 は基準に対し1GHzのILが0.027721dB改善、コイル損失が約11.88%減、**しかしインダクタ群の磁気Qは低下**している。逆極性はQ上昇にもかかわらずIL悪化。従って磁気Q最大化と最小IL設計を混同しない。

この3ケースの1GHzコイル損失枝別（シリーズ、左シャント、右シャント。mW）：
- 基準：(0.191711,0.032011,0.029810)
- +0.1/−0.1：(0.174708,0.025165,0.023531)
- −0.1/+0.1：(0.223763,0.049292,0.045511)

**重大な反例:** 2GHzの減衰は43.087→14.644dBに悪化。これはシャントLC共振ノッチ位置と電力伝送零点が結合で移動したことを示す特定の周波数での観測であり、全帯域の最小減衰や高調波特性の予測ではない。シャントCの再設計、全周波数最適化、結合公差が不可欠。

## 3. 回路解析と再現

枝接続行列
\[
A=\begin{bmatrix}1&-1\\1&0\\0&1\end{bmatrix};
\quad Z_\mathrm{branch}=R+j\omega L+
\operatorname{diag}(0,1/j\omega C_a,1/j\omega C_b).
\]
節点電圧Vと枝電流Iを
\[
I=Z^{-1}AV,\quad
(A^TZ^{-1}A+G)V=J,
\]
\(G=\mathrm{diag}(1/50,1/50),J=(1/50,0)^T\) から解いた。独立に5×5枝電流MNA
\[
\begin{bmatrix}G&A^T\\-A&Z\end{bmatrix}
\begin{bmatrix}V\\I\end{bmatrix}
=\begin{bmatrix}J\\0\end{bmatrix}
\]
で照合。全3ケースで複素電流一致1e−12A以内、電力保存残差1e−13W以内。有限数値ベンチであり、RF-F003全帯域の検証でも高調波仕様達成でもない。

## 4. 技術評価

- 中央シリーズLを左右シャントLと結合するπ型は**有望な独立トポロジー候補**。各シャントLCに共振・減衰零点形成を兼用させられる可能性がある。
- ただしT型におけるシリーズ枝「Lだけの選択的等価強化」や全モードQ非劣化証明はπ型へ直接転用できない。
- π型はシャントLC 2枝が必要で、L3個だけで見た比較ではコスト/寄生/損失が過小評価される。
- T/πで公平に優劣を判断するには、同一周波数範囲・同一負荷/源・同一部品Q・同一高調波減衰と同一実装資源を与えて再合成比較する必要がある。
- 今回は正式EXP番号の事前予約がないため、初期値・位相・結合・全帯域を大規模探索する新規実験runには着手していない。
