# 旧仕様文書リンクの互換エントリ

このパスは `data/design_constraints.json` 内の `canonical_docs` が参照する旧文書名です。

**設計制約の機械可読な正本は [data/design_constraints.json](../data/design_constraints.json) です。**

現行の説明文書は[設計仕様](specification.md)、現行の開発計画は[Phase 2ロードマップ](roadmap.md)、探索方法の分担は[アーキテクチャ](architecture.md)を参照してください。

リンクの互換性維持を目的とし、このファイルに別の制約値や緩和条件は定義しません。
