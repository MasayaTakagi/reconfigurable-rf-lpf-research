# 設計仕様・制約（2026-10-10 時点）

**新しい部品分類・コスト・容量配置規則の正本：** [11_component_cost_topology_rules_ja.md](11_component_cost_topology_rules_ja.md)（機械可読：[../data/design_constraints_20261010.json](../data/design_constraints_20261010.json)）。旧数値結果には新ルール未適用のものがある。

## システム機能

1つの共通RFネットワークを、6つのバンド設定で動作させる。固定Lとその相互結合は全設定共通。設定ごとに可変Cの容量値を変更する。B13+B14は同一の容量設定で両バンドをカバーする。**今後の設計ではGJM01固定チップCと、IC内の可変Cを区別する。固定Cは全設定共通、可変Cだけ設定別に連続値0〜4pFで最適化する。** スイッチドCの離散化はPhase 3でユーザー承認を受けた後のみ着手可能。

## 目的関数（現行Phase 2）

- 最小化するのは **6ケース、各UL/DLすべての通過帯域における最大挿入損失**。
- 必須阻止：各ケースULの2倍波と3倍波の **全域で30dB以上**。
- 探索公称阻止の目標は35dB（スクリプトによって35.05 / 35.10 / 35.15dBの丸め余裕がある。比較表には実値を示す）。
- 新しい公称最大ILの挑戦目標は0.30dB以下。未達時にも未達を報告し、不適合解を性能比較から除外する。

## 回路・部品モデル

| 項目 | 現行モデル | 未確定事項 |
|---|---|---|
| 信号源 | 抵抗50Ω | 非理想PAの出力インピーダンス |
| 負荷 | 60−j40Ω・周波数一定 | 実負荷の周波数・電力・温度依存 |
| LQP02HV相当chip-L | Q=25定数、面積1単位 | 実Q(f), SRF, ESR, ばらつき |
| **LQP01シリーズchip-L** | **Q=15定数、面積2/3単位** | 可用L値、実Q(f)、SRF、部品選択 |
| LQW04系chip-L | 面積3単位、Q未合意 | Q仮定を明記してから評価 |
| 内層PCB-L | Q=12定数、1本あたり概ね3nH以下、**原則3本以内** | PCBスタックアップ・配線・結合・ビア |
| **固定チップC：GJM01シリーズ** | **Q=80（暫定）、各素子100pF以下、面積2/3単位**。直列・シャント等を許容、値は全設定共通 | 実Q(f)、SRF、電圧定格 |
| **IC内可変C** | **Q=80（暫定）、1枝の可変容量合計0〜4pF、原則2枝以内、対GNDのみ**。固定Cとの並列可 | IC実装・寄生・Ron/Coff、直列配置は個別承認 |
| chip-chip結合 | **単列配置の隣接強結合のみ \(\lvert k\rvert\leq0.4\)**。非強結合ペアは公称 \(k=0\)、弱結合感度で \(\lvert k\rvert\leq0.1\)。全結合行列正定値 | 非隣接強結合・2D配置は不許可。配置順序・結合グラフを6設定共通とする。[詳説](15_chip_strong_coupling_layout_proposal_ja.md) |
| chip–PCB結合 | すべて \(\lvert k\rvert\leq0.03\) | 実装公差 |
| PCB–PCB結合 | **原則各ペア \(\lvert k\rvert\leq0.6\)**、全L結合行列の正定値も必須 | 過去のk≈0.98は例外的理論研究として履歴保存 |
| 電力 | >23dBmを想定 | 最大値、CW/変調波、負荷VSWR、電流・ピーク電圧 |

**新しいコスト評価:** チップ面積コスト `A_chip = N_LQP02 + (2/3)N_LQP01 + 3N_LQW04 + (2/3)N_GJM01` を主軸とし、チップ部品点数、PCB-L本数、IC可変C枝数を別途記録する。**新しいコスト–ILトレードオフ探索の面積上限は6単位（旧4単位から拡張）。** 過去の実験での旧面積制約は履歴として保持し、新仕様適合には再評価を要する。PCB-Lの面積0はあくまでチップ部品面積換算であり、配線・ビア・寄生が存在しないという意味ではない。

## 設計上の除外事項

- Murataが公開した公称Qをそのまま回路Qの代用にしない（ユーザー決定）。
- 量産公差込み最大IL、最悪条件高調波抑圧、EM設計、部品定格、大信号非線形はPhase 2の現行結果では保証していない。
- コイル間の結合行列を正定値にすることは必要条件であり、現実の磁界配置の十分条件ではない。
- **Phase 3には進まない。**
