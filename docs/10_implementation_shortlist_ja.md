# 実装検討ショートリストと採用ゲート（2026-10-10）

**結論:** 当面は **I-01（4チップL+4C）を基準試作候補**とし、**I-02（弱結合PCB-L追加）とI-03（PCB-L間結合追加）を条件付き比較候補**として保存する。3PCB-L間ほぼ完全結合の **T-01は理論研究候補であり、PCB実装候補には認定しない**。これは試作品製作の承認でも、部品の実装適合性を保証するものでもない。

## 設計仕様と検証レベル

- 6バンド設定（B13+B14は1設定）、各UL+DLすべての通過域で**最大IL**を比較。各UL全域の2倍波・3倍波の**最小減衰**を評価。必須30dB、Phase 2の公称比較基準35dB。
- 入力50Ω、負荷60−j40Ω（全周波数一定）、chip Q25・PCB Q12・C Q80。Cはすべて**連続値モデル**であり、離散スイッチ実装前。
- chip-chip：主結合2組 |k|≤0.25、残り4組 |k|≤0.16。chip–PCB：|k|≤0.03。PCB–PCB：結合行列の受動性のみ理論上の上限とし、採用前にはEM/製造上の根拠が必要。
- ILと減衰値は最適化＋細かい周波数走査（局所極値探索を含むものあり）に基づく。**連続周波数の厳密保証、実部品実測、公差最悪値、大信号確認、EMモデルは未完了**。
- PCB-Lは**チップ部品面積0単位として会計**。しかし基板層/ビア/ルーティング/寄生は実際に必要。
- メーカー公称Qの流用は禁止。これまでのQ固定値を変更する場合は独立した実測資料と再モデル化が必要。

## I-01：実装検討の基準回路

```text
IN ──[L1∥C1]── n1 ──[L4∥C4]── n2 ──[L3∥C3]── OUT
                                  |
                                  L2
                                  |
                                  C2
                                  |
                                 GND
```

固定値（nH）：L1=0.4000000、L2=5.2045999、L3=3.9740544、L4=3.9698284。

結合係数：k12=+0.1600000、k13=+0.0207054、k14=+0.1322007、k23=−0.2500000、k24=−0.0824688、k34=+0.0847176。

固定値は6設定共通、バンドごとのC1～C4は以下に収録：
- [全設定C値＋通過損失・高調波減衰](../experiments/phase2_4chip_baseline/dense_verification.csv)
- [モデル・最適化制約](../experiments/phase2_4chip_baseline/README_ja.md)

**採用理由:** 35dB公称減衰、最大IL 0.33dB未満を同時に満たす現行Q25モデルの最小チップ4L構成。PCB-L–chipの複雑な磁束経路を必要としない。

**注意点:** L1が探索下限0.4nHに接する。特定実部品のQ(f)、ESR、自己共振、実装パターンの寄生を確認する。chip-chip k23=−0.25・k12=+0.16など複数組の意図的結合が必要。独立ばらつき試験で量産適合は未確認。

## I-02：磁気結合を主目的にしないPCB-L追加型

接続定義（I-01を共通母体とし、節点n1 = L1後、n2 = L4後）：

- PCB-L5–C5：n1→GND
- PCB-L6–C6：n2→OUT、L3∥C3と並列
- PCB-L7–C7：IN→n2、L1/L4をまたぐブリッジ
- PCB間の相互結合=0。chip–PCBの3組はそれぞれ |k|≤0.03。

数値比較の最大ILは0.324314dB。**B8・960MHzの1W正規化比較では、素子内部損失が69.70→70.94mWに増えており、反射電力3.24→1.02mWへの改善が主因**。高周波で「巻線追加すなわち内部損失低下」と説明してはならない。

証拠：
- [固定L・chip間およびchip–PCB結合値](../experiments/weak_pcb/best_components.csv)
- [6設定C1～C7](../experiments/weak_pcb/best_band_caps.csv)
- [高密度周波数解析](../experiments/weak_pcb/dense_verification.csv)
- [損失内訳・容量感度](../experiments/weak_pcb/REPORT_ja.md)

**採用ゲート:** I-01と同じEM/部品モデルで `maxIL` の改善が一貫して正であること。0.1pF付近の容量について、寄生・ばらつきで35dB公称／30dB必須の余裕が消えないこと。増やしたPCB巻線と3個のCの配線・寄生を定量化すること。

## I-03：PCB-L間磁気結合を利用した機能分担

I-01への追加接続：
- PCB-L5–C5：n1→GND
- PCB-L6–C6：n2→OUT
- PCB-L7–C7：n1→n2（L4∥C4と並列）

最良保存解の固定値（nH）：チップ L1=0.412505、L2=5.585453、L3=3.730311、L4=4.089504。PCB-L L5=3.000000、L6=3.000000、L7=0.800108。

PCB間：k56≈+0.0930、k57≈−0.2000、k67≈−0.2000。chip–PCBは各 |k|≤0.03。チップ間の全6組も回路モデルに含まれ、詳細は元データ参照。**3個のPCB-Lが3つの結合係数を同時に満たす配置を確認することが必要。**

証拠：
- [固定Lと全k](../experiments/pcb_pcb_coupled/physical_components.csv)
- [6設定C1～C7・性能](../experiments/pcb_pcb_coupled/six_case_verified.csv)
- [B8電力内訳と感度](../experiments/pcb_pcb_coupled/REPORT_ja.md)

**採用ゲート:** PCB間の実際のk・位相/極性をEMで同時に実現できること。各バンドでCの必要範囲（0.1pF下限を含む）と実基板寄生の整合性を確認すること。I-02との差は僅少（最大IL約0.00092dB）なので、EMと公差評価で優劣が逆転すればI-03を除外すること。

## T-01：理論目標に対する位置付け（**PCB実装案ではない**）

数値モデルで kPCB=0.98、3PCB-L各約0.708nH、Q12、同極性直列として実効Q≈35.52を得る。この実効Qは巻線間の損失相関を無視した理想モデルに依存する。保存済み結果は最大IL0.295208dB・高調波最小減衰35.10dB。k=0.95でも最大IL≈0.297578dB、k=0.90では≈0.301735dBで、`0.30dB`目標未達だった（それぞれ最適化し直した数値）。

- [k別・6設定結果](../experiments/strong_pcb_coupling_theory/stack_band_verified.csv)\n- [k別の固定L・結合・各設定Cを含む最適化ベクトル](../experiments/strong_pcb_coupling_theory/stack_k_sensitivity.json)
- [独立7巻線式との照合](../data/independent_validation/independently_verified.json)
- [理論モデル・解析コード](../experiments/strong_pcb_coupling_theory/stack_refine.py)

**実装候補への昇格条件:** 物理スタックアップ・コイル配置を提示し、結合行列と共通/相互抵抗・寄生容量を含むEM抽出で性能が再現し、製造上のk散らばりと温度、SRF、大信号特性を評価する。条件を満たすまでは本リストのI-01/02/03より優先しない。

## 試作・ロバスト性検証のゲート（Phase 3の承認ではない）

| ゲート | 要求する成果物 | 不合格の場合 |
|---|---|---|
| G0：比較条件統一 | 35.00/35.05/35.10dBの閾値を統一し、同じ周波数集合・損失定義で全候補再評価 | 数値による順位付けを保留 |
| G1：素子モデル | 特定L/Cの実測・SパラモデルによるQ(f)、ESR、SRF、容量上限/下限 | 理想Q結果を実装根拠に使わない |
| G2：結合・EM | chip-chip、chip–PCB、PCB–PCBの全結合を同一レイアウト上で抽出し、正負符号を照合 | 成立しない候補を除外 |
| G3：寄生・変動 | C/L/k/温度/基板差のシナリオ・統計・最悪変動でIL/H2/H3評価 | チューニング可否やトポロジーを見直す |
| G4：大信号 | >23dBmに対するピーク電圧/電流、VSWR、部品定格、非線形H2/H3 | 大信号設計を再検討 |
| G5：試作判定 | 6設定の通過IL・H2/H3とモデルの一致、実装工数/面積/ばらつき | 次候補へ切替 |

**G0–G5は回路研究と実装可否判断のための定義であり、スイッチドCのビット割当・コード探索（Phase 3）を開始する許可ではない。Phase 3はユーザーの明示承認まで停止。**
