# EXP-018 — RF-T004 Phase 2 面積コスト削減探索（2026-10-13〜14）

**試験制約RF-T004（RF-F002正式版ベース）を明示適用。Phase 2継続・Phase 3停止。** 本ページの値はローカルで実行した有限SLSQP局所探索の**集中定数・一定Qモデル上の数値値**。実装SRF・Q(f)・PCB EM・磁気結合の同時実現性、量産性は未確認。

## 目的と検証
EXP-017の5LQW04＋4GJM01＋3可変C（面積17⅔、最悪IL0.299962482dB、H2/H3≥35.007997dB）を起点に、**35dB以上の公称H2/H3減衰と6設定UL/DL最悪IL≤0.30dBを維持し、チップ面積を極小化**する。実用的な**面積6は参考目標**であり、RF-F002のハード制約への変更ではない。

試験実効制約SHA-256 `c66302a281a1fdb88da355fc44dac1ef3b1c4e18e8ff297db9e842b219b5b0c4`（RF-F002正式 `f20d27e93451dcec2f823e6f7c3731c06d843050c4d2ace8b0b46ded605542e2`）。源50Ω、負荷60−j40Ω、`data/bands.csv`にある全6設定UL/DL/H2/H3の不連続区間ごと高密度評価。LQP02HV Q25・0.4〜27nH、LQW04 **仮定Q33**（**メーカーのL範囲とSRFの裏付けなし**、この有限探索では0.4〜27nHの局所探索数値箱を使用）、GJM01 Q80、PCBパターン固定C Q40・0.02〜0.2pF・最大3個、可変C Q50・0〜1.5pF・最大3独立枝。チップLの一列配置・隣接強結合 |k|≤0.15、その他公称k=0。PCB-L不使用、インダクタンス行列SPD。

## C13.667 の回路チェックポイント

- インダクタ枝：L0(1–2)=3.274568nH LQW04；L1(3–4)=26.807794nH LQP02HV；L2(2–5)=3.821500nH LQP02HV；L3(2–3)=11.676313nH LQW04；L4(2–3)=9.021334nH LQW04。
- 物理一列L0–L1–L3–L4–L2、隣接k=[+0.101258,−0.113165,+0.150000,−0.150000]。全固定素子/結合は6設定で共通。
- 固定GJM：Cf0(1–2)=2.417674pF、Cf1(5–GND)=1.143771pF、Cf2(2–3)=0.835750pF、Cf3(3–4)=0.100000pF。

- IC可変C：Cv0(4–GND)、Cv1(5–GND)、Cv2(2–3)、6設定容量は `EXP018-C13.667.json` を参照。
- H2/H3余裕約**0.02dB**、IL余裕約**0.002886dB**と小さい。B71でCv2=1.5pF上限、Cp2=0.02pF下限、LQP02HV 26.81nHが27nH上限付近。**実装ロバスト性の証明ではない**。

## 再検証と限界
計算式 `Z_L=ω[diag(L/Q)+jM]`、`Y_C=ωC/(1/Q−j)`、`IL=−10log10(Pload/Pavs)`。全6設定・28連続区間（B13+B14のギャップを結合しない）各14,001点と、84点の独立電流MNA（5Lは10×10、4Lは9×9）、SPD・電力収支を実行。新規C13.667の最大電圧不一致4.67e−15V、電力不一致1.28e−17W。局所ソルバの収束と連続周波数の大域的保証を混同しない。

**課題：** LQW04実部品Q(f)/SRF、LQP02HV 26.8nHのSRF、同時|k|≈0.15とドット極性、PCB-C=0.02pFのEM／公差、許容差下での再チューニング。PCBパターンCのチップ面積係数0は**実際のPCB占有面積0を意味しない**。面積6で0.30dBを目指すなら単純な高Q→低Q部品置換より、多モード共振／新C位置／PCB-L（Q12/≤2nH、chip–PCB k=0）を使った回路再合成が必要。
