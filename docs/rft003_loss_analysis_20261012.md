## 計算の定義と検算

1V RMS、電源50Ω、負荷60−j40Ω固定、利用可能電力`Pavs=5mW`。全設定・全UL/DL個別周波数区間各**7,001点**で局所最悪周波数を特定し、そこで9×9拡大MNAの`I_L`、キャパシタ枝電流`I_C`を使用して`P_L=|I_L|²ωL/Q`、`P_C=|I_C|²/(ωCQ)`を計算。入力の反射`P_ref`は**部品発熱ではない**。`Pavs = Pload+Pref+ΣPL+ΣPC`を確認し、独立に組み立てた5×5縮約アドミタンス行列の利得と照合。コイル間の相互誘導項は**無損失・実対称**の相互インダクタンスとして扱うため、「コイルごとのジュール損失」は自己抵抗の各電流二乗項で求める。全Qは一定仮定。計算スクリプト[`scripts/analyze_rft003_loss.py`](../scripts/analyze_rft003_loss.py)と回帰[`tests/test_rft003_loss.py`](../tests/test_rft003_loss.py)。

**電力（mW）で分解し、素子別にdBを足し合わせていない。** 総ILはPload/Pavsの対数であり各成分のdB単純加算は厳密でない。個別Q→∞解析は素子値/可変設定を固定した仮想感度で、全体再最適化後の改善予測ではない。

**3C-HVのB28では**L0は0.11015mWに増えているものの、L2は0.01180mW（T003の約23%）、対GNDシャント可変C損失のうちnode5側は0.02197mW（T003 node5可変Cの約38%）になっている。**3C-HQのB28では**L3=0.11558mW（T003の約64%）で、反射電力もほぼ同水準。3C HQ×1のL1≈52.6nH/Q20は製品SRFリスクが高く、Q25へ読み替えてはならない。3C HV×4でもIL=0.321403dBと、2C-T003より良いが0.30dB未達。

**原因の限定**：素子値・L1値・物理配列・k・枝数が同時に異なるので、3本目の可変Cだけに0.055–0.075dB改善の因果効果があるとは言えない。独立したアブレーション（同一グラフ/同一部品設定からC調整自由度だけを増減）が必要。

3Cではnode4側シャントCも設定別に変えられ、HQ案では0.134–0.283pF、HV案では0.180–0.433pF。一方T003ではnode4–GND固定C=0.522225pF。L1とこのCだけを取り出した孤立LC共振の粗い推算はT003≈2.193GHz、3C-HQ≈1.305–1.895GHz、3C-HV≈1.527–2.370GHz。**実回路は磁気/容量結合があるため孤立LC値を回路の真の伝送零点と同一視しない。** ただし固定化で失われた共振モードの周波数依存性を示す比較指標にはなる。

## 推奨するPhase 2探索（未実行）

**P1：L3経路の電流再分配を起点にグラフ再合成**。いまのL3=(2,3)に電力が集中し、2組の隣接kが|0.4|上限にある。L3の電流を増やさずに信号をIN→OUTへ移す固定経路（追加L並列/複数インダクタの電流分流経路、LCブリッジ/サイド枝、L3接続の別形態）を有限トポロジー列挙し、固定L/C/k・Cvを共同再最適化する。チップ面積の正式hard capなし。**ただし追加L自体にも損失と面積があるので、0.30dB達成を保証しない。**

**P1：3Cシャント可変化の役割を固定/共有受動網で近似**。3C-HV候補を新しい種にし、node4固定Cを0.1–0.45pF程度の探索初期値から、L1/L2値・chip-row/隣接k・固定GJM(4,5)・固定PCB-C(0.02–0.2pF,Q40)・容量分圧/結合ブリッジを**一体的に**再最適化する。1本の対GND Cv(5,0)が2本の共振モードに作用する多モード構造を検討。従来の単独(4,5)GJM追加は30dBでIL≈0.44323dBと現行0.37650dBより悪かったため、**単に1枝を追加して終える案では不十分**。

**P2：非GNDブリッジ可変Cの接続位置・高バンド端点の検討**。現行ブリッジCv=(2,3)はB8でC=0の境界、T003でB8がIL最悪の一つ。固定導通経路をバイパスする別の橋絡端点(1,3)/(1,5)/(2,4)等をグラフチェックし、可変CがB8でも有効に最適化される構造を試す。**主経路直列可変Cは禁止**。B8整合だけではB28のILボトルネックが残る。

**P2：低ILと減衰余裕の多目的探索**。現最良の最小H3約30.000828dBは公差余裕がほぼ0。目標30.1/30.3/30.5dB、チップ面積コスト、最大L/HQ数、結合上限kのマージンをパレート化。同じ各区間7,001点＋独立MNAで昇格候補を比較する。

**方法上の推奨**：3C HV3Cを種とする`(4,0)可変→固定`統合と、L3の接続変更を独立要因の2×2比較として、最初は6設定の通過帯域の`I_L3² R_L3`と全UL H2/H3余裕を同時に可視化。改善候補のみ大規模Actionsへ。IL・減衰・コスト・回帰再現性を分けて保存する。Phase 2継続、Phase 3への移行は未承認。
