- 双方の候補を各独立周波数区間**7,001点**で再評価。別実装の独立枝電流9×9MNAで84代表周波数を照合した。30dB候補の最大IL差8.38×10^-13 dB／電力残差9.54×10^-18W／K最小固有値0.83959。35dB候補は最大IL差8.74×10^-13 dB／電力残差5.45×10^-18W／K最小固有値0.84952。

- 独立MNAの再評価用スクリプト[verify.py](verify.py)を新規追加。**リポジトリ内での実行・回帰CI PASSは未確認**。この環境での既存MNAとは別に、モデル一致確認を行うためのコードである。
- 名目35dB条件もわずか0.02dB余裕。温度・部品公差・スイッチ寄生・LQP02HVのSRF/Q(f)・PCB/IC配置のEM実装性は未検証。有限局所探索を物理性能限界／大域最適値と扱わない。
