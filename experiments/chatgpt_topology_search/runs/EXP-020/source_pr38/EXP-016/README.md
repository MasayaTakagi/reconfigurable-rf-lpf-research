参照：`data/constraints/trial/RF-T004.json`（Git blob SHA `765d0dd14d88bb7c91d1303ed896ae69132997f6`）、`data/constraints/formal/RF-F002.json`（blob `0417b0bbc0f44bf58db102da6d65107c71af77a5`）、`data/bands.csv`。RF-F002の台帳掲載effective SHA256は`f20d27e93451dcec2f823e6f7c3731c06d843050c4d2ace8b0b46ded605542e2`。**RF-T004オーバーレイ後の実効SHA256とソースコミットSHAは本ローカルrunでは記録できていない。** 次のCI実行前に正規制約ローダで算出し、マニフェストにピン留めすること。

50Ω電源、60−j40Ω負荷、6設定UL/DL全連続区間の最大ILとUL-H2/H3全連続区間の最小減衰。GJM01 Q80、LQP02HV(0.4～27nH,Q25)、可変C最大3本(各0～1.5pF,Q50)、チップLの一列隣接|k|≤0.15、非指定ペアの公称k=0、PCB-Lなし。面積ハード上限なし。

回路解析は結合コイルのZ行列 `Z_L = omega*(diag(L/Q)+1j*M)`、キャパシタY `Yc = omega*C/(1/Q-1j)`、負荷アドミタンスを含むMNA。IL=`-10 log10(Pload/Pavs)`。epigraph SLSQPの局所最適化、30.02dBまたは35.01dBの高調波下限を置いた。公称35dB以上と必須30dB以上は別集団として比較する。

各6設定の全UL/DL/H2/H3の不連続区間を別々に**7,001点/区間**で評価。9×9インダクタ枝電流独立MNAを**84点/候補**で実行し、5×5消去式との電圧差最大<6e−15V、最大電力収支残差<8e−18W、インダクタンス行列正定値（λmin(K)>0.78）を確認。対象は6候補。

RF-T004-B35の最悪IL点B28 DL端803MHzでは、入力反射は利用可能電力の約0.0074%、L3損失約4.293%、L0損失約2.224%。整合のみよりコイル損失・電流配分削減が次の研究の主眼。
