## 1. 研究課題と成功判定

ユーザーの探索目標は、旧W3-F4（チップ面積8⅔、IL=0.298355657dB、H2/H3最低約30.02dB）の性能を維持しつつ**チップ面積コスト6**を目指すこと。RF-T004自体は面積の**ハード上限なし**であり、6は今回選択した有限探索予算である。

評価は、6設定B71/B12/B28/B13+B14共通/B26/B8のそれぞれのUL・DL全通過区間の最大ILとUL-H2/H3全阻止区間の最小減衰。B13+B14の不連続区間は連結せず評価。50Ω源、周波数一定の60−j40Ω負荷。全設定共通の固定L/C・枝接続・チップ一列順・結合係数に対し、6設定別のIC可変C値だけを変更。

適用数値条件：LQP02HV 0.4–27nH/Q25、LQP02HQ 0.2–56nH/Q20、GJM01 Q80、PCBパターン固定C 0.02–0.2pF/Q40・最大3個、IC可変C 0–1.5pF/Q50・最大3独立枝。物理一列の隣接強結合のみ|k|≤0.15、非強結合ペアの公称k=0、L行列SPD。IL目標0.30dB、H2/H3最低必須30dB、公称目標35dB。

**実績判定：今回の面積6探索ではIL≤0.30dBとH2/H3≥30dBを同時達成した候補は未発見。** 最低観測IL=0.305481244dB。差は+0.005481244dB。これは有限局所探索のbest-foundで、理論下界・不可能性証明ではない。

上記差分は**構造変更と全パラメータ再最適化の組合せ**による差であり、部品1つの因果的性能寄与とは解釈しない。また順序0と後続は高調波余裕がわずかに異なるため厳密な同閾値比較ではない。

観測される設計教訓：
1. **結合強度増加や高価な高Q部品への単純置換だけが解ではない。** 電気的な枝接続の変更で共振モード・ポートとの結合を変えることが重要。
2. PCB小容量は単なる「Lと並列の高調波トラップ調整」ではなく、**入力から内部共振器ノードへの微小フィードフォワード枝**として機能し得る（作用機構は仮説。零点感度・モード電流による因果検証は未実施）。
3. 固定チップ部品数を維持したまま、PCBパターンCの接続とL枝の再接続を**連続的に探索**することが有望。
4. 単一枝を最適化して終了するのではなく、良好トポロジーをシードとして**複数枝の再配線と再最適化**に発展させる。

## 3. 元研究で報告された探索シードのグラフ：将来の最優先探索シード

ノード0=GND、node1=入力50Ω源側、node3=出力60−j40Ω負荷側。

```text
                  Cf0(GJM)
             +------||------+
             |              |
IN node1 o---+-- L0 --------o node2 --- L3 ---o node3 OUT
       |                     |         ||       |
       |                     |        Cf2(GJM)  |
       |                     |         ||       |
       |                     |        Cv2(IC)   |
       |                     +-- L2 --o node5 -- [Cf1(GJM) || Cv1(IC)] -- GND
       |                     |
       |                     +-- L1 --o node4 -- Cv0(IC) -- GND
       |                              |
       +---------- Cpcb(PCB) --------+
```

上の図の`Cf2 || Cv2`はL3=(2,3)と並列、`Cf0`はL0=(1,2)と並列、`Cf1 || Cv1`はnode5–GNDと並列を指す。図の線形表現で矛盾がある場合は下記**端子リストを正本**とする。

| 枝 | 端子 | 種別・役割 |
|---|---|---|
| L0 | (1,2) | HV/Q25、主信号経路前段 |
| L1 | **(2,4)** | HV/Q25、内部共振枝。旧(3,4)からの再配線が成功点 |
| L2 | (2,5) | HV/Q25、内部共振枝 |
| L3 | (2,3) | HV/Q25、主信号経路後段 |
| Cf0 | (1,2) | GJM/Q80、L0並列 |
| Cf1 | (5,0) | GJM/Q80、Cv1並列 |
| Cf2 | (2,3) | GJM/Q80、L3/Cv2並列 |
| **Cpcb** | **(1,4)** | PCB/Q40、入力と内部共振ノード間の微小ブリッジ |
| Cv0 | (4,0) | IC/Q50、設定別0–1.5pF |
| Cv1 | (5,0) | IC/Q50、設定別0–1.5pF |
| Cv2 | (2,3) | IC/Q50、設定別0–1.5pF |

チップL物理一列：**L0–L1–L3–L2**。強結合候補は物理的に隣接する3ペアのみ。非隣接公称k=0。全6設定で同じグラフ/結合。

`C-H30p0002.json`の主要定数：

- L[nH] = **[3.1943411, 20.2855898, 14.6892266, 5.0800844]**（L0,L1,L2,L3）

## 4. 有効だった探索方法：再利用手順

**実行済みの研究手順（局所探索であり網羅ではない）：**

1. **現行RF条件を明示固定**：RF-F002＋RF-T004 trial opt-in。6設定共通の固定部品/結合、可変3枝のみ設定依存。既存EXP016/017の旧Q・旧枝数/旧結合条件とは混合しない。
2. **面積制約を探索ジョブに付加**：面積≤6、PCBパターン固定C≤3。RF仕様自体の面積上限を導入したわけではない。
3. **既知候補の温スタート**：旧V、W3-F4をシード。LQP02HV化・固定C除去、PCB追加、L枝1本変更、L複数枝変更、固定GJMや可変C接続変更、物理一列順、HV/HQ置換を別探索族で試した。
4. **同型・不適合候補を除外**：配置・部品範囲、可変C接続、k上限、全L行列SPD、出力と入力の固定導通経路など。数値最適化途中のH2/H3不成立を成功と判定しない。
5. **SLSQP＋解析ヤコビアンでepigraph minimax**：変数はL値、固定C、許可された隣接k、6設定×3可変C、最悪IL上界。通過区間には`IL(f)≤t`、阻止区間には`IL(f)≥Htarget`を課す。非凸のため複数初期値・別グラフを試し、成功フラグと最終グリッド適合を分ける。
6. **粗格子→精密化**：1構成につき少数開始点を低密度で試験し、有望グラフは31点/区間・多初期値、さらに101点等で候補選別。単一段階の未収束を限界扱いしない。
7. **16初期値の再最適化**：Cpcb=(1,4)構成を30.02/30.005/30.0002dBの条件で各16開始点。多くの初期値は同等の良好局所解に戻ったが、**各条件で少なくとも1件の不適合・失敗試行もあった**（`refine_move5.log`）。候補を全開始点が成功したと記載しない。
8. **独立再検証で昇格判定**：6設定の各不連続周波数区間を7,001点/区間、必要に応じ1次元内部極値を探索。縮約5×5に対し9×9枝電流MNAを別に構成し、電力収支・受動性・K SPD・Q/C範囲を確認。

**独立検証の保存値**（C-H30p0002）：6設定最悪IL=0.305481243666dB（B28 DL 803MHz）、H2最小30.0001999999999dB（B28 1496MHz）、H3最小30.0001999999999dB（B28 2244MHz）。代表点でMNA節点電圧最大差2.23×10⁻15V、最大電力収支残差5.20×10⁻18W、正規化K最小固有値0.849453。密格子＋局所極値は連続周波数全域の数学的保証ではなく、実部品Q(f)/SRF/EMも保証しない。

**再実行アーカイブ**：`EXP021_RFT004_area6_research.zip` を展開したディレクトリ（`EXP021_RFT004_AREA6_PACKAGE`）から以下を実行する。原本コードが要求する`EXP018_RFT004_COST6/EXP016_source/bands.csv`を同梱していることを確認する。

```bash

```

このコマンドは選別済み2候補の帯域評価・独立MNA・単一パラメータ感度を再計算して`selected_verified.json`を更新する。旧実行環境はPython 3.13.5、NumPy 2.3.5、SciPy 1.17.0。推奨WSL2 Python3.12/uv.lockによる**同一環境再実行は未完了**。さらに正式運用では実行コードGit SHA・trial実効ハッシュ・乱数seed・実行環境を新しいmanifestに固定すること。

## 5. 無効・改善限定だった操作（探索済み範囲だけでの評価）

| 試み | 観測・限界 | 将来への示唆 |
|---|---|---|
| W3-F4の高Q LQW04を単純に安いHV/LQP01へ置換・GJM削減 | 少数の局所開始点ではIL目標を維持できない | **単純置換ではなくL枝とC枝を同時再合成** |
| 5HVへの主経路L分割 | 研究した5HV族は面積6条件で改善不足 | 電流分散の効果は「追加Lを通す損失増」と同時評価 |

## 6. 次に有望な構造仮説：優先順位と判定法（**以下すべて未実行の提案**）

### P1：入力–内部共振器ブリッジの伝送零点感度を利用した再合成（最優先）

現候補の`L1=(2,4)`・`Cpcb=(1,4)`・`Cv0=(4,0)`を保持し、L2支線/Cf1/Cv1の接続、Cf0/Cf2容量、物理列順を共同変更する。仮説：入力→node4の弱フィードフォワードパスの干渉によりH2/H3の零点が生まれ、通過帯域の補助枝電流を小さくできる。**未測定**の零点位置・`∂A_H2,3/∂Cj`・素子電流・モード電圧で検証し、単なる接続の印象で機構を断定しない。数値予選は面積≤6/30dB条件でIL<0.30548を目安（これは選別目安であり新たなRF制約ではない）。

### P2：2内部共振枝L1(2,4)/L2(2,5)の非対称デュアルモード化

node4–5間の固定PCB微小C（0.02–0.2pF/Q40）、可変枝の4–5橋絡、固定GJMの移設を候補とし、偶奇モード干渉・TZ分離を狙う。PCB固定Cは合計3個以下。**既存の同じ追加方法では必ずしも改善しなかった**ため、L/C/k全部を再最適化し、零点感度の独立性が増すかを測る。主経路直列0pF可変Cを試す際は開放状態の連結性を確認。

### P3：部品数を維持した固定GJMとPCB微小Cの役割交換

`(1,4)`の微小PCB-Cは公差と寄生に敏感。面積6のまま**GJM×3の端子配置を組換え**、`(1,4)`をGJM/Q80にし、他の固定CをPCB-Q40へ移す、または固定GJM容量を節点に再配分する。単なるQ80への値置換は許されるが、GJM部品数、面積、Cの値域、IC CのQ50との違いを厳守して再合成する。微小容量への依存を減らすことを評価軸とし、名目IL低下だけで採用しない。

### P4：入力–出力間の固定電気的バイパスによる主経路損失削減

`(1,3)`、`(1,5)`等への固定小CまたはブリッジCと、L0/L3・内部L1/L2の複数枝再配線を組合わせる。狙いは主経路L0/L3の通過帯域電流・有限Q損失削減。ただし高調波の不用意な再透過が起こり得る。電流損失配分・H2/H3最悪値を**共通帯域**で比較。

### P5：磁気結合への張り付きと微小PCB-Cへの依存を避けるロバスト化

現在`k(L0,L1)=+0.15`境界、`Cpcb≈0.0256pF`、一部のCv=0または1.5pF。固定一列順の候補を系統列挙し、強結合の追加数・上限|k|≤0.12等の**探索時の感度条件**を変え、同時に全固定L/C/Cvを再最適化。正式|k|≤0.15を勝手に緩和しない。再調整なし感度と各設定のCv再調整後を区別し、H2/H3の実用的ヘッドルームとchip/PCB面積をパレート化。

### P6：公称35dB向けの別系統（最後に比較）

30dB版で見つかった内部ブリッジを固定阻止セルへ発展させ、H2/H3それぞれに複数TZを制御する。30dB版をただ35dBへ絞るだけの継続法で満足しない。固定零点セルと3可変Cの役割分担を設計し、35dB条件で**同一のコスト・Q・帯域**を満たすか判定。未達結果は失敗/未収束として記録。

## 7. 実験の追跡・昇格ゲート
