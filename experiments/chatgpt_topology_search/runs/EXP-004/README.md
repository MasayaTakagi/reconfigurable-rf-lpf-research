# EXP-004 — Phase 2：公称最大IL 0.40dB目標のトポロジー探索

**2026-10-11時点の結論：0.40dB未達。** 現時点の比較基準は、コスト7探索で保存した [A7-01](../EXP-002/A7-01.json) の **最大IL 0.508388959dB、H2/H3最小約35.07dB**。本EXP-004で性能基準を更新する成立解は発見できていない。この記録は計算ジョブの実行状況を明示し、理論性能限界や大域最適性を主張しない。

## 固定する評価条件

- 全6設定のUL/DL全帯域で最大IL評価、ULの2倍・3倍波全帯域で公称減衰 **35dB以上**（正式必須条件は30dB以上）。
- 50Ω入力、周波数非依存60−j40Ω負荷。
- LQP02 Q25、固定GJM01・IC可変C Q80、PCB-L Q12、PCBパターンC Q40（0.02～0.2pF、最大3）。LQW04のQ値は未確定。
- IC可変Cは独立2枝、各0～4pF、**対GNDのみ**、6設定別の連続最適値。固定素子・結合・回路構成は全設定で共通。
- チップL一列配置、隣接強結合 |k|≤0.4、非強結合公称k=0、結合L行列正定値。
- 面積評価上限7は今回のコスト別比較用の**実験条件**であり、[正式制約](../../../../data/design_constraints.json)のhard cap6は変更していない。
- Phase 3は停止。

## 計算の高速化と次の大規模探索

新しい周波数一括解析は、一定Qモデルの結合Lインピーダンス `Z_L=ω(R+jM)` が周波数に比例することを利用し、`Y_L(ω)=B·(R+jM)^{-1}·Bᵀ/ω` としてコイル行列の反転を周波数ごとに繰り返さない。Cは `Y_C(ω)=ωC/(1/Q_C−j)` として各周波数の節点方程式をバッチ化する。**保存済みA7-01の6設定全ての数値を再現済み**。これは数学的な高速化であり、固有の小規模一次探索結果を直ちに改善するものではない。

### GitHub Actionsでの実行方法

[Actions → Phase 2 target 0.40dB topology sweep](../../../../actions/workflows/lpf-target040.yml) から **Run workflow**。初期値2本×最大160回の局所反復を既定設定とし、4並列シャードを実行する。1回のワークフローでは各シャードで指定数のグラフを計算し、**完了した各グラフの直後にcheckpointを書き換え**、最後にArtifactを保存する。残りは別runで `resume_run_id` に直前のrun IDを入れ、同一ソース指紋・パラメータの場合のみ再開できる。Artifact不存在や不一致を探索完了と扱わない。数値ジョブ・独立再検証は起動された時点でのみ「実行済み」とする。

**注意:** 新しい手動ワークフローを用意しただけで大規模計算が実行済みになったわけではない。新しい最良候補を採用するには、高密度周波数・独立MNA・SPD・電力収支・面積・物理結合配置・寄生／公差を別途検証する。
