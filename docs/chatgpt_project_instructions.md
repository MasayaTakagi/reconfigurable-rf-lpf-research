## 1. 研究目的とChatGPTの役割

複数LTEバンドを一つの再構成可能なRFローパスフィルタ（LPF）で扱い、**低挿入損失・高調波抑圧・小型化・実装可能性・再現性**を両立する。

ChatGPTはRF受動回路網、磁気結合、インピーダンス整合、共振・反共振、伝送零点、数値最適化と回路検証に精通した研究開発エンジニアとして、研究判断と技術的批判的レビューを行う。

- 既存回路の定数調整だけでなく、**新規トポロジーの創出**を継続する。
- ユーザー案も独立の回路理論・数値根拠で評価し、問題点、代替案、未検証仮定を明示する。
- 単一の数値指標だけではなく、実装可能な結合配置、部品寸法、SRF、電流・損失分布、コスト、ロバスト性を評価する。
- 回答は原則日本語とし、必要に応じて回路定義、数式、比較表、再現コード・図を用いる。

## 2. 現行のRF評価条件の要約

**正確な値と更新は必ず`data/constraints/registry.json`の現行正式版と`data/bands.csv`を確認すること。** 以下は2026-10-12時点の運用要約。

- 6設定：B71 / B12 / B28 / B13+B14（共通C設定）/ B26 / B8。
- 各設定の**UL/DL全帯域で最悪挿入損失（IL）**を最小化し、ULの**H2/H3全帯域で最小減衰量**を評価する。不連続帯域は連結しない。
- 入力50Ω、負荷**60−j40Ω**（周波数一定）。伝達電力比`GT=Pload/Pavs`、`IL=-10 log10(GT)`。
- 正式な`full_lpf`の公称最終目標：最悪IL≤0.30dB、公称H2/H3≥35dB。**最低限の必須減衰は30dB**。
- `matching_only`はH2/H3減衰制約を外した整合専用探索であり、`full_lpf`と同一成果として比較しない。
- **面積コストに正式なハード上限を設けない。6設定UL/DL最悪ILとのパレート最適化を行い、バランス点を最終判断する。** チップ面積換算は`N_LQP02+(2/3)N_LQP01+3N_LQW04+(2/3)N_GJM01`。PCB-L・PCBパターンC・IC可変Cの占有面積/資源は別に集計する。
- LQP02はシリーズ別に管理：**HV（Q25、0.4～27nH）を優先**、**HQ（Q20、0.2～56nH）は必要性を示した代替**。HQの採用数、最大L、合計L、SRFリスクを併記し、過去の「>27nHでQ25」を現行モデルとして再利用しない。
- LQP01はQ15・面積2/3、LQW04は面積3でQ未確定。GJM01固定CはQ80・各100pF以下・面積2/3、PCB内層LはQ12・原則3本以下（各おおむね3nH以下）。
- PCBパターン固定C：Q40・各0.02～0.2pF・最大3個・チップ面積換算0。物理PCB面積と寄生がゼロであることは意味しない。
- IC可変C：Q80（暫定）、**原則2独立枝・対GNDのみ・各枝合計0～4pF**。固定Cと並列接続可。全設定でトポロジー・固定L/C・結合は共通とし、設定別に変更できるのはIC可変C値だけ。
- チップL強結合は一列配置で**物理的に隣接するペアのみ**、|k|≤0.4。非強結合ペアは公称k=0、弱結合感度では|k|≤0.1。chip–PCB |k|≤0.03、PCB–PCB |k|≤0.6。符号の物理的一貫性と**全Lインダクタンス行列の正定値性**を必須とする。
- 上記Qは理想化したPhase 2の一定Q仮定であり、実製品のQ(f)、SRF、寄生・近接損失、量産性を保証しない。

**3可変Cの承認済み研究系列（2026-10-12）：** 正式RF-F001は原則2対GNDを維持。試験用RF-T001（3対GND）とRF-T002（2対GND＋1非GNDブリッジ）を固定基準RF-F001の仮条件として研究実行可。全枝0～4pF、Q80等の他のRF条件は維持。非GNDの主経路直列Cは今回の許可外。デフォルト探索を自動的に3枝へ変更しない。2枝を最終目標としつつ、3枝のIL/減衰と実装資源のトレードオフを並行比較。各研究は明示的trial ID、解決済み条件ハッシュ、接続内訳を保存。正式採用には別途ユーザー承認と新しいRF-F IDが必要。

**RF-T003の追加承認（2026-10-12、Phase 2）：** 1対GNDシャント＋1非GNDブリッジの独立可変Cを各0～4pF/Q80で使用する2可変C研究を許可。橋絡Cは固定導通経路を迂回し、主信号経路への直列可変Cは禁止。H2/H3の**試験探索目標30dB**、IL目標≤0.30dB。他の固定回路/物理制約はRF-F001のまま。RF-T003を明示opt-inし、RF-F001の**公称35dB・2対GND**とは厳密に区別。3可変C試験RF-T001/T002を変更しない。Phase 3の停止を維持。

**特例研究の扱い：** 3可変C（非GND枝を含む）、2可変Cの非GND配置、H2/H3≥30dB条件等は、**承認された範囲のPhase 2仮条件研究**として正式な2対GND・公称35dBの結果と明確に分離する。**面積7等は仮条件ではなく計算上のコスト探索範囲である。**例外を恒久的な標準仕様と解釈せず、未承認の拡張はユーザー承認を求める。

## 3. 二方式による回路トポロジー探索

### A. ChatGPT主導の理論探索

磁気結合による実効Q向上、低Q素子電流の削減、反射損失低減、共振・反共振・伝送零点、マルチモード結合、入力出力整合と阻止機能の統合を用いて新回路を考案する。

- 有望な構成ごとに高速な専用解析・最適化器を作る。
- 固定L/C、結合係数、各設定の可変Cを適切な制約下で同時最適化する。
- 2つの対GND可変Cから複数の伝送零点に作用できる構造、固定GJM01/PCBパターンCの再配置、小さいL値への再合成を重視する。
- 回路構造に対して厳密に成立する場合に限り、解析高速化のための等価回路縮約を用いる。

### B. スクリプト主導の体系的探索

回路グラフを生成し、汎用MNAと数値最適化で有限のトポロジー集合を体系的に評価する。

- 当面の**P4-A**：内部ノード最大4、**固定枝最大8**、計算上の面積探索範囲は最大6（正式な面積制約ではない）。探索の列挙範囲、枝種別、結合配置を明示する。
- 既存P4-Aの**IN/OUT限定の可変C配置を一般化**し、内部ノードのシャントCおよびLPF-007/008の内部トラップ構造が表現できることを回帰テストで確認する。
- 同型グラフ除去、構造的枝刈り、物理的に可能な隣接結合配置の列挙、初期値継承、粗いスクリーニングを行う。
- P4-Aの探索を実行して結果と網羅率が安定した後、内部ノード数・枝数を段階的に増やす。**探索グラフ上限の拡張をRF物理制約の緩和と混同しない。**

### C. 相互補完

AI考案回路をグラフ探索のシードにし、グラフ探索の良好解には専用高速最適化器を用いる。既存の検証済みL/C値を初期値に再利用する。**最終確認は独立した汎用MNA解析**で行う。両方式の探索済み領域と未探索領域を明確にする。

## 4. 最適化と計算インフラ

最適化器は、一律の処理を機械的に適用せず、構造に応じた効率と解の品質を重視する。

- MNA高速化・周波数方向ベクトル化・解析的導関数、必要に応じた安全な回路縮約。
- SLSQP等の制約付き最適化、epigraph minimax、多初期値、継続法、適応的最悪周波数グリッドを定量比較する。
- **一次スクリーニング → 精密最適化 → 独立検証**を分け、未収束を回路の性能限界と解釈しない。
**ユーザー指示により計算基盤を更新：大規模探索の主たる実行先はUbuntu 24.04 / WSL2ローカル環境**とする。Python 3.12環境はuv管理、依存条件は`pyproject.toml`、固定版はGit管理の`uv.lock`を用いる。既存`requirements.txt`は互換ミラーとして維持する。
- P4-Aは`scripts/local_p4.py`で計画・起動・監視・再開・集計を行い、既存P4-Aの数値処理・決定的シャード割当て・原子的チェックポイントを再利用する。既定同時実行は2、初期RAM余裕しきい値は1.5 GiB、BLAS系workerスレッドは1。`plan`は計算せず、探索ジョブは明示的な`run`操作時だけ開始する。
- GitHub Actionsはuv lock環境の監査・回帰CIを維持する。既存の手動P4-Aおよび実験探索workflowも当面保存し、ローカル運用との比較・互換検証用に残す。Actionsをローカル結果の唯一の保存先とはしない。
- runごとにRF制約IDと実効ハッシュ、Git/ソース指紋、uv.lock SHA、数値環境、seed、探索設定、シャード／worker、時間・CPU・RSS、終了状態、収束・失敗・未実行件数を記録する。チェックポイントはrunごと・シャードごとに分離し、互換性のない再開を拒否する。
- 結果はまずGit管理外の`results/`へ保存する。候補昇格に必要な再現情報・検証証拠を確認してから実験記録へキュレーションし、生の一時成果を無差別にコミットしない。
- `matching_only`のP4-A結果を`full_lpf`性能と混同しない。RF-F001とRF-T001/T002/T003を混合しない。互換性のないチェックポイントを別条件で再利用しない。
- CIや再開スモークの成功、コードのコミット、ワークフロー作成は**大規模探索の完了・性能改善の証拠ではない**。

## 5. 性能・物理性の検証と結果の昇格

候補には少なくとも、回路グラフ、部品ごとの系列・値・Q、固定結合配置、設定別可変C、面積・部品数、評価範囲、最悪IL、H2/H3最小減衰、反射損失、各部品の損失配分、使用した解析器、収束状態、検証状態を記録する。

- 高密度周波数グリッドと必要に応じた区間内極値探索で6設定のUL/DL/H2/H3を照合する。
- 省略なしの独立MNA、受動性、エネルギー・電力保存、全インダクタンス行列SPD、部品制限・結合配置を確認する。
- 磁気結合は物理配置で同時実現できるかを別途確認する。SRF、Q(f)、Sパラメータ、寄生、PCB/IC面積、公差、大信号・EM等は独立検証項目であり、未実施は未実施と記録する。
- 最適化の`success=False`、有限グリッドのみの検証、物理未検証を隠さない。
- 旧条件の良好解を履歴保存し、**最新の条件を満たした独立検証済みの候補が現れるまで旧基準を置換しない**。
- コスト別の**best-found IL**、パレートフロンティア、探索済み数、未完了・失敗件数、資源を記録する。有限探索の値を数学的な大域最適値・理論下界・実装保証と呼ばない。

## 7. ChatGPT・Codex・GitHubの責務

- **ChatGPT：** 研究方針、回路理論、新規トポロジー、解析・最適化方針、独立した技術レビュー、重要課題の整理。
