## 新しい2可変Cの回路構造

最良EXP014-02/03は以下の**同一グラフ**で素子値のみ異なる。ノード1が入力、ノード3が出力、0がGND。

| 部品 | 接続先 | 役割（研究仮説） |
|---|---|---|
| L0 (Q25) | 1–2 | 主信号経路前半 |
| L3 (Q25) | 2–3 | 主信号経路後半 |
| L1 (Q25) | 3–4 | 出力側補助共振枝 |
| L2 (Q25) | 2–5 | 内部補助共振枝 |
| Cf0 (GJM Q80) | 1–2 | L0並列の固定周波数整形 |
| Cf1 (GJM Q80) | 5–GND | Cv1を廃止した枝の固定容量 |
| Cp0 (PCB Q40) | 3–1 | 入出力を結ぶ固定小容量ブリッジ |
| Cv0 (IC Q80) | 4–GND | 第1可変C |
| Cv1 (IC Q80) | 2–3 | L3並列の**非GND第2可変C** |

- 物理チップL一列: **L0–L1–L2–L3**、結合はその3隣接組だけ。最良EXP014-02のkは約**+0.052317、−0.051591、−0.170013**（正定値）。
- EXP014-02固定値はL0≈**2.96854**、L1≈**28.56046**、L2≈**8.66228**、L3≈**5.46343 nH**。Cf0≈**1.83401**、Cf1≈**0.89164**、Cp0≈**0.06358 pF**。6設定ごとのCv値は[候補JSON](EXP014-02.json)が正本。
- 入出力・高調波を横断する最悪IL点は**B28・803 MHz**（B8・960 MHzもほぼ同等）。独立MNAでの会計損失は入力反射約**0.00254 dB**、L合計約**0.28339 dB**、C合計約**0.05726 dB**。[損失データ](EXP014-02-loss.json)。これは部品除去の因果感度ではない。
- EXP014-01では追加GJMが既存GJMと同一枝（向きの逆を含む）・同Qのため、**並列2個の固定容量を厳密に1個へ統合**した。Cの和は同一枝で同じQ80を保つ。この統合が面積を5⅓に縮小。詳細は[テスト](../../../../tests/test_exp014.py)にも記録。

## 何を実際に探索したか

[search_summary.json](search_summary.json) に、**323件の一次局所最適化＋6件の精密化=計329実行**を記録。これらはグラフの固有数を意味せず、収束・未収束と未実行を区別する。実行途中で止めたグループは、次の通り。

- 2可変Cの配置×GJM配置：**72/210予定**（未完138）。
- PCB-L Q12付加の粗探索：**14/75予定**（未完61）。
- 第5チップL Q25追加の候補：**15/30予定**（未完15）。
- 良好解からの追加多初期値：**43/48予定**（未完5）。
- それ以外に、固定C置換（14）、固定GJM/PCB-C追加（30+30）、物理一列L順序12通り×2（24）、PCB-C2本化（15）、追加PCB-L（15）、全対GND2可変C10位置（10）、高価値解からの多初期値（16）、EXP013起点コスト4・2可変Cの5構成×5開始点（25）。
- プログラム例外0、ただし**非凸最適化の未収束・減衰不成立・IL未達は実際に存在**。それらを「回路の性能限界」と断定しない。

**有望な設計操作:** 3可変Cの小振幅調整枝を**固定GJMまたはPCB-Cへ置き換え**、2本の残存可変Cと全固定L/C/kを再最適化する。特にチップL一列順の変更とPCB小容量ブリッジを組み合わせると、従来2対GND可変Cの0.411dB水準から改善した。ただし、IL≤0.30の性能維持条件まではまだ離れている。新しい2可変C向けの共振器グラフ、2枝以上のLの同時接続変更、3C→2Cへの非線形特性変換を探索する必要がある。
