## 1. 固定したRF条件

- 登録済み試験条件`RF-T004`を明示適用。正式ベース`RF-F002`の部品・配置・結合・電力評価条件は変更しない。
- 可変IC Cは**最大3独立枝、各0～1.5 pF、Q=50**、シャント・橋絡・直列を許可。今回検討した有力回路は固定Lに並列に置く橋絡CとトラップのシャントCを使用。6設定で同一回路構造・固定部品、設定ごとの3容量だけ変更。
- LQP02HV：Q=25、0.4～27 nH。GJM01固定C：Q=80、各100 pF以下。PCBパターンC：Q=40、0.02～0.2 pF、最大3個、チップ面積0。今回の**公称磁気結合はすべてk=0**（RF-F002の許容範囲内）。全インダクタンス行列は正の対角行列。
- 50 Ω信号源、60−j40 Ω定数負荷、IL=−10log10(Pload/Pavs)。6設定はB71/B12/B28/B13+B14（同一Cで不連続UL/DL/H2/H3を個別評価）/B26/B8。`data/bands.csv`の区間を手動で一致転記したプログラムを使った。**今後帯域正本を変更したら再同期・再計算が必要。**
- チップ面積ハード上限なし。面積＝LQP02個数+(2/3)×GJM01個数。PCBパターンCの実PCB面積とEM寄生は別に管理。
- 正式RF-F002の2可変Cとの同条件最良値比較は**未実施**。旧RF-F001系LPF-007/EXP-015を新条件のベースラインとして扱わない。

## 2. 文献から採用した回路合成の着眼点

先行する[RF-T004文献調査](../../../../docs/research/rf_t004_literature_survey_2026-10-14.md)に基づき、(a)固定LC阻止セルと可変整合の役割分担、(b)主信号経路を迂回する可変橋絡での伝送零点、(c)複数共振モード・複数経路の干渉、(d)不要な通過帯域シャント電流の削減を回路グラフに落とし込んだ。これは原文献の集中定数・低Q・複数バンドでの実証を意味しない。

**最良構造は必ずしも固定Cを増やしたものではない。** D-PCBpattern-trapではPCBパターンCが両方0.02 pFの下限に張り付いた。D-trap-onlyはこれらを取り去ってさらに低い35 dB目標ILを示した。D-3L-trapは微小なシリーズLも取り除き、名目35 dBのIL差0.0341 dBで面積1単位削減。

### 回路の明確なエッジ定義

ノード0=入力、3=出力、`GND`=接地、その他は内部ノード。

**D-PCBpattern-trap:** LQP02HV L0:(0–1), L1:(1–2), L2:(2–3), L3:(2–4)。固定PCB C0:(1–GND), C1:(2–GND) およびGJM C2:(4–GND)。可変C0:(0–1), C1:(2–3), C2:(4–GND)。チップ面積4+2/3。

**D-trap-only:** 上のLと可変Cを保持し、固定CはGJM:(4–GND)のみ。チップ面積4+2/3。

**D-3L-trap:** LQP02HV L0:(0–1), L1:(1–3), L2:(1–2)。固定GJM C:(2–GND)。可変C0:(0–1), C1:(1–3), C2:(2–GND)。チップ面積3+2/3。

部品定数・6設定個別可変C・IL/H2/H3・代表点独立MNA照合は同フォルダの`curated_results.json`に保存した。いずれの候補も全枝0～1.5 pF、LQP02HVの値域、固定C上限、固定回路構造の6設定共通性を満たす。

## 5. IL損失分解（最悪通過点、電力はPavs基準）

- D-PCBpattern-trap、30dB、**B8 960 MHz**：負荷到達89.532%、反射1.595%、全部品で散逸8.873%。主損失は出力側L (2–3)3.880%、入力側L (0–1)2.319%。
- D-trap-only、35dB、**B8 960 MHz**：負荷到達87.172%、反射0.103%、全部品で散逸**12.725%**。出力側L (2–3)5.499%、入力側L (0–1)2.881%、固定トラップC1.865%、トラップL1.448%。電力和1を数値確認。

## 7. コードと再現方法

このフォルダの`search_t004.py`が22構造の網羅**でない**有限スクリーニング、`refine_t004.py`が制約付きSLSQPと独立照合。初期値・最適化グリッド・再検証グリッド・出力先・停止回数を記録する。

```bash
OPENBLAS_NUM_THREADS=1 uv run python experiments/chatgpt_topology_search/runs/EXP-016/search_t004.py --names D-PCBpattern-trap D-trap-only D-3L-trap --starts 12 --iter 120 --points 9 --dense 201 --seed 20261016 --out results/exp016_screen.json
OPENBLAS_NUM_THREADS=1 uv run python experiments/chatgpt_topology_search/runs/EXP-016/refine_t004.py --inputs results/exp016_screen.json --all-starts --grid 31 --verify-grid 2001 --out results/exp016_refined.json
```

`uv`経由の環境監査、制約ローダ統合、既存共通MNAとのコード回帰、GPU/WSL大規模ジョブは**未実施**。最良値の厳密再現には入力seed・依存版・コードコミット・選択startの記録と既存コードとの二重比較が必要。
