# Phase 2：PCB間|k|≤0.6・チップ面積≤6の整合専用追加探索

**更新日：2026-10-10。Phase 3は引き続き停止。**

> **履歴注記：** 本研究は旧チップ間結合規則（主2ペア|k|≤0.25、その他|k|≤0.16）で計算した記録。現在の新ルールは**各chip–chipペア|k|≤0.4**。結合上限変更後の整合専用の更新ベンチマークと疎結合感度は[追加研究](14_chip_coupling_k04_study_ja.md)を参照。旧データを削除せず、モデル変更を比較できるよう保持する。

## 規則と目的関数

[最新部品・コスト規則](11_component_cost_topology_rules_ja.md)、[機械可読仕様](../data/design_constraints_20261010.json)を使用する。

- ソース50Ω、周波数一定負荷60−j40Ω。6設定B71 / B12 / B28 / B13+B14 / B26 / B8の**ULとDL全域**で最大ILを最小化する。各設定の容量は可変Cだけ変更可能。
- **減衰制約なし**：H2/H3仕様は今回の最適化に含めない。後で35dB阻止を戻す段階を別途評価する。
- 面積コスト：LQP02=1 (Q25)、LQP01=2/3 (Q15)、GJM01固定C=2/3 (Q80暫定)、**上限6**。PCB-L Q12は原則3本、IC可変Cは対GNDで原則2枝まで、1枝0〜4pF (Q80暫定)。LQW04はQ未合意なので今回の数値探索対象外。
- chip–chip主結合2組|k|≤0.25、残り|k|≤0.16。chip–PCB結合は0（上限|k|≤0.03以内）。**PCB–PCB結合は|k|≤0.6**で、さらに全インダクタンス行列の正定値性を必須とした。従来のk=0.8、0.98を用いる結果は新仕様のパレート候補から除外する。

面積2→4で約0.02110dB改善、面積4→6で約0.01314dB改善。増えるチップ面積に対して損失改善は徐々に小さくなる。

**PCB-L k=0.6の面積0候補**は、チップ面積という代理コストが0であり、PCB配線・ビア・層間配置コストが0という意味ではない。全PCB間をk=0.6にできる実装成立性は未評価。

## 探索クラス・再現性

- 旧296件＋直列L群の追加216件＋シャントL/複数固定GJM01配置の追加300件＝延べ**812件**の局所最適化ケースを照合。うち**707件**が新PCB-k/面積規則と収束・電力収支等のチェックを通過。異なる初期値や重複する回路を含むため、「812種類の独立トポロジー」を意味しない。
- 新規のシャントLを含む限定300件では、283件が数値収束・所定チェックを通過。その最良最大ILは**約0.258842dB**で、直列L群の候補を上回らなかった。ただし非直列ネットワーク全体を網羅した結果ではない。
- 代表7構成を0.02MHz刻みで再評価したほか、複素結合を含む**全巻線の独立MNA**で複数の周波数を照合し、電力収支をチェックした。代表7構成での差は約1e−14dB以下。
- 6チップL最良候補はB71 617MHzが最悪点。利用可能入力電力1Wに対し、負荷975.3167mW、入力反射11.8459mW、L損失11.9188mW、可変C損失0.9186mWで合計1000mW。
- 保存した数値結果は**大域最小値の数学的下限ではなく、探索で得られた成立候補のIL値**。有限Q近似に加え、Q(f)・SRF・相互抵抗・寄生容量・近接効果・強結合の実装成立性・連続帯域での区間保証がない。

## 実装とコストに関する判断

1. **面積2～4**のLQP02回路は、低チップ数と最大IL約0.14～0.12dBを両立する比較基準。
2. **面積6**では0.10854dBまで改善。ただしLQP02×6の全15組について、主結合2組0.25と副結合13組0.16を同時に仮定。幾何学的配置・磁束経路の検証が必要。
3. GJM01固定Cを追加した限定探索では、整合専用の最良パレート候補の更新はなかった。高調波減衰を復帰すれば変わりうるため、固定Cが不要という結論ではない。
4. PCB-L間k=0.6は**設計上の許容上限**であって、実際に実現できるという意味ではない。k=0.4,0.5などの感度を含める。
5. Phase 3の離散C化には着手せず、次は**結合値の実装成立性と35dB減衰復帰のコスト上昇**を評価する。
