## ロバスト性：明確な弱点

`single_parameter_tolerance_101pt_20261017.json` で28区間×101点、6設定のCvを固定したまま、固定C各±1%、隣接k各±0.01、2Cv全設定一括±1%の**計16個の単独摂動**を数値確認した。**16/16がH2またはH3の30dB条件に不適合**だった。例：Cf1（tip4–GND GJM）−1%でH3=29.2995dB、k(L1,L3)−0.01でH3=28.3373dB。公称30dBから約0.03dBしか余裕がない。±変動が許容範囲外になるケースはあくまで感度診断であり、新たな公称設計条件の承認ではない。

これは局所値の1パラメータ試験であり、分布公差、設定別Cv再調整、公差歩留まり、Q(f)/SRF、実磁気結合、PCB/ICの寄生、EM、試作測定は未実行。有限28×1001点PASSは連続帯域極値の保証でもない。数学的大域最適・RF-F003での最良4L一般解の証明ではない。
