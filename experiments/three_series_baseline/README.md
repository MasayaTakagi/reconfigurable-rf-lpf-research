# LPF 構成探索：0.33 dB 達成設計（公称値）

設計対象：B71, B12, B28, B13+B14共通容量, B26, B8 の6ケース。
通過域：各ケースのUL + DL。阻止域：ULの2倍波/3倍波全域。
入力：50Ω、出力：60-j40Ω一定。Q：すべてのL=25、すべてのC=80（一定値）。
部品面積制約：LQP02HV ×4（面積換算4単位）。LQW04/PCB-Lは採用しない。
各ケースでC1～C4を連続値として可変、L・kは全ケース共通。
Phase 3（スイッチドCの離散値・部品寄生・スイッチ非線形）は未実施。

## 新回路
IN -- [L1 // C1] -- [L4 // C4] --●-- [L3 // C3] -- OUT
                                    |
                               [L2 series C2]
                                    |
                                   GND

L1, L4, L3が直列経路に並列共振トラップを構成。L2-C2は中間シャント。
インダクタは枝方向に対するk符号（inductors_couplings.csv参照）で結合。
主結合は k14 ≈ +0.183, k23 ≈ -0.248。その他の組は絶対値0.03以下。

## 達成内容
- 採用候補：弱結合制限0.03、C上限25pF、34.0dB公称減衰を狙った局所最適化解。
- UL+DL全域最大IL ≈ 0.32017dB。
- 2倍波・3倍波全域の最小減衰 ≈ 33.9998dB（30dBの必須仕様に対して約4dBの公称余裕）。
- 6ケース0.02MHz刻み検証、および独立MNA実装で代表点の確認。
- 高調波35.05dB目標の場合：最良探索値 ≈ 0.33494dB（0.33dB未達）。

## 重要な制約・限界
1. 結合係数は設定値を厳密に実現するものと仮定。製造ばらつきを保証していない。
2. LQP02HVの実際のQ、SRF、定格電流、寄生および公差は含まない。
3. C1はB71で17pF超となる。部品やスイッチドC実装時の実際のQと寄生が課題。
4. L/C各独立±1%、k各独立±0.01の250試行では127試行が30dBを下回った。
5. スイッチドCはPhase 3でユーザー承認があるまで一切進めない。
6. 大域最適性の数学的証明ではなく、候補を探索した数値的設計解。
